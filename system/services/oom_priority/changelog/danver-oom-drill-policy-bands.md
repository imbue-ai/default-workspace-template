The OOM drill (`bin/oom_drill.py`) puts its sleepers at the shed policy's own scores unless `--bands` names others: an aged chat (1000), Chromium's tabs (960), its GPU and utility processes (943) and main process (910), an agent's commands (900), the Screen's stack (850), a worker agent (600), a fresh chat (560) and a user agent (300). It now counts every built-in service, up to 86, as one that must not be shed while an agent's command or a browser process remains. A test holds both to `bands.py`, and `OOM_DRILL.md` drops the old `--bands 1000,900,800,600,300` example and checks Chromium's scores.
