The memory candidates command also lists what else holds memory and why it is not a candidate: chats and workers mid-turn, in use or waiting on a background task, the main chat, the critical and internal apps and workspace services, and the browser while a window shows the Screen, which it used to leave out entirely. In JSON each section carries these as `others`. `oom_priority.meminfo` gains `read_smaps_memory`, one read of a process's `smaps` for its anonymous memory and its shared memory segments, which the System Monitor uses under gVisor.
