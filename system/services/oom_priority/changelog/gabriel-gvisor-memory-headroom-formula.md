Corrected the description of the memory headroom a cloud workspace's VM publishes. The oom_priority README and the `cgroup_meminfo` module said the VM-side publishers count only the inactive file cache because that is all a gVisor sandbox's cgroup holds. That was measured false on gen-2 slices, and mngr's publishers now count the file cache on both lists and the reclaimable slab, less a fixed reserve. The local Docker publisher's own figure is unchanged.
