New near-exempt band `UPDATE_APPLY` (15) for the update-apply orchestrator: only the owner-exec (5) and terminal (10) authority bands that would repair a failed apply sit below it, so every service, agent and chat -- including the system interface (20) it may be replacing -- is shed before it. Losing one of the apply's builds is an ordinary failure its rollback absorbs; losing the orchestrator mid-motion strands the workspace half-applied with the only copies of the pre-apply state orphaned.
