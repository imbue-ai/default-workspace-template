The README's account of how the chat app's prioritizer re-tags chats now matches the prioritizer: a presence report asks for a pass only when it changes whether the chat is open or showing, passes run one at a time on the prioritizer's own thread at most once every two seconds, and each reads the pid registry once for every chat. The registry's and launch wrapper's docstrings name `live_pids_by_agent_id`, which the prioritizer now reads once for all chats, in place of the per-agent `lookup_pids_by_agent_id`.
