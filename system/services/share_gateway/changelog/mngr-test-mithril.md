New service: the in-workspace half of the self-hosted sharing redesign, replacing the cloudflared tunnel stack. Idles on data/.secrets/share.env; while sharing is enabled it runs an in-workspace caddy TLS terminator (the key never leaves the workspace; certs come from the connector via CSR + ACME DNS-01), an frpc tunnel to the region relay, and a forward-auth gateway enforcing data/.secrets/share_grants.toml per request (grant edits need no restart or token rotation).
