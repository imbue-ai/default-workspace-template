Embeddable cross-origin workspace sharing for the hosted web client. The share gateway now supports the hosted minds chrome embedding a workspace in a cross-site iframe: an owner fast path, cross-origin session cookies (`SameSite=None; Secure; Partitioned`) so the workspace session is readable inside the iframe, an origin policy that admits the configured chrome origin, health endpoints the chrome can probe, and the injected share materials (including `SHARE_CHROME_ORIGIN`) needed for the workspace's frpc to dial the relay and terminate TLS in-workspace.
