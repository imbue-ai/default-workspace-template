- `share.env` gains an optional `SHARE_COOKIE_HOST_ONLY=1`. When set, the gateway's login callback sets both session cookie copies (`imbue_machine_session` and the partitioned one) with no `Domain` attribute, so a cookie belongs to the one service host that set it. The web latchkey auth sandbox uses it: every sandbox of a region is a share on the one workspace domain `auth.<region>.<content domain>`, and a domain-wide cookie would let two users' sandboxes overwrite each other's sessions. The verify path, the cookie names and the partitioned copy are unchanged; a `share.env` without the key behaves as before.

- On a share marked `SHARE_COOKIE_HOST_ONLY=1` (an auth sandbox), frpc now logs in to the relays as the share's auth label instead of the workspace domain's first label. frps prefixes every proxy name with the login user and refuses a name already in use, so sandboxes of one region, which all share the domain `auth.<region>.<content domain>`, would otherwise all register `auth.share` and `auth.screen-media` and only the first could be reached; the connector accepts `<auth label>.screen-media` as the sandbox's media proxy. A workspace share's login user is unchanged.

- On a share marked `SHARE_COOKIE_HOST_ONLY=1` the login callback runs on the host being visited: caddy serves `/_auth/callback` on every service host of such a share, and the gateway's redirect to the broker names the visited host as the callback origin (the dedicated auth origin otherwise). A host-only cookie set by the auth label reaches no other host, so with the callback confined to the auth label every visit to a sandbox's Screen or owner-exec host would have been bounced to the broker again.

- On a share marked `SHARE_COOKIE_HOST_ONLY=1` the login callback expects the broker's handoff token to name the host the callback runs on as its audience, not the shared workspace domain: every sandbox of a region shares `auth.<region>.<content domain>`, so a token the broker minted for one user's sandbox would otherwise open an owner session on another user's sandbox whose label they knew. A domain-wide share still expects the workspace domain.
