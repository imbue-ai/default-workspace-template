The share gateway now runs caddy, frpc and the frpc reload in their own sessions, so a child that touches the workspace's terminal can no longer stop the gateway and drop every share tunnel with it. Because those children are no longer reachable by supervisord's group signals, the gateway's own shutdown now signals all of them before waiting on any: a single tunnel that is slow to exit used to be able to use up the whole shutdown window and leave the rest running on their ports, which kept the restarted gateway from claiming port 443.
