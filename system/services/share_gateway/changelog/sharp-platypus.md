Visitors to a shared workspace now stay signed in for 30 days instead of 24 hours. The workspace session cookie the login callback sets was fixed at 24 hours and nothing renews it on use, so anyone using a share link -- the owner included -- was sent back through accounts.imbue.com roughly once a day. Where the accounts sign-in was still alive that cost a "Continue as ..." click; where it was not (notably on iOS, which drops the accounts session cookie because it carries the CHIPS `Partitioned` attribute and no plain copy), it cost a full sign-in.

The session is still fixed rather than sliding, so 30 days is an absolute cap from the moment of login. Revoking someone's grant still cuts them off immediately -- the gateway re-reads the grants file on every request -- but an account revoked at the broker (sign-out, suspension) is not re-checked by the gateway, so that now takes up to 30 days to be felt on an already-issued session.
