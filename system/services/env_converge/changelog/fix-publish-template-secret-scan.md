`template_manifest.secret_references_in` is the one scan for the secret files a template runs under, shared by the validator and the publish flow's manifest writer. It covers only the supervisord programs and `mcp-servers.json` under the recipe's include paths, and reads program configs with supervisord's own comment rules, so the base's `host-backup` and `share-gateway` programs no longer fail every template's validation. An included program config that does not parse is reported as a problem. `is_covered_by` is the include-path test the env.d unit check also uses.
