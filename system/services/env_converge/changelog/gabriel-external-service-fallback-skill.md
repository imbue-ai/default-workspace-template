A template's `[[requirements.secret]]` entry now names a `file` (the `<file>` of `data/.secrets/<file>.env`) and its `variables`, which is what `use-template` files a secret card for; the legacy bare `name` still loads until no published template predates the change. `validate_template_tree` flags a supervisord program or an `.mcp.template.json` server that runs under a secret file no entry declares, so an adopter is never left with a program that starts without its credential.
