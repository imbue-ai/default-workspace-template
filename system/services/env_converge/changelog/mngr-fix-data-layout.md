New library: environment record + boot-time convergence. Captures actual installed state (dpkg via an apt Post-Invoke hook, `npm -g` and `uv tool` probes) into per-source JSON files at `~/.mngr/plugin/env-converge/`, and converges the regenerable rootfs back to the record at the pinned apt snapshot timestamp on every boot: overlay symlinks (fast phase, pre-services), `system/scripts/env.d/<NNNN>-<name>.sh` units (idempotent, fast satisfied-checks, no markers), and record replay with removal-stickiness via a rootfs identity stamp. `env-converge upgrade` advances the pinned timestamp (the only version-moving operation).

- New cargo/rust source: `cargo install --list` and `rustup toolchain list` are captured into `cargo.json` alongside the apt/npm/uv records (empty when rust is absent -- it is agent-installed, not in the base image), and converge replays recorded registry crates via `cargo install --locked <crate>@<version>` after installing the recorded rustup default toolchain. Non-critical for restores (`~/.cargo/bin` binaries ride the backup as files); it exists for inspiration manifests and genuinely fresh homes.
