Template-manifest field descriptions and the service README now use the new vocabulary: a manifest records what an agent adopted or built on, rather than what a mind did. The desktop app is now called Imbue Studio, and the noun for the thing you talk to is now "your agent" rather than "your mind".

Only the human-readable descriptions changed; every manifest field name is the same, so published manifests stay readable by older and newer workspaces alike.
