The backup's default excludes now cover copies of an app's data made while changing the app: an isolated instance's `copies/` and `scratch/` (`data/.state/isolated-instances/*/copies` and `*/scratch`) and `update-app`'s pre-change snapshots (`data/.state/app-data-snapshots`). The data they copy is backed up where it lives, and one app's store can run to many GB, so without this every hourly snapshot taken while a preview or test instance was up swept a second copy of it. The instance's own state (`instance.json`, its logs) is still backed up. The README's manual restore now targets `/var/tmp/restored`, since `/tmp` in the container is memory.
