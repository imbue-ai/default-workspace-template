The backup's default excludes now cover the update apply's pre-apply snapshots (`data/.state/update-apply/snapshots`). Those copies are a venv, two uv tool environments and a built bundle -- exactly what the existing `**/.venv` and `**/node_modules` globs exclude everywhere else -- and they are only meaningful to an apply on this container. An apply whose rollback could not restore health keeps them indefinitely on purpose, so without this every hourly snapshot swept a full venv plus two tool environments.
