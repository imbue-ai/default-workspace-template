Backup retention no longer thins away a snapshot from the last hour. `restic forget` now runs with `--keep-within 1h`, which keeps every snapshot taken within an hour of the newest one. Before, any extra tick in the same hour as the previous one (a restarted service, a changed `restic.env`, a manual backup) made keep-hourly drop that previous snapshot. A minds restore rewrote `restic.env` just before it ran, so restoring the newest backup of the current hour failed with "failed to find snapshot": the tick the restore itself triggered had forgotten the snapshot the user picked. Seen on a staging workspace.
