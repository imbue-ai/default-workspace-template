A host_backup snapshot test no longer fails when run inside a live workspace. Its fake outer helper decided whether a request was new by the request file's modification time, which can change while the request stays the same, so the helper handled one request several times and the test saw `cleanup, cleanup, snapshot, snapshot` instead of `cleanup, snapshot`. The fake now goes by the request id, the same way the real code matches a result to its request. The backup service itself is unchanged.
