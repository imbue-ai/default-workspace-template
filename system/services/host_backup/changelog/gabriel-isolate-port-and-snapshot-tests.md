A host_backup snapshot test no longer fails when run inside a live workspace. Its fake outer helper decided whether a request was new by the request file's modification time. Under gVisor, which workspaces run on, the modification time the sandbox reports for a file it just wrote changes to the host's slightly different value once the sandbox drops its cached copy of the file's details, which a busy test run makes likely. The helper then handled the same snapshot request twice, and the test saw `cleanup, snapshot, snapshot` instead of `cleanup, snapshot`. The fake now goes by the request id, the same way the real helper and the backup service match a result to its request. The backup service itself is unchanged.
