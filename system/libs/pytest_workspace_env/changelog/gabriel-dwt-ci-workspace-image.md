New test-only pytest plugin, loaded in every pytest root through the `pytest11` entry point. With `DWT_REQUIRE_WORKSPACE_ENV=1` set, a test that skips is reported as failed (a skip from the test body) or as an error (a `skipif` condition), with the skip's own reason in the message; without the variable the plugin does nothing. The CI job that runs the suites inside the workspace image sets the variable, so a tool missing from the image turns the job red instead of quietly shrinking it.
