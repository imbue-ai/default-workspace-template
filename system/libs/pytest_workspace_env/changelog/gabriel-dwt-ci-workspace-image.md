New test-only pytest plugin, loaded in every pytest root through the `pytest11` entry point. With `DWT_REQUIRE_WORKSPACE_ENV=1` set, a test marked `browser` or `real_claude` that skips is reported as failed, with the skip's own reason in the message; every other skip, and every run without the variable, is untouched. The CI job that runs the suites inside the workspace image sets the variable, so a Fortress or `claude` binary missing from the image turns the job red instead of quietly shrinking it.
