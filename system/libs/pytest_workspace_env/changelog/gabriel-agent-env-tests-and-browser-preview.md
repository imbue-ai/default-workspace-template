The plugin now clears the environment an mngr agent runs with before any conftest is imported: every variable starting with `MNGR_`, `MINDS_`, `CODE_GUARDIAN_`, `REVIEWER_` or `CLAUDE_`, plus `CLAUDECODE`, `MAIN_CLAUDE_SESSION_ID`, `TMUX`, `TMUX_PANE`, `LLM_USER_PATH`, `ORIGINAL_CLAUDE_CONFIG_DIR` and `PI_CODING_AGENT_DIR`. CI has none of these, so a test that read one without setting it passed in CI and failed whenever an agent ran it, as update-self's test gate does. Seen with `create_worker_test.py`, which failed one test inside any agent on 0.8.6. Tests, conftests and the subprocesses tests start no longer see them; a test that needs one sets it itself. The session header lists what was cleared. The root, chat and system interface pytest configurations name the plugin in `required_plugins`, so a run that cannot load it stops before collecting anything.
