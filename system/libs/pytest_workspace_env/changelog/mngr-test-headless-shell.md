A new `pytest_workspace_env.browsers` module says which browser a browser test launches: Playwright's headless shell where the workspace installed it for the tests, else Fortress (always Fortress for a `--headed` run), else Playwright's own managed browser. It also holds `is_e2e_browser_installed`, the skip condition for a browser test. The repo-root, chat and shell suites all use it in place of their own copies.
