New test-only pytest plugin that stops a test run on macOS before it collects anything, with a message saying to push and let CI run the tests or to run them in a workspace. The suites target the Linux workspace container: on a Mac some cannot install and others fail for macOS reasons, so a local run cost minutes and proved little. Set `DWT_ALLOW_MACOS_TESTS=1` to run pure-Python tests there anyway.
