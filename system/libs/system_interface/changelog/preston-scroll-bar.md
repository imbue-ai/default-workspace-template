Workspace UI scrollbars are now native: the custom `.app-content` scrollbar (a 6px bar sitting flush against the content edge) and the model-selector dropdown's `scrollbar-color` override were removed, so the OS draws its own auto-hiding overlay scrollbar that aligns to each container's edge and matches the light/dark scheme.

The chat/transcript scroller keeps a small (6px) gap between its native scrollbar and the panel's right edge, so the bar no longer sits flush against the wall.
