New library: the latchkey gateway as a workspace program reaches it. `gateway.py` holds the agent-to-gateway contract once (the `LATCHKEY_GATEWAY`, `LATCHKEY_GATEWAY_PASSWORD`, and `LATCHKEY_GATEWAY_PERMISSIONS_OVERRIDE` environment names and the two request headers) and `GatewayAccess`, which reads the environment, builds gateway URLs, and answers the headers every request carries. The chat app's `latchkey_gateway.py` and the shell's identical `gateway_access.py` are replaced by it; the file browser's client and the routines notifier take the names from here.
