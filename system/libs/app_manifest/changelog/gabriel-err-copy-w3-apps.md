Test helpers for an app page framed by the workspace shell: `shell_stand_in_page` frames a page and greets it with a handshake as the shell does (saying whether a bug report can open), keeping what the page posts, which `shell_messages` reads back by type, and answering its `shell:start-new-with-text` as the shell does when a test calls `answer_start_new_with_text`; `built_app_contract_source` serves the shell's built app contract to the page; `SHELL_HANDSHAKE_COUNTER_SCRIPT` tells a test when a page has had its handshake.

The pytest and playwright those helpers import are declared as the `testing` extra (`app-manifest[testing]`), which each test suite that uses them lists in its dev dependencies, as `app-schema[testing]` is.
