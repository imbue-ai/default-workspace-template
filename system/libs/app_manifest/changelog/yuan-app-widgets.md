The manifest and the registry row gain an optional `[widget]` table (`path`, `default_enabled = true`): a page of the app the desktop keeps on screen.

The `[widget]` table gains `tray` (default `false`): the page draws a tray form, so a client may put the widget in the taskbar's tray.

The `[widget]` table gains `toolbar` (default `false`): the page draws a toolbar form, so a client may put the widget in the taskbar's row.
