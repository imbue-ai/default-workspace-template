A launch path with `app_params` may also name a `text_param` (`app_params = {name = "app", display_name = "app_display_name"}` with `text_param = "message"`): the param the desktop fills with the text of a page's ask about an app. It must be one of the path's params and neither of the app params, and it does not make the path a launcher row. Every other pairing of `text_param`, `draft_param`, `mention_param` and `app_params` is still refused.
