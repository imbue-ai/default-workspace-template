A launch path's `app_params` may name a third param, `text` (`app_params = {name = "app", display_name = "app_display_name", text = "message"}`): the param the desktop fills with the text of a page's ask about an app. It must be one of the path's params and distinct from the other two. A path without it is the one "Chat about this app" runs; one with it is the one an ask runs. The registry row carries it.
