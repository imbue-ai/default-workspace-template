`app.toml` takes a `[theming]` table saying how far an app takes part in workspace themes: `mode = "tokens"` (the default: built from the shared parts and design tokens), `"parts"` (also declares named parts a theme may style, as `parts = [{ name, description }]`), or `"none"` (content with its own look). `registry.py` names the page kit's built paths, `SHELL_THEME_SCRIPT_PATH` and `SHELL_THEME_STYLESHEET_PATH`.
