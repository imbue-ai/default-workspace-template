`RegistryRow` reads the new `isolated_instance` key (`{app, kind, chat?}`, kind `change` or `mock`) a preview's or mock frame's row carries; absent on every other row.

A launch path may declare `chat_draft_params = {chat_id = "<param>", text = "<param>"}`, two of its params the desktop fills with the chat that booted a stopped preview or UI sketch and the text it drafts there when that window's "Ask in chat" is pressed. It stands alone like the other filled params, is never a launcher row, and `RegistryLaunchPath` reads it.
