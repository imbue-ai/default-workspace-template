New `app-manifest pass-scope --creation <type>:<name> [...] [--diff-base REF] [--out FILE]` writes the scope file for a harden pass over several creations: each creation's footprint, and one diff split into the changed files some creation accounts for and those none does. A creation is `app:<name or package>`, `skill:<directory>`, `service:<package>`, or `shared:<path under .agents/shared>`. A standalone service (and an app directory with no `app.toml` yet) is scoped by its directory and, as wiring, the program named after its package plus every `<name>-<role>` program; scope files gain the `service` creation type.
