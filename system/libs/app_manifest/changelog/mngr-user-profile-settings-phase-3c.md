An app's `app.toml` may declare `[[keybindings]]`: the actions the keyboard can trigger in it, each with an id, a label, and its default chords (`KeybindingAction`, with the `KeybindingActionId` and `KeybindingActionLabel` rules; ids unique within the manifest). `RegistryRow` carries them as `keybindings`, so the shell's Keyboard shortcuts dialog lists every app's actions from the registry whether or not the app is running (user-profile-state spec, phase 3C).
