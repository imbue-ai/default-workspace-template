`pass-scope --lead-ref` records what a branch merged in from the lead after leaving its line (a catch-up): `incoming_base` and `incoming`, the changed files of those lead commits, both empty for a branch that merged in nothing.

`select-tests --scope-file` runs, for each incoming file, only the suites and npm packages of the pass's own creations that it reaches through a declared dependency (a package, a `uv.lock` upgrade, a shared frontend package, or the root project's `pyproject.toml` / `conftest.py`), not the changed package's own suite, its other dependents, or the full root suite. A shared script in the pass gets the full root suite. When an incoming `uv.lock` cannot be compared, every creation's own suite runs, with a note `select-tests` now prints even when it selects nothing. A gate whose branch merged nothing from the lead selects exactly what it did before.
