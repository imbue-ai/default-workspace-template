Enabling GitHub sync now writes its own `system/supervisord.conf.d/github-sync.conf` rather than appending a `[program:github-sync]` block to the shared `system/supervisord.conf`, and disabling it deletes that file. `github-sync` was the second concurrent writer of the shared config, so this removes the last way that turning sync on could collide with an app being scaffolded at the same time.
