Restore the `X-Latchkey-Gateway-Permissions-Override` header in the global git wiring, now optional: when `LATCHKEY_GATEWAY_PERMISSIONS_OVERRIDE` is set (desktop-hosted gateways -- Docker/Lima/Modal workspaces) it is written as a second `extraHeader` entry alongside the password; when unset (remote-VPS gateways) only the password header is written, so both topologies work.

Timeline: the wiring sent both headers until commit 58e2f55c (2026-07-31) dropped the override while retiring the VPS secondary-gateway fallback. On desktop gateways the override is the per-agent authorization JWT and requests without it hit a deny-all default, so github-sync pushes in desktop workspaces failed with 403 despite approved grants. Unlike the pre-58e2f55c wiring, the override is no longer required -- its absence just means a VPS-style gateway.
