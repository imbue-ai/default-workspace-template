New test-only pytest plugin that keeps a session's temporary files where they can be run. A workspace container created before `/tmp` was mounted executable has it `noexec`, so a test's stub executable written under `tmp_path` and put on `PATH` was skipped, and the real tool it stood in for ran instead. One update's validation run reached the user's live `tmux` this way, killed their terminal sessions, and failed 110 tests. The plugin checks, before any test runs, that a file written under the temp root can run. If it can't, it moves temporary files to `/var/tmp`, or stops the session when the root was chosen explicitly.
