A routine's row (`RoutineRow`, so `routines list --format json`, `routines show --format json` and the Routines app's API alike) gains four fields about a routine an app owns, read from the directory its definition file is in rather than from the definition's `app` field: `owning_app` (the app's name as the workspace's record has it, else the directory's), `is_schedule_only` (only its schedule and its switch can be changed), `has_schedule_override` (the user's schedule is in place of the app's) and `app_schedule_text` (the app's own schedule in words meanwhile). `build_row` takes the apps' names by directory as a fifth argument.
