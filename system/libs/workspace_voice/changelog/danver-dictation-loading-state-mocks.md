`Dictation.prepare()` loads the engine (the first-time download) without opening the microphone and idles again when it is ready, so a composer can offer the download as a step of its own; it runs the load as `start()` does, with the same progress events and failure notice, and a dictation starting on another page of the workspace leaves it be. `DictationEvents.onEngineReady` fires from both `prepare()` and `start()` once the engine is loaded. `probeEngineDownload` tells a page whether the speech model is already on this device: the device picked as the worker picks it (`pickDevice`, now in `devicePick.ts` with the navigator as a parameter) and every pinned file of that variant looked for in the page's own Cache Storage, with the size the download would be; `PinnedFileStore` gains `has(url)` for it. `createReadyChime` plays two short bell tones through the Web Audio API, woken from a user gesture and played when dictation starts listening.
