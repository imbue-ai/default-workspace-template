`Dictation.prepare()` loads the engine (the first-time download) without opening the microphone and idles again when it is ready, so a composer can offer the download as a step of its own; it runs the load as `start()` does, with the same progress events and failure notice, and a dictation starting on another page of the workspace leaves it be. `DictationEvents.onEngineReady` fires from both `prepare()` and `start()` once the engine is loaded. `probeEngineDownload` tells a page whether the speech model is already on this device: the device picked as the worker picks it (`pickDevice`, now in `devicePick.ts` with the navigator as a parameter) and every pinned file of that variant looked for in the page's own Cache Storage, with the size the download would be; `PinnedFileStore` gains `has(url)` for it. `createReadyChime` plays two short bell tones through the Web Audio API, woken from a user gesture and played when dictation starts listening.

`speechModel.ts` is the page's speech models: one managed load per engine, held in a TanStack Query cache (the new `@tanstack/query-core` dependency). `getSpeechModels()` is the page's one instance and `getVoiceQueryClient()` its query client. A surface observes an engine's load with a `QueryObserver` over `loadQueryOptions(options)` given `enabled: false`, asks for it with `request(options)` (one load runs however many ask, a load in flight is joined, and a loaded model is answered from the cache), reads the download's progress under `progressQueryKey(options)`, finds out what the workspace's worker already holds with `discover(options, isDownloaded)`, and transcribes on `engine(options)`. The engine worker is the authority, and is what keeps the workspace's pages in step: it now tells each port what it already holds as the port connects (a `hello` message); `EngineWorkerClient` gains `onMessage` (every message the worker sends the port, among them each step of a load another page asked for) and `onLost` (the worker taken for lost, which the page's own `dispose` is not); and the speech models mirror what the port hears into the cache, so a page learns a model came ready whichever page asked for it. A page also hears on a BroadcastChannel that another page asked for a model, and connects to hear the worker load it. `isEngineWorkerShared()` says whether the realm's worker is the one every page shares. `Dictation` is as it was, loading through a client of its own.
