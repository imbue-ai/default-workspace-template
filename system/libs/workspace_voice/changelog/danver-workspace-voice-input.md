New: `workspace_voice`, dictation for the workspace's pages (the workspace-voice-input spec in the mngr repository, implementation step 2). On-device speech recognition behind one engine interface, with Moonshine Base as the first and default engine: an engine registry (`voice_models.json`) pinning every file to a Hugging Face commit with its size and SHA-256; a downloader that checks each file against its pinned size and hash and keeps the checked files in the browser's Cache Storage for the workspace's origin (one variant, checked again on every read, evicted by the browser under storage pressure); an engine worker, one SharedWorker per workspace origin and engine that every chat page shares (a dedicated worker where the browser has none), which picks WebGPU or WebAssembly, transcribes one job at a time, and keeps the engine loaded for as long as a page of the workspace is open; the transformers.js adapter with the runtime's caches off; Silero VAD v5 through vad-web with Sculptor's tuning; Sculptor's streaming turn (commit-and-slice, so dictation has no length limit and each preview costs the same); one inference lane with commits ahead of previews, a failed commit retried twice, and words held for Retry or Discard when it keeps failing; the dictation controller a composer drives; the live span that lands words at the caret, fitted to the sentence around them; and the vite plugin that ships the runtime's WebAssembly, the detector's worklet, and the detector's model with an app's build.
