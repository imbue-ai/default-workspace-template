New library: one-way markers recording what a workspace's owner has already done (finished the tour, used the phone layout, started a second chat, filed a permission request, been shown where connections live, started an app build), one empty file each under `data/.state/onboarding_activity/`. `mark`, `is_marked` and `marked_at` set and read them, and a reader can tell a marker that is not set from one that could not be read. The chat's activity suggestions read them.
