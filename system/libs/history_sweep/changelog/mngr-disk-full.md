New `history-sweep` library and command: frees the disk a deleted chat leaves behind. A deleted chat's claude session files in the account folders are removed at once (mngr's preserved archive holds the same transcript), and the preserved archive 30 days after the delete. A chat still listed, a present agent (archived hand-off segments included) and any session a present or listed agent still names are never touched, and an unreadable chat record stops the sweep before it removes anything.
