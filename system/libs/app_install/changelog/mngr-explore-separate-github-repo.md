New library and command: `app-install`, which registers the apps a workspace's agent builds and keeps the files the workspace needs for them in step with their manifests. `add <package>` allocates a port, writes the app's record (`system/config/apps/<name>.toml`) and generates its supervisord program files and skill links; `regenerate` rewrites them after a manifest changes and gives a new port to an app that shares one; `check` fails when a generated file was edited by hand or two apps would collide; `uninstall <name>` removes an app with its generated files and its programs while keeping its stored data and secret files; `install <url>` adds an app from its published repository (read anonymously, or through the workspace's latchkey gateway when the repository is private) with `git subtree add --squash`, lands it registered and generated as one commit, starts it, and reports what it still needs from the user; `update <name>` merges a newer version over the workspace's own changes after copying the app's data aside, and stops with the files and a waiting worktree when the app's code conflicts or its checks fail (`--continue` finishes it); `migrate <package>` converts an app built before this layout, moving the skills and routines it owns into its directory, or leaves it untouched and says why; `list` prints the records. Every run ends in one JSON line.
