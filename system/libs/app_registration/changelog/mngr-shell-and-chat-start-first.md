`forward_port.py --announce` also appends the registered row's `service_registered` event to the services stream (`$MNGR_AGENT_STATE_DIR/events/services/events.jsonl`), in the same shape the shell writes. The minds desktop and `mngr forward` can then route to the app before the shell has started and read the registry. A row whose latest event in the stream already says the same is not written again, so an app that restarts in a loop does not grow the stream. Outside a workspace (no agent state directory) the flag only registers. It cannot be combined with `--remove`. The new `app_registration.announcement` module does the writing and is stdlib-only, like the rest of the package.
