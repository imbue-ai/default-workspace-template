# Retro themes

The looks a desktop can wear besides the standard one, chosen in Desktop settings > Theme and stored per desktop in the shell's `desktop_themes.json`: **Classic Mac**, built on [system.css](https://sakofchit.github.io/system.css/), and **Windows 2000**, built on [win95.css](https://alexbsoft.github.io/win95.css/). The shell puts the theme of the desktop on screen onto `<html data-ui-theme="...">` (`uiTheme.ts`), and each stylesheet here is scoped to its own value, so the standard look matches none of them.

- `vendor/<theme>/`: the library, rewritten by `scripts/vendor-retro-themes.mjs` so every rule is scoped to its theme, with the fonts and images it uses and its license. Generated: rerun the script rather than editing it. The script pins each source (system.css by npm version and digest, win95.css by commit and digest) and lists the few library rules it drops or trims because they fight the desktop's own layout, each with its reason.

- `mac-classic.css`, `windows-2000.css`: import the library unlayered, so its components win over utility classes on the elements that carry its class names, then remap the design tokens (colors, fonts, radii, shadows, and the desk metrics such as the title bar height) and fill in what the library has no component for. The desktop opts into a library component by carrying its class name, which does nothing outside the theme: `btn` (every shared button), `card` and `card-header`/`header-inactive` (windows and their captions, win95.css), `.window`/`.title-bar`/`title` (system.css's window, which the desktop's class names already match), `modal-content`/`standard-dialog` with `modal-header`/`modal-title` (dialogs), `dropdown-menu`/`dropdown-item` (menus), `.taskbar` and `form-95` (the taskbar and the launcher field).

- `icons/<theme>/<app>.png`: 32x32 pixel-art app icons, drawn with [Retro Diffusion](https://retrodiffusion.ai) by `scripts/generate-retro-icons.mjs`; `app.png` is the icon for any app without one of its own. To draw one for a new app, add it to `ICONS` in that script and run it with `RETRODIFFUSION_API_KEY` set and `--only <app>` (`--variants 2` draws two to choose from).

To add a theme: add it to `UiTheme`/`UI_THEMES` in `uiTheme.ts` and `DesktopTheme` in the shell's `primitives.py`, give it a stylesheet here imported by the shell's `style.css`, vendor its library in the script, and draw its icons.
