The element context menu (`docs/system/blueprint/element-reference-menu/`): `element_reference.ts` describes a right-clicked element as JSON (its tag, id, classes, attributes, text, a selector checked to match it alone, its ancestors, its markup, the click and the viewport, and the app, window, and page from the shell's handshake), `context_menu_rows.ts` builds the menu's rows (Cut, Copy, Paste, Select All, the link and image rows, then "Copy path to element", "Explain this element...", "Modify this element..."), and `context_menu.ts` is the installer every page runs, with a framework-free renderer for pages without Mithril and `components/contextMenuOpener.ts` for pages with it. `app_contract.ts` gains `draftText` (`shell:draft-text`) and the handshake's `app`.
