The element context menu (`docs/system/blueprint/element-reference-menu/`): `element_reference.ts` describes a right-clicked element as JSON under a random `REF-<id>` (its tag, id, classes, attributes, a selector checked to match it alone, the selection and field value, the click and the viewport, and the app, window, and page from the shell's handshake), `context_menu_rows.ts` builds the menu's rows (Cut, Copy, Paste, Select All, the link and image rows, then "Copy reference", "Explain...", "Modify..."), and `context_menu.ts` is the installer every page runs, with a framework-free renderer for pages without Mithril and `components/contextMenuOpener.ts` for pages with it. `app_contract.ts` gains `draftText` (`shell:draft-text`) and the handshake's `app`.
