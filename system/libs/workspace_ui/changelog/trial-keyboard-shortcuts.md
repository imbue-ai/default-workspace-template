`keybindings.ts` gains `chordDisplayLabel`, which writes a canonical chord the way a menu does ("⇧⌘N" on an Apple platform, "Ctrl+Shift+N" elsewhere), `chordKeycapLabels`, the separate keys it is built from, `chordSpokenLabel`, which names a chord in words ("Shift+Command+N") for tooltips and screen readers, and `isApplePlatform`, the platform check the shell's launcher already used.

`embed.ts` exports `KEYBOARD_SHORTCUTS_PAGE` (`minds:keyboard-shortcuts-page`, embed contract v15), probed like the other newer types, with which the shell's keyboard shortcuts page reports its height and whether its recorder is listening.
