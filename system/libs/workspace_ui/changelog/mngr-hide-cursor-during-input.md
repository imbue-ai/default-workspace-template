The shared library gains `hideCursorWhileTyping.ts`: a page installs it once on its document, and the mouse pointer hides while a keystroke inserts or deletes text in a focused field (a writable input, textarea, or editable region), coming back on the first real pointer movement, press, or scroll. Shortcuts such as Cmd+C, bare modifier presses, and keys pressed outside a field leave the pointer alone. `base.css` carries the matching rule, `html.typing-hides-cursor * { cursor: none !important }`. Because `cursor` never crosses a frame boundary, every page installs it for itself.
