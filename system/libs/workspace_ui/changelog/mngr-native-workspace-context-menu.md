`installElementContextMenu` leaves some right-clicks to the Imbue Studio desktop app's native menu when the app says it draws one, through the handshake's new `drawsContextMenus` (read by `readHandshake` into `ShellHandshake`) or the new `hasNativeMenu` option. Those are a right-click on text being edited, on the selection under the pointer, on a link the page has no rows of its own for, and any with Shift held. Every other right-click opens the page's menu as before, and so does every right-click where no native menu is announced.

An image's menu gains "Copy image", which puts the image on the clipboard as a PNG. It is offered for a loaded image whose pixels the page can read: one of the page's own origin or inline in it, or one loaded with CORS.
