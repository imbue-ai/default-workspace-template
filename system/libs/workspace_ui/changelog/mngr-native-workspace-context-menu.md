`installElementContextMenu` leaves a right-click to the Imbue Studio desktop app's native menu when the app says it draws it: the handshake's new `drawsContextMenus` (read by `readHandshake` into `ShellHandshake`), or the new `isDrawnByHost` option. The installer then opens nothing and keeps the right-click's rows (the page's own, "Open link", and the reference rows) on the page's `__studioContextMenu` bridge. The app reads them with `sections()` and runs a pick with `select(key)`, which waits for the page to take focus first. A right-click with Shift held is always left to the browser's own menu.

A page's own rows (`extraRows`) can now be check rows (`isChecked`, `onToggle`) and submenus of actions and check rows, one level deep, as well as actions and dividers. The native menu shows them as checkboxes and submenus; the framework-free renderer apps load from `/_static/context_menu.js` opens a submenu as a flyout beside its row and draws check marks and red danger rows. A row may name an SF Symbol in the new `symbol` field, which the native menu shows on macOS; the reference rows name `doc.on.doc`, `questionmark.bubble`, and `pencil`. A page's own `open` now also receives the right-clicked target.
