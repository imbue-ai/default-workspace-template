`keybindings.ts` reads chords per platform. `meta` is the primary modifier: the Command key on a Mac and the Control key on Windows and Linux, where it is drawn as "Ctrl" and the Windows key is no modifier at all; `ctrl` stays the Mac's Control key, which has no partner elsewhere, so `isChordHiddenOn` hides a chord holding it off a Mac, and `readsChordAsApple` names such a chord with the Mac's symbols there ("⌃K"). `chordFromKeydown` takes the platform (`detectChordPlatform` reads it off the browser); while Option is held it reads every printable key from the physical key as the US layout types it, since a Mac composes a character for it (⌥⌘] records as `alt+meta+]` everywhere), and it reads the Space bar from the physical key always.

The library mirrors the desktop's per-platform chord lists, pinned by the contract test: `REFUSED_CHORDS` (Ctrl+Alt+Del, `isRefusedChord`), `BROWSER_RESERVED_CHORDS`, `OS_KEPT_CHORDS` and `HOST_ACTED_CHORDS`; `chordNotices` writes the non-blocking warnings for a chord on a platform (browsers keep it, the OS is known to keep it, Imbue Studio takes it from the OS), the same wherever the workspace runs. `isWorkspaceWideChord` says whether a chord may fire anywhere in the workspace.

The app contract carries the workspace-wide shortcuts (the keyboard-shortcuts spec in the mngr repo, section 6.1): `shell:workspace-chords` gives a page their chords, a keystroke spelling one is stopped in the capture phase and handed to the shell as `shell:shortcut`, and `shell:chord` hands a page a chord the desktop app took from the OS for it (`onChord`). A page whose program owns every key passes `ownsKeys: true`. `embed.ts` mirrors the desktop app's relays: `minds:shell-shortcuts`, `minds:run-shortcut`, `minds:run-chord` and `minds:record-chord`.
