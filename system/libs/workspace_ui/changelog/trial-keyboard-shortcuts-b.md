`keybindings.ts` reads chords per platform. `meta` is the primary modifier: the Command key on a Mac and the Control key on Windows and Linux, where it is drawn as "Ctrl" and the Windows key is no modifier at all; `ctrl` stays the Mac's Control key, which has no partner elsewhere, so `isChordHiddenIn` hides a chord holding it off a Mac. `chordFromKeydown` and the matchers take the platform (`detectChordPlatform` reads it off the browser), and read a letter or digit from the physical key while Option is held, since a Mac composes a character for it.

The library mirrors the desktop's per-platform chord lists, pinned by the contract test: `REFUSED_CHORDS` (Ctrl+Alt+Del, `isRefusedChord`), `BROWSER_RESERVED_CHORDS` (hidden by `isChordHiddenIn` when the workspace runs in a browser), `OS_KEPT_CHORDS` and `HOST_ACTED_CHORDS`; `chordNotices` writes the non-blocking warnings for a chord in a context (a browser would keep it, the OS is known to keep it, the desktop app takes it from the OS). `isWorkspaceWideChord` says whether a chord may fire anywhere in the workspace.
