The app contract module offers `mountFailureRemedies(root, connection, { failure, request, askLabel })`: `FailureRemedies` for a page drawn without Mithril. It draws the ask for a failure that owes help once a shell greets the page ("Asking an agent…" until the shell answers), a refused ask under it with its own "See details", "Draft it in a chat", and a "Report a bug" that files the page's failure with the ask's, and answers a `redraw()` the page calls on each handshake. The button labels (`ASK_AGENT_TO_FIX_LABEL`, `ASKING_AN_AGENT_LABEL`, `DRAFT_ASK_LABEL`, `REPORT_A_BUG_LABEL`) are declared in the module, which imports nothing; `FailureButtons` and `models/failure` export them as before.
