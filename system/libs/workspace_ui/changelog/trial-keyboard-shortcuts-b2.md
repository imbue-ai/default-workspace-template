`embed.ts` mirrors the desktop app's two messages for Imbue Studio's own shortcuts (the keyboard-shortcuts spec in the mngr repo, section 8.3): `minds:chrome-shortcuts`, which hands the framed keyboard shortcuts page the shortcuts with their defaults, and `minds:save-chrome-shortcut`, with which the page asks the desktop app to save one. `chordNotices` takes `isBrowserReservedNoticed: false` for a binding no browser runs, which leaves out the warning that a browser keeps the chord.
