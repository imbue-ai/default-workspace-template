`describeRequestErrorKind` now recognises mngr's `submission_unconfirmed` send-failure kind (the message was typed and Enter sent, but nothing confirmed the agent took it), so the chat can give it its own notice. mngr's `agent_not_found` still reads as `unknown`: nothing was typed, so the default Retry fits it. `isUnansweredRequest` tells a request that got no answer from the app it was sent to (no HTTP response, or a gateway's 502 or 504 with no detail of the app's own) from one the app answered, so a caller can repeat a request that is safe to repeat.
