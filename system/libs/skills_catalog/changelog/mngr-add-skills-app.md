A new library, `skills_catalog`: every skill under `.agents/skills/` (the one folder claude, codex, pi, opencode and antigravity all read), read fresh on each call. Each `SKILL.md` is parsed with mngr's own reader (`imbue.mngr.utils.agent_skills`), and each skill carries its frontmatter author, a `source` (`STUDIO` for author `imbue`, else `INSTALLED` when `.agents/skills-lock.json` or the root `skills-lock.json` that `npx skills add` writes lists it, else `WORKSPACE`), an `audience` (`SYSTEM` for `metadata.audience: system`, else `PEOPLE`), a `last_updated_at` that counts unsaved edits, and its folder and the skills folder as absolute paths.
