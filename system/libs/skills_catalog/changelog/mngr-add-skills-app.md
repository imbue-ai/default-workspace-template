A new library, `skills_catalog`: every skill under `.agents/skills/` (the one folder claude, codex, pi, opencode and antigravity all read), read fresh on each call. Each skill's `SKILL.md` is parsed with mngr's own reader (`imbue.mngr.utils.agent_skills`) and checked against the agentskills.io layout, and its origin is classified from the git history and the skills lock files: built in, built in and changed here, installed (recorded in `.agents/skills-lock.json` or the root `skills-lock.json` that `npx skills add` writes), made here, or not saved yet. A commit counts as the template's when it is the root commit or on the upstream side of an `update-self:` merge; the history is read once per HEAD. The listing names the skills folder, and a skill's page its own folder, as absolute paths. Each skill also carries its frontmatter author, a `source` (`STUDIO` for author `imbue`, else `INSTALLED` when a lock file lists it, else `WORKSPACE`), and a `last_updated_at` that counts unsaved edits.
