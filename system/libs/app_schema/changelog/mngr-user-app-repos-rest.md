`app-schema` is how an app built in a workspace gets the workspace's own app SDK, for as long as the app lives there: the app moves to a new SDK with the workspace, and no release of the SDK is needed for it. Publishing an app replaces the dependency with one on the released `imbue-app-sdk`. The README, the comments on the package's dependencies and the `CLEANUP` note on its modules say so, and that an app written before the SDK keeps importing this package's names until it is published; nothing the package exports changed.
