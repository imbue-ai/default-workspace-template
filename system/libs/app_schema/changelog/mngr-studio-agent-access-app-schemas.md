New library: an app's self-description. `register_api_schema_route` serves an OpenAPI 3.1 document built from the app's Flask routes, Flask's own static routes (the app's and a blueprint's) left out (a docstring's first paragraph as the operation's summary and the whole of it as its description, a blank one counting as none; path parameters; and optional pydantic request and response models) at the path the manifest names in `api_schema_path`; `assert_api_schema_describes_app` is what each app's tests assert about it, and it fails for a route whose view has no docstring, so a route cannot be added without saying what it does.
