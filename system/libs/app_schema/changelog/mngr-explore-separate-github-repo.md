`app_schema` is now a thin package that re-exports the app SDK (`imbue.app_sdk`, the `imbue-app-sdk` package), which holds the code that used to live here. Each module offers the SDK's own objects under their old names, so an app built before the SDK keeps working unchanged; `app_schema.testing` maps to `imbue.app_sdk.app_testing`. Nothing built in imports this package any more, and it goes away once every supported workspace has converted its apps.
