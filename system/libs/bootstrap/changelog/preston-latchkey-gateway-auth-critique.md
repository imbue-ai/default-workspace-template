The boot-time timezone fetch through the latchkey gateway sends the `X-Latchkey-Gateway-Permissions-Override` header again when `LATCHKEY_GATEWAY_PERMISSIONS_OVERRIDE` is set, fixing the fetch on desktop-hosted gateways (which deny override-less requests via a deny-all default and left containers on UTC). The header is optional so VPS gateways, which omit the env var, keep working. The override had been sent until commit 58e2f55c (2026-07-31) removed it along with the retired VPS secondary-gateway fallback.
