Each boot runs `mngr upgrade` with the workspace's own mngr on every stopped local agent before anything starts one, so chats and workers an older mngr created get the current mngr-generated hooks and scripts and stay stopped. A running agent is never touched. The new step (`upgrade_agents`) is skipped while an update apply is in flight and when the boot's venv sync failed; it is bounded, logs each agent's outcome, and never stops the boot.
