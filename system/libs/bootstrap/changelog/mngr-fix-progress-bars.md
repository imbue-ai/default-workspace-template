The bootstrap announces each step it runs as an event under the agent's state directory (`events/bootstrap/events.jsonl`, one JSON line per event under the standard envelope, appended to on every boot): a `bootstrap_step_started` and a `bootstrap_step_completed` (with the step's duration) for each of its steps, in order, and a final `bootstrap_completed` as it hands off to supervisord. The desktop that created the workspace tails these while it waits for the system interface, so its progress bar moves through the boot instead of sitting on one long "waiting" step. Outside an agent (no `MNGR_AGENT_STATE_DIR`) nothing is written and the boot is unchanged.
