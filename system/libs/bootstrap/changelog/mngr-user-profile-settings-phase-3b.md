The bootstrap no longer fetches the user's timezone from the Imbue Studio desktop at boot (user-profile-state spec, section 8.4): the client that creates a workspace now writes `data/.state/user_timezone` once, and the boot's `set_timezone` step just applies that file -- the same file the old fetch cached, so workspaces created by older clients keep their zone. Drops the bootstrap's `tenacity` dependency, which only the fetch used.
