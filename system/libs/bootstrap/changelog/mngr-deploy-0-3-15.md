The bootstrap now migrates root-homed claude state into the current home tree at boot. Workspaces created before the /home/user home layout (pre-minds-v0.3.16 lima and modal creates) kept claude's chat transcripts, sign-in credentials, settings, plugins, and global `.claude.json` under `/root`; updating such a workspace repoints root's home at /home/user, after which claude resolved a freshly created empty `~/.claude` and the workspace looked wiped (no history, sign-in prompt). The migration runs before supervisord and the initial chat agent, fires only when the legacy dir holds real user state (transcripts or credentials) and the new location holds no transcripts of its own, never overwrites a lived-in new home, and is idempotent -- so it heals both a workspace at the moment update-self restarts its services and one an earlier update already stranded.
