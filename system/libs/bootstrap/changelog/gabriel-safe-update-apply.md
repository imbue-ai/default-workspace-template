Bootstrap checks for an interrupted update apply at container start (the marker under `data/.state/update-apply/`) and rolls it back before the venv converge and before any service or agent starts, via the dependency-free `update_self.py recover --if-stale --no-restart` (git restores plus pre-apply snapshot copies -- no network, no package manager, no working mngr needed). On a real rollback it then wakes and messages the DRI agent the marker names, best-effort, so someone verifies state and talks to the user about retrying.
