- Three boot steps carry the `# own-process` markers the launch rules now require. Update recovery through `update_self.py` is `other-tier`: it runs under the system `python3` with no venv, because a broken venv may be what the interrupted update left. `routines migrate-cron` and `env-converge run --phase fast` are `other-tree`: they run after the boot re-syncs the venv this process started from, so an import would load the venv as it was at start.
