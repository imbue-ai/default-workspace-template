- When a restart interrupts an update and the boot-time recovery rolls it back, the agent that was driving it is now woken with a note the chat shows as a single "Workspace update not applied" notice: the update stopped part-way when the workspace restarted, the workspace was put back the way it was, and the user can ask to try it again. Before, the agent's instructions appeared in the chat as if the user had typed them. A rollback that could not put everything back says instead that the workspace may not work fully until it is repaired, and an interrupted apply that was not an update (a critical app's change) is described as a change to the workspace. The note uses an outcome the chat app has shown since minds-v0.9.0, because the chat app that reads it is the rolled-back one.
