- When a restart interrupts an update and the boot-time recovery rolls it back, the agent that was driving it is now woken with a note the chat shows as a single notice line: the update stopped part-way when the workspace restarted, the workspace was put back the way it was, and the user can ask to try it again. Before, the agent's instructions appeared in the chat as if the user had typed them. A rollback that could not put everything back gets its own line, saying the workspace may not work fully until it is repaired, and an interrupted critical-app change is described as a change to the workspace's apps rather than an update.
