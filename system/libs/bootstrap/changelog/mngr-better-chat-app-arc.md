Phase 9 of the workspace app model (the migration): the bootstrap runs `system/scripts/migrate_workspace_layouts.py run` at every boot, after an interrupted update's rollback (so the restored tree's script is the one that runs) and before supervisord starts the shell that reads its output. The script is guarded by its own marker and never destructive, so the call costs nothing once the workspace is migrated; a failure is logged and never blocks boot.
