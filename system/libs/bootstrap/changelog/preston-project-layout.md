The workspace's first chat now displays as "Chat 1" -- the same series the New Tab launcher continues ("Chat 2", ...) -- instead of wearing the workspace's name. The mngr-level agent keeps its host-derived name (agent names cannot hold spaces); the bootstrap files "Chat 1" into the machine-wide member-title store at create time, exactly as the launcher titles the chats it creates. First boot only, so existing workspaces keep their current chat name.
