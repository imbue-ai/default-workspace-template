- The bootstrap gains a `latchkey_gateway_env` step, run after the timezone step and before supervisord is exec'd: when `$MNGR_HOST_DIR/env` names no `LATCHKEY_GATEWAY` (a web-created workspace), it appends `LATCHKEY_GATEWAY=http://host.docker.internal:1989`, a freshly generated `LATCHKEY_GATEWAY_PASSWORD` (32 random bytes, base64) and `LATCHKEY_DISABLE_COUNTING=1` to the file and adds the three to the environment it launches supervisord with (its own process environment is left alone), so every supervised service inherits, and every later chat agent reads from the file, the VM gateway's address and the password the web chrome later reads over owner-exec. A file that already names a gateway (a desktop-created workspace) is left untouched, and a bare dev run without a host dir skips the step. The step id is part of the boot-progress event contract.
