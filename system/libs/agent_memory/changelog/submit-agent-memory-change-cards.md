New library for the agent's memory (`data/memories/`, Claude's `autoMemoryDirectory`). `notes` reads and writes the notes and their index (`MEMORY.md`), and renders a file as a person reads it (a note's summary and text without its frontmatter; the index as "Title — summary" lines). `changes` is stdlib-only: per chat session it records one change per note per turn (the note with its own index lines; index lines that point at no note get their own change) under `data/.apps/chat/memory_changes/`, and `ChangeLog.undo` restores only that change's files and index lines, refusing unless forced when they were changed again since. Claude's memory change-log hooks and the chat app import it.
