New `command_words(segment)` returns the words of the command a segment runs, past leading `VAR=value` assignments and the shell keywords that can precede it (`do`, `then`, `elif`, `{`, ...). The pipe-into-`head`/`tail` guard and the new foreground-sleep guard (`agent_block_foreground_sleep_check.py`) both use it, so they agree on which command a segment runs; the pipe guard now also sees through `elif` and `{`. The README and the module docstring list the sleep guard among the gates that import this parser under a bare `python3`.
