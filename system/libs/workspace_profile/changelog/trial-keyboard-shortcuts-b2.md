The README says which default chords `load_app_keybinding_actions` refuses (one off the grammar, Ctrl+Alt+Del, or a workspace-wide action's chord typing could trigger) and that the grammar refuses Ctrl+Alt+Del. An action holds at most 16 chords (`MAX_CHORDS_PER_ACTION`, the most the desktop's embed contract carries for one action): a keybindings value assigning more is refused, a manifest declaring more defaults fails to load, and resolution keeps an older stored assignment's first 16.
