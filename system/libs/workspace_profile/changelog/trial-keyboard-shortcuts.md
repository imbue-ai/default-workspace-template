`resolve_app_keybindings` takes `is_user_override_applied` and `is_unsent_applied` (both true by default). Passed false, they leave out the requester's own override in this workspace (what a reset restores) and, with it, the owner's undelivered "everywhere" changes (what a discard restores); the shell's keyboard shortcuts catalog uses them to answer `reset_chords` and `restored_chords`.
