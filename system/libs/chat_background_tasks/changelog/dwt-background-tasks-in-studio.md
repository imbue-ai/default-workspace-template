New stdlib-only library holding the background tasks each chat waits on: the marker files under `data/.apps/chat/background_tasks/<chat-id>/` and their liveness rules (`markers`), and the chat-app-first listing with its fallback to the files (`listing`). A task's `source` is `run_in_background` or `harness`, and a harness task names its harness (`claude`). The chat app, the shell's avatar, `memory_candidates.py`, `create_worker.py`, `system/scripts/background_tasks.py` and `system/scripts/claude_background_task_hooks.py` import it.
