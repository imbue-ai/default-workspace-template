The request identity and the provenance check moved to the app SDK (`imbue.app_sdk.identity`). `workspace_layout.identity` re-exports it for apps written before the SDK, and `workspace_layout.primitives` takes `UserId`, `ParticipantKey`, and the owner and workspace-agent keys from the SDK, so there is one definition of each. A user id or participant key off its rule now raises the SDK's `InvalidIdentityValueError` (re-exported from `workspace_layout.errors`) rather than `InvalidLayoutValueError`; both are `ValueError`s.
