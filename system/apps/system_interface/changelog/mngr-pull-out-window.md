A window can be pulled out of the desktop into a desktop window of the Mind app's own.

Drag a window's title bar past the edge of the Mind window and it comes out: the app opens a window of its own under the cursor holding that page, and the desktop keeps a ghost of the window where it was, with "Show" (raise or reopen that window) and "Bring back". "Open in its own window" in the window menu does the same without a drag; a pulled-out window's taskbar entry is marked and offers "Show" and "Bring back to desktop" in its menu. Dragging back inside before letting go, or pressing Escape, puts the window back. The desktop's shell is the one writer during a drag: it saves the detach the moment the window goes out (with the drag's raise, so the window keeps its place on top) and the return the moment it comes back, and the pulled-out window's own view of the desktop only reads, waiting for that word rather than writing a stale layout over it; a return dropped back onto the desktop through the app goes through the desktop's shell too, so a quick drop no longer leaves a ghost behind. The pulled-out window's own view still takes the window back when no desktop is open to do it, reporting the return only once it is saved. The gesture and the menu item appear only where the app can make windows (the Mind desktop app), never in a plain browser.

Under the hood: placements gain `is_detached` (a file without it reads as attached; every verb that shows a window clears it), the shell gains a solo mode (`/?solo=<window-id>`) that shows one window edge to edge for the app's own window, and the shell announces every title-bar drag to the app (`window-drag-started`), which watches the cursor and says when the window is out, back in, or released (`tear-out`), since the shell's own pointer events stop at the app window's edge on some platforms; and the shared embed library learns the pull-out set of the minds embed contract (`pop-out-window`, `window-drag-started`, `window-drag-ended`, `detached-windows`, `embedder-capabilities`, `reattach-window`, `tear-out`), probed with fallbacks so the shell builds against the pinned older contract too. Design: mngr's `specs/pull-out-window/spec.md`.
