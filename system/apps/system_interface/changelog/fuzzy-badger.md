Opening a chat's notification now lands in the full chat window (the chat list beside the chat) instead of a new single-chat window. A chat window that already has the chat selected is brought forward; otherwise the chat is selected in the chat window you have on screen on this desktop (else the pinned one), and a new window, if one is still needed, opens on the chat list with the chat selected. Before, a chat selected in the chat list never counted as already showing, and the pinned chat window was sent a path it could not read, which cleared its selection.
