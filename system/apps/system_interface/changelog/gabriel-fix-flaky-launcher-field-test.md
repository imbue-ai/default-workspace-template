The launcher menu now moves in the same frame as the launcher field when the field grows or clears. Before, the menu followed one frame late: for that frame a grown field overlapped the menu's foot, and a cleared field left a gap under it. That lag also made `test_the_launcher_field_grows_upward_out_of_its_row_and_lifts_the_menu` flaky, because it reads the menu's position right after the field changes.
