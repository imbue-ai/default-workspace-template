Fixed the workspace losing the bottom of the chat -- the model picker, the agent-terminal button and the harness sign-in button under the composer -- whenever the window it runs in got shorter. The row holding the rail and the dock could grow with the window but never shrink back, so the dock stayed laid out at its old height and everything it positions in pixels (the panes, and the pages shown in them) hung below the bottom edge, with no way to scroll or resize the strip back into view. The Minds app hits this without the user touching the window: its recovery band takes about fifty pixels off the top of the frame the workspace runs in, so a machine reporting a lost connection would also silently swallow the row under the composer. An e2e test now shrinks the window and asserts that row stays inside it.
