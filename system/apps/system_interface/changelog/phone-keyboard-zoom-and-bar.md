On a phone, tapping a text field no longer zooms the page in. iOS Safari zoomed into any field set smaller than 16px (the chat composer, the start sheet) and stayed zoomed after the field let go; the shell's viewport now carries `maximum-scale=1`, which stops that in every app's page. The shell can no longer be pinch-zoomed on phones.

While a phone's soft keyboard is up, the bottom bar steps aside so the shown page reaches down to the keyboard, and it comes back when the keyboard goes. The keyboard is read off the viewports (a touch screen, a field or an app's page focused, and a visual viewport as wide as the layout and more than a fifth shorter), so a mouse-driven window, a pinch zoom, or a hardware keyboard keeps the bar.
