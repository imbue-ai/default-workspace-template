The desktop launcher's Enter now sends a typed text to the main chat: the chat app lists "Send to main chat" first among its text rows, ahead of "New Chat" (now Cmd+Enter, or Ctrl+Enter off a Mac). The inventory test expects the new row.


"Design your own..." in the avatar chooser now drafts its prompt into the main chat instead of whichever chat the pinned window shows: a launch into a window can leave out the window's page (`sends_window_path: false` on the target), so the app puts the text where a text with no chat of its own goes.
