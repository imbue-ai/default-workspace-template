The Claude sign-in modal's "Sign in with Imbue" deep link is now keyed by the workspace's id (its `system-services` agent id, read from the `is_primary`-labeled agent's state) instead of the machine's host id, so the link keeps working if the workspace ever changes machines. The machine's host id remains the fallback coordinate when the agent state is unreadable, and the desktop app dual-accepts both. The status field carrying it is renamed `workspace_host_id` -> `workspace_id` (internal to the system interface and its own frontend).
