A chat asking to have its tab surfaced (the `assist` label, or the new purpose-neutral `auto_open` label) is now shown its tab once, reliably, instead of only if a browser happened to be connected the instant it appeared. Before, the open was a broadcast to whoever was connected: a chat created from outside the workspace -- the minds app's update flow -- appeared while the user was still on their way in, so the open went to nobody and the tab never showed. The open is now held until a client has registered, and which chats have been shown is remembered on disk beside the saved layouts, so the interface that comes up after an update's own restart neither re-pops a tab the previous one surfaced nor loses one it never got to show: a recent chat found at startup that no client has seen (an update run overnight) is shown on the next connection, while older ones are left as the saved layout has them.\n
