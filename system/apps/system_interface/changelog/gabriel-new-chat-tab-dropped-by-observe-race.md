A tab no longer closes because its app briefly stopped listing the instance. Only a delete through the shell takes an instance out of the project tab sets and saved layouts now. A tab whose instance is missing from its app's list stays open with a dashed status dot and a pane that says it can't be found right now: it may come back on its own (the tab then reconnects) or it may have been removed, with a suggestion to ask an agent if that seems wrong and a Close tab button. No page is loaded while it is missing, so the tab makes no requests. Before this, a new chat's tab closed a few seconds after the chat was created whenever the chat app's list lagged behind the create.
