A tab no longer closes because its app briefly stopped listing the instance. Only a delete through the shell takes an instance out of the project tab sets and saved layouts now; a tab whose instance is missing from its app's list stays open, shows the instance as unavailable (a dashed status dot and a placeholder, with no page loaded, so it makes no requests), and loads the page again once the app lists the instance. Before this, a new chat's tab closed a few seconds after the chat was created whenever the chat app's list lagged behind the create.
