The shell describes its own API: `GET /api/schema` answers an OpenAPI document built from its routes (the inventory, layout and presence routes among them), every route's view carries a docstring the document shows as the operation's summary, and its manifest carries a one-line `description` and the `api_schema_path`. The shell is internal, so the visiting-agent primer never lists it; a workspace-scope agent reaches the document on the shell's loopback port.
