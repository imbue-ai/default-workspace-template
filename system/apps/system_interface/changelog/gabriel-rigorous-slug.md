Fixed a blank screen that appeared if the workspace interface was rebuilt while the workspace server was running. The server used to decide whether to serve the interface's scripts once, at startup, based on whether a build existed at that moment -- so a build that appeared later was never served, and the browser silently refused to run the page, leaving nothing at all on screen. The scripts are now always served, and a genuinely missing one returns a plain "not found" instead of the page itself, which is what produced the blank screen.

Improved the page you get when the compiled interface is missing. It now explains that your work and your agents are untouched, names the one repair that works from that state -- build the interface in a checkout of the app and copy the result in -- and refreshes itself, so an interface restored by anything else (most often an update rolling itself back) brings the page back without you having to know to try again. Previously it printed a command naming a directory that is not present in the situation where you would most need it.

The server also now records a warning naming the exact directory it looked in whenever it falls back to that page, so the cause is visible in the service logs rather than only on screen.
