Hover tooltips no longer go stale when an element changes state. Before, a New Tab launcher opened before the app list loaded left the "Build a new app" tile saying "No app on this machine can start a chat" after the tile became usable, and an "Open new" tile kept naming its action while greyed out for a pending create. The fix is in the shared tooltip helper, so the other tooltips that switch on or off with state (the template detail dialog's actions, stopped rows in the all-apps picker and the project rail, the rail's menu rows) now follow it too.
