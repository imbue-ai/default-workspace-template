The system interface answers the Mind app's new `minds:focus-chat` embed message (sent when the user clicks a chat's notification in the app) by showing the chat its `chatId` names: it opens the chat's tab if closed, stays in the current view when that view already holds the chat (Everything always does), otherwise switches to the first project whose tab set contains it, otherwise opens it in the current project. A chat nothing lists is ignored with a console note. Once its embed handlers are registered, the workspace tells the app it is listening, so an ask that arrives while the page is still loading is delivered when the page comes up rather than lost.
