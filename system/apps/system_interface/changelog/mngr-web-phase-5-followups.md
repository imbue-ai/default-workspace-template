- The version the status route answers for a workspace made from a published copy of the template is no longer empty for good: the update dispatcher fetches the template's release tags into such a checkout, and the route reads them once they are there. The route itself still fetches nothing.

- The shell's handshake tells each page whether the Imbue Studio chrome said it relays no provider sign-in (`declinesProviderRelay`, embed contract version 20), which a chrome with no computer behind it says. The chat app's sign-in chooser reads it.

- The first run's provider page, which the shell frames over the desktop and sends no handshake, is told what the Imbue Studio chrome can do: the shell repeats the chrome's capabilities message to it once it has loaded. The page's sign-ins need it to know a chrome that relays none.
