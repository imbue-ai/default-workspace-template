Wire the Antigravity (agy) harness into the chat UI's model bar, plus a "New Antigravity Agent" launcher.

Antigravity agents now show a model bar, and there is a "New Antigravity Agent" item in the add-tab menu (always shown, like the pi/opencode launchers). This is a first cut mirroring pi/opencode: the model bar is wired but the transcript is not, so an antigravity tab renders no messages yet (a placeholder no-op watcher and claude-style activity). The model bar is READ-ONLY and reads the agent's model from agy's own per-agent `antigravity-cli/settings.json` `model` key -- the display name agy reads at launch and rewrites on an in-agy `/model` change -- so it is persisted, restart-robust, and reflects a model change made in agy's terminal picker (it just cannot drive one). The catalog is the flat `agy models` list (each model+effort pairing is its own entry, so there is no effort axis).
