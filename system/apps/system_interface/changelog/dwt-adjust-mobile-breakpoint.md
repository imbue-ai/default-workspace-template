The phone layout now takes only a phone-sized screen: at most 500px one way and 1000px the other, whichever way round. Before, any screen whose shorter side was under 700px got it, which caught the Imbue Studio window near its smallest size (800 by 600, so about 560px of workspace) and any short desktop window however wide. Phones still get the phone layout upright and on their side; iPads, the Studio window at any size, and desktop windows wider than 1000px keep the desktop.
