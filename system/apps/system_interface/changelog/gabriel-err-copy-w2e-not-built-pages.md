A stopped app's could-not-start page asks its agent with the app contract module's `mountFailureRemedies`, from a copy of the shell's built module it carries, so it offers what every other failure in the workspace does: "Ask an agent to look at it", a refused ask with its own "See details", "Draft it in a chat", and a "Report a bug" that files the page's sentence and error log with why the ask failed. With no built contract module the page offers no agent.
