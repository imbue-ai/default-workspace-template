The avatar moves into the taskbar on every screen once, when a workspace takes this update, as the 0.10.0 default intended. Under the older floating default, dragging the avatar saved that screen's whole presentation, the floating mode included, so most workspaces kept a floating avatar after 0.10.0. `clients.json` moves to version 3: reading a version-2 file puts every client's pinned entries in the taskbar and clears their floating positions. Floating the avatar again afterwards sticks.
