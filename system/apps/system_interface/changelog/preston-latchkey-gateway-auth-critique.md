The latchkey scope-catalog endpoint sends the `X-Latchkey-Gateway-Permissions-Override` header again when `LATCHKEY_GATEWAY_PERMISSIONS_OVERRIDE` is set, fixing 403s from desktop-hosted gateways (which evaluate override-less requests against a deny-all default). The header is optional: VPS gateways omit the env var and keep working with the password header alone. The override had been sent until commit 58e2f55c (2026-07-31) removed it along with the retired VPS secondary-gateway fallback, not realizing desktop gateways still require it for authorization.
