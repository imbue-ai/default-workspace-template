Switching desktops back and forth quickly no longer leaves the desktop flashing. Before, every window and its workspace kept answering each other's desktop moves: about once a second the windows disappeared, came back minimized in the taskbar, and reappeared, until the page was reloaded. A window now ignores the late news of a switch it has already moved past, and a window that only followed a switch made elsewhere no longer moves the other windows of the same browser in turn, so every window ends on the desktop chosen last and stays there.
