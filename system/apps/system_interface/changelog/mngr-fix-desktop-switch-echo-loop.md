Switching desktops back and forth quickly no longer leaves the desktop flashing. Before, every window and its workspace kept answering each other's desktop moves: about once a second the windows disappeared, came back minimized in the taskbar, and reappeared, until the page was reloaded. A window now ignores the late news of a switch it has already moved past, and a window that only followed a switch made elsewhere no longer moves the other windows of the same browser in turn, so every window ends on the desktop chosen last and stays there.

An agent's desktop switch (a `load`, a `show` from a link, or a deleted desktop's fallback) made while the page's own report of its desktop was still on its way to the shell, such as right after the page loads or reconnects, is no longer silently undone by that report. Each report that moves the client now names the page and the newest desktop revision the page had heard, and the shell ignores one made before a move it had not heard of (other than the page's own switches), so the page follows the agent's switch instead, and is told of it again in case it missed the news while connecting.
