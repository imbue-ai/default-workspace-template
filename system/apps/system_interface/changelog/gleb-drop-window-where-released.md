A window you drag stays where you let go of it, even when the desktop never sees the release. A drag interrupted that way -- the button comes up outside the window, or over a live page while the window has lost focus -- used to be thrown away on the next pointer move, snapping the window back to where the drag started; it now settles at the last point the pointer held it, which is where you let go. A resize loses its size the same way and is kept the same way. A drag the browser itself cancels still returns the window to where it was.

Dragging a window's edge out into the desktop starts as readily as dragging it inwards. A press becomes a drag only once it travels the drag threshold, and the pages of the windows around it are live until the drag begins, so the pixels before the threshold could be spent inside a neighbouring app's page, where the desktop sees nothing at all and the threshold is never crossed. Since an edge strip lies mostly inside its window (it overhangs the frame by less than the threshold), outward drags were the ones that left the strip early and stalled. The pages are now inert from the press rather than from the drag, so the threshold is measured against moves the desktop can always see. The pages are live again the moment the press ends, whether it became a drag, a click, or a long press.
