Opening a chat's notification now moves the pinned chat window back to that chat after the user switched it to another chat by hand. An independent window's page kept guarding the path it had just left until the next layout change, because the shell's confirmation of its own location report changed nothing in the fetched layout and so never reached the pages; a later move back to that path (the notification's chat) was taken for a stale snapshot and skipped. The confirming layout read now lets the pages follow, which ends the guard.
