Claude's post-auto-compaction summary now collapses into a chip instead of showing as a giant user bubble.

When Claude Code auto-compacts a long session, it injects a record whose text is the carried-over summary ("This session is being continued from a previous conversation that ran out of context. ..."). It is a real, visible message (not `isMeta`), so it used to render as a wall-of-text bubble that looked like the human typed it. The transcript parser now passes through Claude's `isCompactSummary` flag, and the classifier surfaces it as a collapsed, expandable "Summary of earlier conversation" chip -- same chrome as Stop-hook feedback -- keyed off the structural flag, not the summary text, so wording changes never break it. Because the summary can be the first event of a resumed session (no turn open yet), the grouping opens a leading section for it so it renders at the top rather than being dropped.
