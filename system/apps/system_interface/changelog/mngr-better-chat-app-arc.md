The system interface gains an `app.toml` manifest (`internal = true`, `critical = true`, `priority = "system_interface"`), and its supervisord program registers through `forward_port.py --manifest system/apps/system_interface/app.toml` instead of `--name system_interface --no-icon`. Its registry row now carries `display_name`, `critical`, `priority`, and `program`; nothing the shell renders changes (the row was already hidden by name). The `system-interface` tool is now installed by the generic per-app loop in `system/scripts/build_workspace.sh`, with its mngr plugins looked up under its manifest name (`system_interface`) in `system/config/mngr_plugins.toml`. Phase 1 of the workspace app model (`docs/system/blueprint/workspace-app-model/`). Deregistering an app (`POST /api/apps/<name>/deregister`) now runs `forward_port.py --remove` under a plain `python3` instead of `uv run`, since the script is standard-library only.
