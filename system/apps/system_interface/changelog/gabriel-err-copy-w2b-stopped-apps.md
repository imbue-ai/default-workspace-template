A stopped app says it isn't running and offers the next step, in its window, its launcher row, a launch's toast, and its could-not-start page.

- A stopped app's window says it isn't running ("Terminal isn't running.", or "Chat is not running right now." for an app the workspace runs as part of itself) and offers "Ask an agent to start it", asked in the chat about the app and laid out beside the window; for Chat itself, which an agent would be asked through, it offers "Report a bug" instead. Its launcher row says the same on hover.

- A launch into an app that isn't running says what the app's window would, with the same agent; the note goes once the app runs again. A launch that woke a stopped app that didn't come up says what its could-not-start page says: it couldn't start (Try again and "Ask an agent to look at it"), it failed several times in the last few minutes so it wasn't started again (the agent only), or it is still starting (Try again, and no help owed). The shell's answer names each with a `kind` (`app_stopped`, `app_could_not_start`, `app_start_budget_spent`, `app_still_starting`).

- A stopped app's page says "Starting <name>..." without guessing a cause; one that couldn't start waits for Try again instead of reloading on its own (with no Try again once it has failed to start several times in the last few minutes, when a press could not help), offers an agent to look at it, asked in the chat about the app (a refused ask offers "Draft it in a chat" and "Report a bug"), and shows the end of the program's error log behind "See details" (no "See details" when the log can't be read).
