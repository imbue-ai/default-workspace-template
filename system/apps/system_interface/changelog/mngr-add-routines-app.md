The shell's page now relays a message the Imbue Studio chrome posts into it whose type the embed contract does not define (a notification's `destination`, such as `minds:show-routine`) to the app whose manifest registers the type, through `relay.ts` (`setEmbedderAppMessageHandler`), since the contract's endpoint drops such a type before `embed.ts`'s observer sees it. Opening a routine's notification in the desktop app now shows the routine's page.
