Apps get an honest lifecycle: the registry row is identity, liveness is derived. AgentManager probes supervisord's process state for rows registered with a `program` (TCP-connecting the registered URL otherwise) and carries `is_running` on every app over the WebSocket; stopped apps render dimmed everywhere (rail, tab list, All apps popover, launcher tables) with tooltips distinguishing "stopped" from "not running (managed outside the workspace)", and open tabs of a stopped app show a minimal placeholder with a Start button instead of a dead iframe.

New idempotent `POST /api/apps/<name>/stop` and `/start` endpoints drive the supervised program (400 for programless rows and the essential `{system_interface, terminal}` set, 404 for unknown names). The app's destructive-slot verb becomes the reversible "Stop <name>" -- no confirmation -- with "Start <name>" while stopped; the deregister-flavored "Unregister app" verb and its dialog leave the UI (the endpoint stays for tooling). Clicking a stopped app anywhere starts it and opens its pane.

The rail's top section generalizes into per-project **shortcuts** with modes: focus mode goes to the view's most recently used member of the kind (machine-wide recency store, view-restricted -- superseding the old prefer-the-project's-own-chat rule) and creates only when the view shows none; new mode always creates. Labels derive from the mode, chat's default flips to "New Chat" (code-side, no migration), and every shortcut row gains a kebab/right-click menu with the complementary action, the mode flip, and Unpin (built-ins only). Apps get the same machinery, including "New X" second panes that bypass the focus-existing dedup, and shortcut-initiated creates take the launcher tiles' in-flight guard.

Storage generalizes `unpinned_shortcuts` into a sparse `shortcut_overrides` map (`is_pinned` for built-ins, `mode` for any shortcut, keyed by name or `app:<service>`); a legacy list is folded in on read and migrated on first write. `POST /api/projects/<id>/shortcuts` accepts `{shortcut, is_pinned?, mode?}` and answers the full effective override map.
