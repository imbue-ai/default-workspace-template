- An app can now take custom-scheme links (`slack:`, `paseo:`, `vscode:`) by registering a message handler for `open:<scheme>` (`open:slack`). The shell announces `opensCustomSchemeLinks` to Imbue Studio, which then hands it such links from the workspace's pages, and a page's click on one comes to the shell too. A custom-scheme link no app takes goes back to Imbue Studio, which asks before opening it in the app of the user's system. With an older Imbue Studio, which shows a popup of one as an empty window, the shell launches the link by navigating its own page to it; in a plain browser (a share link, `minds run`) it opens in a new tab, as a web link does.
