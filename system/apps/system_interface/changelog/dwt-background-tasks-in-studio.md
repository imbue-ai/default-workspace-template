The avatar keeps working while a chat waits on a background task. An agent that ends its turn to wait on a command it started through `run_in_background.py`, or on one of Claude's own background tasks, reads WAITING to mngr, so the avatar used to go idle though the task's completion would start the agent's next turn. Its mood is now working when any agent but the services agent is running, as before, or when any chat holds a live background task marker under `data/.apps/chat/background_tasks/`. The shell watches that directory as it watches mngr's agents event file, so a marker written or removed shows within the debounce, and its periodic re-check catches a marker whose process died without removing it.
