Dragging a window no longer makes the desktop flicker. Two things together ran the browser out of the GPU memory it draws the desktop with during a drag. First, every window hidden behind another started rendering again for as long as the drag lasted; now only a window that the dragged one was covering does, and windows behind ones that stay put stay paused. Second, the dragged window was repainted on every pointer move; it now gets a compositor layer of its own until the drag ends, so a move only slides it. On a test desktop with three maximized windows behind a fourth and a chat floating on top, a drag used to fill that memory (about 650 MB against a budget of 655 MB); with this change, drags on a similar desktop peaked at about 440 MB, with no flicker or lag.
