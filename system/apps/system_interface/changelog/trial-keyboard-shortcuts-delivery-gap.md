An "everywhere" keyboard shortcut save applies at once and stays applied. Once the account takes it, the workspace keeps its own copy, marked delivered, until Imbue Studio rewrites the account snapshot after taking the save, a few seconds later. Before, the copy was dropped on delivery, so every app and the Keyboard shortcuts screen showed the previous keys until that rewrite (the screen until it was reopened). A snapshot Imbue Studio worked out before taking the save no longer counts, so a second save made within those seconds does not briefly revert either. A delivered save reads as the account's, is not listed as waiting to be saved, and gives way to a value set from another computer once a later snapshot carries it.
