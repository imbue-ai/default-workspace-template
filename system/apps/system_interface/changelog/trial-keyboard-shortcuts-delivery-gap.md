An "everywhere" keyboard shortcut save applies at once and stays applied. Once the account takes it, the workspace keeps its own copy, marked delivered, until the account snapshot Imbue Studio rewrites a few seconds later carries the same keys; before, the copy was dropped on delivery, so every app and the Keyboard shortcuts screen showed the previous keys until that rewrite (the screen until it was reopened). A delivered save reads as the account's, is not listed as waiting to be saved, and gives way if a newer snapshot carries another value set from elsewhere.
