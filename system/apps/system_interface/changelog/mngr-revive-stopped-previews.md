A preview or UI sketch whose window outlived it (a workspace restart stops every one) now says "This preview stopped." or "This UI sketch stopped." in place of the old "not running (managed outside the workspace)", with a **Start it again** button and **Close**. Start brings it back where it was, on the same ports and over the same copy of the data, and the window shows its page again once it answers; a start that fails says why, and Start stays on offer. The window's refresh control does the same as Start. Behind it is `POST /api/apps/<name>/revive`, which runs the instance's `revive` from the workspace root and is refused for any other app and in a preview shell.
