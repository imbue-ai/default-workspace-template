A preview or UI sketch whose window outlived it (a workspace restart stops every one) now says "This preview stopped." or "This UI sketch stopped." in place of the old "not running (managed outside the workspace)", with **Start it again**, **Ask in chat**, and **Close**. Start boots it again as it was last booted, and the window shows its page once it answers; a start that failed says so and can be tried again. Ask in chat drafts what happened into the chat for the user to finish. Behind Start is `POST /api/apps/<name>/revive`, which runs the preview's or UI sketch's own `revive` from the workspace root, logs what it printed when it fails, and is refused for any other app and in a preview shell.
