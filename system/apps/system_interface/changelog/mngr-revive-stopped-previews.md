A preview or UI sketch whose window outlived it (a workspace restart stops every one) now says "This preview stopped." or "This UI sketch stopped." in place of the old "not running (managed outside the workspace)", with **Start it again** and **Close**. Start brings it back where it was, on the same ports and over the same copy of the data, and the window shows its page again once it answers; the window's refresh control does the same. A start that did not work says to try again; one that cannot work (its data copy or ports are gone) says so and offers **Ask in chat**, which drafts a request for a new one. Behind it is `POST /api/apps/<name>/revive`, which runs the instance's `revive` from the workspace root, logs what it printed, and is refused for any other app and in a preview shell.
