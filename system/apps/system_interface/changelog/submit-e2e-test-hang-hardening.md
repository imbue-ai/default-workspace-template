Made the system interface's Playwright e2e suite fail fast instead of hanging, and restored ten tests that had been silently skipping. The suite runs as part of the default `uv run pytest`, but with no built frontend every test used to load the "Frontend not built" placeholder and then burn its full timeout waiting for selectors that could never appear — roughly 20 minutes of dead time — and because the project sets `timeout_func_only = true`, a stuck browser launch or server fixture was entirely unbounded. The module now skips in ~0.06s with a clear "frontend not built" message when `static/index.html` is missing, and every e2e test caps both its setup and its body via `func_only=False` timeouts so no path can hang unbounded. Separately, ten tests had targeted the pre-simplification sidebar/SubagentView UI and had been marked skip since the single-dockview change, so real UI regressions went uncaught; they are rewritten against the current DOM (tab titles, the liveness dot, the add-tab "+" dropdown, the empty-state overlay, collapsible tool calls) and pass again. CI still builds the frontend first, so it continues to run the full e2e suite.
