The tour record (`GET` and `POST /api/tour`, `tour.json`) gains `is_finished`, false by default so an older file reads whole. A record written finished sets the `tour_finished` onboarding marker, and the owner's phone layout reporting what it shows (`POST /api/clients/<client_id>/shown`) sets `phone_layout_used`; the chat's activity suggestions read both. A marker that cannot be written is logged and does not fail the request.
