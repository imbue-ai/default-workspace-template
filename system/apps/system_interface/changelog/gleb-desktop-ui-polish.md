The desktop's shortcuts, the window chrome, and the menus that hang off them have had a pass.

**Shortcuts.** An icon's drawing sits inside its tile rather than filling it, and the tile's corner is a fraction of the icon's size, so an icon shown larger or smaller keeps its shape. A name is bold at the label size over a softer shadow, and the icon and the name start at the top of their cell, so every icon sits on one line across the grid and every name starts on one -- a two-line name no longer lifts its icon off its neighbours' line. Hovering an icon grows it; the tinted box now says only *selected*, in the accent colour under an accent outline, and it wraps the icon and its name rather than filling the cell. Right-clicking an icon selects it, so the menu names something that looks picked. Dropping a dragged icon lands it where it was dropped, instead of showing it back where it started until the move is recorded.

**Window chrome.** The taskbar is translucent over a blur, which needed the wallpaper to carry on behind it. Refresh has left the window menu for a button of its own beside the window's name, followed by the three dots, which stand vertically. The controls are sized from the bar rather than the touch target, and share one box so their hover targets line up; the app's icon takes the title's colour and dims with it. The bar shows the open hand, and the closed one while a window is dragged. A window's frame has no border: the shadow is what separates it from the desktop.

**Move and resize.** New: a grid of nine places a window can take -- the whole backdrop, the four halves, the four quarters. Rest on the maximize control to open it, or find the same grid under *Move and resize* in the window's menu. Each tile's picture is drawn from the placement it performs, so the two cannot disagree.
