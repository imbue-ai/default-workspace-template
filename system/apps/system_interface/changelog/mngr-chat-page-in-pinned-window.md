A link from an app's page to a chat (the chat root at `/?chat=<id>`) now shows that chat in the pinned chat window instead of opening a second chat window. More generally, a link to an app's pin page with a query of its own goes through the shell's `show`, which raises a window already there, or points the app's on-screen root window or its pinned window at it. Shell pages reach `show` through a new `POST /api/clients/<client_id>/show` route, since the op route is loopback only.
