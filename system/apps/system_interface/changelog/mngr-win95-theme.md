The desktop wears a Windows 95 look: a teal backdrop with no wallpaper, silver window frames with the classic raised bevel and a navy title bar, bevelled taskbar entries, a raised Start button in place of the launcher's text field, and a Start menu with the navy band down its left edge. The launcher's typed filter and message field still exists, as the foot of the open Start menu, hidden while the menu is closed. The tray gains a clock. The theme is one stylesheet, `frontend/src/theme/win95.css`, imported after the default tokens; the markup is unchanged apart from the Start button and the clock.
