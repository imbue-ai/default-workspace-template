The shell installs the request guard ahead of its routes (`app_schema.request_guard`): a request the workspace's own browser marks as a page of another origin's is refused with 403, other than a GET navigation and the two `_static` modules served to other origins on purpose, and a request with no `X-Imbue-Identity` header reads as the owner's only from loopback under a loopback `Host` (imbue-ai/mngr-internal#2816). A present header that does not parse is now answered with 400 on every route by the same hook.
