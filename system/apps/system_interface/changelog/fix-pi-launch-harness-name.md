The New Tab launcher's "Pi agent" and "Introductory Pi chat" tiles now actually create an agent. They were sending the tile's own kind (`pi`) as the harness, but mngr's agent type is `pi-coding` (`pi` is only an mngr-side alias, which the create endpoint's harness enum does not accept), so every Pi launch was rejected before any `mngr create` ran and surfaced as a raw validation error. Codex and Claude were unaffected, their tile kinds happen to match their agent types. The launcher now translates kind to harness through one table, which the intro- tiles share, so the two namespaces cannot drift again.
