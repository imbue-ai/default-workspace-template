Hovering a window behind the focused one and scrolling now scrolls its page, with no click first. A click or press on a background window reaches its page and brings the window to the front in the same press, as in a native desktop application; before, a transparent cover took that first press and only raised the window. Keys typed after the press go to the window that came forward.

The shell raises a window whenever the document's focus lands in its page, so this holds for every app, whether or not it speaks the shell contract. A focus a page takes in answer to a message the shell has just sent it is no press: a terminal that focuses itself when the shell shows it (after a reload, a switch back to its desktop or an agent's refresh) stays behind the window you are in, and the focus requests the shell posts to a raised window are dropped once another window is focused. After a raise the shell raises no other window for a few frames, so pages that take the focus back whenever they lose it no longer flip the stack on every press.

Touch screens keep the cover over background windows, so the first tap there still only raises the window, and every window is covered while a menu or the launcher is open, so the press that closes them never reaches a page.
