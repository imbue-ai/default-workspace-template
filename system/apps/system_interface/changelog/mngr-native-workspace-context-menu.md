The shell takes the Imbue Studio desktop app's `drawsContextMenus` capability and passes it to every page in its `shell:handshake`, greeting the open pages again when it arrives after them. The shell's own element menu follows it too: where the app draws a native menu, a right-click on text being edited, on a selection, or on a plain link in the shell's chrome, and any with Shift held, is left to it.
