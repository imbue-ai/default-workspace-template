A right-click on a taskbar or floating entry, a desktop shortcut, the bare desktop, an overview thumbnail, a launcher row of an app shortcut, or the tray's agent no longer draws a menu of its own. It goes through the shell's element menu, which leads with that thing's rows and follows them with the standard rows (Copy, for a selection) and the reference rows. A right-click on a shortcut still selects it.

The shell takes the Imbue Studio desktop app's `drawsContextMenus` capability and passes it to every page in its `shell:handshake`, greeting the open pages again when it arrives after them. The shell's own element menu follows it too: where the app draws a native menu, a right-click on text being edited, on a selection, or on a plain link in the shell's chrome, and any with Shift held, is left to it.
