The shell takes the Imbue Studio desktop app's `drawsContextMenus` capability and passes it to every page in its `shell:handshake`, greeting the open pages again when it arrives after them. The shell's own element menu follows it too, so in the desktop app on macOS a right-click on the shell opens the app's native menu with the shell's rows in it.

That covers the shell's own menus as well: a right-click on a taskbar or floating entry, a desktop shortcut, the bare desktop, an overview thumbnail, a launcher row of an app shortcut, or the tray's agent no longer draws a menu of its own but leaves the click to the element menu, which leads with that thing's rows. In the desktop app on macOS they appear in the native menu (Close and Delete desktop... with their symbols); elsewhere each still opens its own HTML menu, now with the standard rows (Copy, for a selection) before the reference rows. A right-click on a shortcut still selects it.
