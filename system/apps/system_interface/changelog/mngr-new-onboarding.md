The desktop gets a show-around tour. It begins the first time the workspace's agent goes to work, so the user learns the product while waiting for a reply: a card pops out beside the agent's avatar and walks through the agent, the workspace, the chat window (whose Next snaps the chat to the right half of the desktop, revealing the shortcuts), the apps, connecting data, backups, sharing, devices, feedback, AI providers, and durable apps, ending at the launcher. The agent answering interrupts the tour: the card stays, the next Next shows "The agent is waiting for you. We'll resume the tour later", and the tour resumes from the card that would have come next the next time the agent works. The page's `tour_start_ms` query parameter makes the tour wait for a task that has been running that long instead of starting on the first message. A card about a control of the Imbue Studio chrome (the workspace switcher, a workspace tab, the help button) asks the chrome to ring it through the new `minds:highlight-chrome` embed-contract message; the words never depend on the ring. Exiting early leaves one badge pointing at the launcher, whose new "Show me around" row runs the tour again from the first card at any time. The phone layout, where the tour does not run, never lists the row.

What the tour has done is one record the shell keeps in `data/.state/system_interface/tour.json` (`is_seen` and `resume_index`), read and written through `GET` and `POST /api/tour`. The tour's three pictures (the connectors strip, a loop of service logos sliding by; a computer and a phone; the provider menu) are hosted on the onboarding-media bucket under content-addressed names, not bundled, and the shell's page policy admits images from that origin.

The pinned chat window now first shows at most of the backdrop (a margin in on every side) rather than the right half, so a new workspace opens on the welcome chat; the tour's chat card is what snaps it aside.

For now the tour runs once per workspace; limiting it to a user's first workspace waits for the cross-workspace data sync.

The tour's words follow the v2 copy document, adapted to the shipped tour (it pauses when the agent answers rather than bringing the user back, and its connect card carries both the services and the folders): the intro, agent, connect, security, devices, feedback, and last cards, and the pause notice, are reworded, and a card's text may hold several short paragraphs (a blank line in the text; the card draws each with a gap).
