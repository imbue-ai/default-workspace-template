- Clicking a chat's notification in the Mind app now opens that chat. The pinned chat window was sent to `/<chat-id>`, a path the chat list does not read a selection from, so it landed on the chat list with nothing selected and looked blank until the chat was picked again. The notification now points the window at `/?chat=<chat-id>`, the path the chat list selects a chat from, and a chat window that already shows the chat at that path is raised instead of being moved. With no pinned chat window, the chat opens in a new chat-list window with the chat selected.
