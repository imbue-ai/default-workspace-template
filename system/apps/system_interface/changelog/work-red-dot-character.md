The imbue character is called "Imbue" in the avatar chooser, jumps when it is chosen, and shies from a mouse resting on it.

- The chooser lists the character as "Imbue" rather than "Imbue character"; its still preview carries the same title. Its id is unchanged, so a stored choice still finds it.

- Choosing the character makes it jump once as it appears: it crouches, launches, stretches on the way up, eases off at the apex and folds on landing. Only a switch does this. A page load, the same choice pushed again, or its entry being drawn somewhere else leave it on the floor, and reduced motion keeps it still.

- A mouse coming onto the character presses a very slight dent where it came in and moves the body two screen pixels the other way, whatever size it is drawn at. Both are set on the way in and held until the mouse leaves, so it does not squirm as the pointer crosses it. Touch has no hover, so a tap only presses.
