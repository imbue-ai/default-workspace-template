New: the Style Guide app, one page cataloguing the workspace's design system. Foundations lists every color token (a swatch drawn with the live value, its utility, its `--c-*` value and the value as declared, under `base.css`'s own groups), the type roles and font stacks, spacing, corner radius, elevation, motion, the stacking layers and widths, and the whole icon set; Components draws every Button variant, size and state, the text fields, the Dropdown and SegmentedControl, the Menu with a submenu, check rows and disabled and danger rows, hover tooltips, badges, banners, activity dots, spinners, the Modal, the notice and delete-confirmation dialogs, toasts, and the surfaces stacked as the apps stack them. The tokens are read out of the shared stylesheet at build time and the components are the library's own, so the catalog follows the library with no edit of its own.

It wears the workspace's theme (`[theming] mode = "tokens"`), opening in it without a flash of the standard look, and serves the themes from its own origin. Under a theme every swatch and control is that theme's, each value caption shows the value the page wears with the standard one struck through when the theme changed it, and the header names the theme. A Theming group lists every part a theme can style, linked to the section that shows it. The shadow values (`--c-shadow-*`) are drawn as elevation rather than as colors, and the font stacks include `--font-display`.

The Tooltips section shows the tooltip's quieter second line (the `detail` option). A Plain pages section frames a page built as plain HTML on the page kit, which the app serves from its own origin (`/page-kit-sample`, and the kit's `/_static/workspace_theme.css` and `.js` from the shell's build); the page hands the theme the shell names on to it, previews included. The parts list names each section by its contents label, and links the tile and list-row parts to that frame.

The contents column is wider and scrolls with a thin bar in a gutter of its own, so on a system that always shows scrollbars the bar no longer sits against the labels.

The app stays off the desktop (`desktop_shortcut = false`): it is in the launcher, and a shortcut of it can be added by hand.

The colors are one compact table, a row per color: its name (the utility and its `--c-*` value), the value the page wears, and a swatch with a strong edge so a fill the same as the page still shows. The page says "color" throughout.
