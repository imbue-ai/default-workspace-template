New: the Style Guide app, one page cataloguing the workspace's design system. Foundations lists every colour token (a swatch drawn with the live value, its utility, its `--c-*` value and the value as declared, under `base.css`'s own groups), the type roles and font stacks, spacing, corner radius, elevation, motion, the stacking layers and widths, and the whole icon set; Components draws every Button variant, size and state, the text fields, the Dropdown and SegmentedControl, the Menu with a submenu, check rows and disabled and danger rows, hover tooltips, badges, banners, activity dots, spinners, the Modal, the notice and delete-confirmation dialogs, toasts, and the surfaces stacked as the apps stack them. The tokens are read out of the shared stylesheet at build time and the components are the library's own, so the catalog follows the library with no edit of its own.
