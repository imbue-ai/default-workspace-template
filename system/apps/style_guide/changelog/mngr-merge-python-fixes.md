The Style Guide app is a built-in like every other app the template ships: a root dependency and workspace member, run from the workspace venv (`.venv/bin/style-guide-app`) rather than installed as its own uv tool. It takes a band of its own (`style-guide`, right before System Monitor's) instead of the user band, which the built-in rules reserve for user-built apps, and its preview boots `style-guide-app`, the entry point its program runs, rather than the program's name.
