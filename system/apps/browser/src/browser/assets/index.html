Using this browser

  • Browser works in the background. Even if you close this workspace tab, the browser will run in the background and agents can work on it.
  • Copy and paste, both ways. You can copy both images and text out of the browser, and can paste them in too.
  • Keyboard shortcuts.
    • If you're on a Mac, you can use Cmd + C, V, X for cut, copy, and paste with the remote browser. However, no other Cmd keyboard shortcuts will work — use Ctrl instead, such as Ctrl + R for reload.
    • If you're on Windows or Linux, Ctrl keyboard shortcuts won't work in the browser.
  • Use it like a normal browser. Click, type, scroll, manage tabs, and watch videos (with sound) — it all works.
  • You share each browser with agents, through a queue. Only one of you drives at a time; whoever else wants it waits in line. Click “Return control to agents” to hand it back when you're done.
  • An agent may hand a browser to you for something it can't do itself — a captcha or a login check. Control comes to you and this bar turns amber; finish the step, then return control.
  • Logins are saved. Each browser keeps its own cookies and sign-ins, and they persist across restarts — so you stay logged in.
