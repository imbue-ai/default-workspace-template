Using this browser

  • Keyboard shortcuts. Mac: Cmd + C, V, A, E, F, etc. work; Cmd + T/W/N are unreliable — use Ctrl + T, W instead. Windows/Linux: Ctrl + C, V, A, E, F (and Shift variants) work; Ctrl + W/N unreliable.
  • Scrolling. Click and drag to scroll works best; the trackpad and mouse wheel also work.
  • Use it like a normal browser. Click, type, scroll, copy/paste text and images, manage tabs, watch videos with sound — it all works.
  • You share each browser with agents, through a queue. Only one drives at a time; others wait in line. Click "Return control to agents" to hand it back when you're done.
  • An agent may hand a browser to you for a captcha or login check. Control comes to you and this bar turns amber; finish the step, then return control.
  • Logins are saved. Each browser keeps its own cookies and sign-ins across restarts.
