- The viewer pauses its stream when the workspace shell hides its window (minimized, or on another desktop), by listening for the shell's `shell:hidden` and `shell:shown`. It used to notice from its pane measuring 0x0, but the shell now keeps a hidden window's page at its real size, so that no longer happens. This also fixes Safari, where a hidden pane never measured 0x0 and kept streaming.

- A browser window reloaded while hidden (a refresh, an app restart) no longer takes the stream from the browser window you are looking at, which used to freeze it behind "Livestream paused" until clicked, and no longer resizes the browser to its own size. A viewer inside the shell now opens its stream only once the shell says its window is shown.
