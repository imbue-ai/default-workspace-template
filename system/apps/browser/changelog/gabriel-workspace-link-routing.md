The browser opens links clicked elsewhere in the workspace.

- A local link clicked in a chat (or a page's popup to a local address) that no app of the workspace is registered at opens as a new tab in front in the workspace's one browser, starting or relaunching it when needed, and the browser window comes to the front.

- While an agent is driving the browser, the link waits: the agent's overlay names it with "Take control of this browser", which opens it as a tab in front, and "Cancel", which drops it and leaves the agent's work alone. A link that arrives while the browser is still starting opens once it is up, instead of being lost.
