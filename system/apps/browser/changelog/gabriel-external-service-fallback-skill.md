`agentic-browser-fleet handoff` now brings the browser window up in front of the user: it opens the viewer without `--minimized`, which restores and raises a window the browser already has. It used to open it minimized like `new`, which left a window already there as it was, so the user handed a CAPTCHA or sign-in often could not see it. `new`, `acquire`, and an agent's first command still open the window minimized.
