The `new` launch path is a POST: the shell posts `url` to `/new` and the browser answers `{"path": "/?session=<name>"}` after starting the fleet's browser (and opening the URL as a tab), so a reload of a browser window starts nothing. A refusal of the launch (a `url` that is not an absolute http(s) URL, say) answers its reason as `{"detail"}`, which the shell passes on as `browser refused the launch: <reason>`. A `GET /new` answers 405.
