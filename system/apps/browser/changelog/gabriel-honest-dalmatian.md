- Fixed a self-deadlock in `test_launch_cdp_and_proxy_come_up_together_real_chromium`. The test starts the CDP proxy on the event loop created by `asyncio.run`, then fetched `/json/version/` with a blocking `urllib.request.urlopen` from inside that same coroutine -- so it blocked the loop while waiting for a response only that loop could produce, and timed out after 5s. Raising the client timeout did not help, as a deadlock cannot. The fetch now runs off the loop via `asyncio.to_thread`. The proxy itself was never broken: the documented `agentic-browser-fleet new` -> `playwright-cli attach` workflow answers `/json/version` in milliseconds against the live supervisord-managed service, where the proxy and the client are separate processes. Because the test is skipped in GitHub Actions CI, its failure only ever surfaced on developer machines, where it read as the attach workflow being broken.
