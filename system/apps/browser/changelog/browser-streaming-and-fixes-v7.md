The agentic browser fleet now streams through the hardened streamed-browser display stack instead of the old CDP screencast with rebuilt HTML tabs and address bar: each browser is a full Chromium -- its own tabs, omnibox, and native menus -- streamed as damage-driven H.264 (pixelflux stripes, CPU-only) with display-level XTEST input, on its own private virtual display. browser-use is now the single connection driving each browser, so switching tabs switches the real tab and the pane follows whatever tab an agent acts on; a crashed browser is detected and reported instead of freezing. Copy and paste work both ways for text and images, videos play with sound (per-browser Opus audio, only while a tab actually makes sound), and a "View tips" card explains the controls. A browser pane that isn't being shown -- the workspace tab backgrounded, or the browser not the active tab -- throttles to about 1 FPS so it stops burning CPU while nobody is watching, and returns to full rate when shown again.
