The agentic-browser-fleet now streams via pixelflux instead of CDP screencast. Each browser renders headful into its own private Xvfb display, captured as damage-driven H.264 (pixelflux stripes, CPU-only) over the cast WebSocket with per-stripe credit-ack flow control; human input injects at the display level via XTEST (the Selkies grammar), audio rides a jsmpeg MPEG-TS socket gated on real sound, and clipboard (text + images) bridges over HTTP. The whole fleet envelope is unchanged -- the ownership state machine, waiting queue, take-control overlay, agent handoff for captchas/logins, the tips card, browser-use agent driving, saved per-browser logins, and the single "+"-menu entry all carry over; agents keep driving the same Chromium over CDP while a human takes pixel-level control. Chromium's own tab strip and address bar are now in the streamed pixels (no rebuilt chrome). A hidden pane drops to a ~1-2 fps trickle so a backgrounded browser costs almost nothing while its agent keeps working. This replaces the standalone streamed-browser prototype, which is removed -- its pixel modules (videopipe/xinput/audiopipe) are absorbed into the browser app, and the fleet's existing native xclip clipboard bridge is reused (retargeted to each browser's private display).
