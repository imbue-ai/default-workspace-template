The browser's tips card now opens by itself the first time you open the browser on a device, over the live picture once it has loaded, and can be brought back any time from the small "?" button in the bottom-right corner. Its copy is rewritten around what makes this browser different, under the heading "This browser is special!": the agent can control this browser, it stays open even when your computer is off, anyone in the workspace can see it, and there is only one browser for the whole workspace.

The bar across the top of the browser is gone while you simply have control. It now appears only while an agent is driving, an agent is waiting for its turn, or an agent has asked you for help, and it lies over the top of the streamed picture, covering the browser's own tab row, instead of taking up a row of its own. The memory warning moved next to the "?" button in the corner.

Pasting with Ctrl+V into the streamed browser now works every time. The paste keystroke is delivered to the page directly instead of being typed into the remote keyboard, so it no longer races your own held Ctrl key or depends on which window has focus.

Ctrl+W in the browser now closes the current tab instead of the whole browser. Closing the last tab replaces it with a fresh one, so the browser stays open and keeps its logins.
