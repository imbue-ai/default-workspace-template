- The browser can now be previewed: update-self's check of a customized browser and update-app's preview can boot a throwaway copy beside the live one. Before, the service always bound port 8081, so a second copy could never start. It now reads `BROWSER_PORT` (default 8081), and the manifest's new `[preview]` table gives a preview its own ports, a copy of the saved fleet, and its own profile directory. The profile directory matters most: on startup the browser relaunches every profile under its root and deletes any its saved fleet does not name, so a preview sharing the live root would have run on, or deleted, the user's logins. A preview also names its audio sinks under a prefix of its own (`BROWSER_PULSE_SINK_PREFIX`, default `browser`): its browsers carry the live ones' names on the one shared PulseAudio daemon, so with the live sink names its audio would have played into the live browsers' streams and closing it would have cut their audio.

- The tests' own fixture that cleared `MINDS_CHAT_ID` and `MNGR_AGENT_ID` is gone: the pytest-workspace-env plugin now clears the whole agent environment for every test run.
