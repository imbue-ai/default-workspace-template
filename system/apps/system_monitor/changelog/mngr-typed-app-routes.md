Memory & disk's routes are typed: `GET /api/stats` answers a `StatsResponse` (the memory and disk figures, the breakdown's rows and their items, the usage mode, the memory guard's stops, and the graph's history) and `GET /health` a `HealthResponse`; the page and the shell's browser-side modules are declared schemaless. The API document at `/api/schema` publishes the models, and every answer is checked against the route table. Every row of the breakdown now carries a `limit` field (null except on the Temporary files row).
