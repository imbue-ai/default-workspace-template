New: the Markdown Editor app, for reading and reviewing the markdown files agents write (plans, notes, reports). It opens a file by `?path=` (or from its start page, which lists the recently opened files and the workspace's markdown files) and shows it formatted, in Suggest mode by default: what the person types and deletes becomes tracked suggestions, and any selection can be commented on. Suggestions and comments are saved inside the file as CriticMarkup (`{++added++}`, `{--removed--}`, `{==text==}{>>comment<<}`), so the agent that reads the file next sees them in place; each one is accepted or rejected by clicking it, or all at once. Edit mode changes the file directly and Read mode changes nothing.

Saving is automatic, and blocks the person did not touch are written back byte for byte, so the editor never reformats an agent's file. A save based on a version the file has since left is refused and the page offers to reload or keep its own; while nothing is unsaved the page shows an agent's rewrite as soon as it lands. Every save keeps the version it replaced under `data/.apps/markdown-editor/history/`. It opens files under `/home/user`, never in a `.secrets` folder, and writes only markdown and text files. Built on Tiptap 3 with its markdown extension and the open `@handlewithcare/prosemirror-suggest-changes` plugin; served on port 8070.
