Clicking a file in the File Viewer opens it in a File Viewer window on the desktop, instead of a bare browser window.

- A file's name opens its view page (text as read-only source; PDFs, images, audio and video shown; anything else offered as a download) in a new File Viewer window, titled after the file. Clicking it again raises that window rather than opening another. A modified or middle click does the same.

- The listing's Edit button opens the file's edit page the same way, raising a window already editing that file.

- A file's view page has an Edit button that switches the same window to the edit page.

- Folders still open in place.

- A path that does not exist shows the File Viewer's own "not found" page, naming the path and linking the nearest folder above it, instead of a bare "Not Found".

- Opened on its own in a browser tab, outside the desktop, the viewer's links behave as before.
