The file browser's shortcuts become rebindable (user-profile-state spec, phase 3C): new `/__files/api/keybindings/actions` and `/__files/api/keybindings/me` routes declare the browser actions (select-all, go-up, back/forward, new-folder, open, rename, delete, clear-selection, save-file) with their existing chords as the defaults, and `keyboard.ts` and the file page's save match the resolved chords instead of hard-coded ones, re-fetched when the shell announces a change. The selection arrows and the type-ahead jump stay built in. The project also gains the `[tool.ty]` table its siblings carry, so its type-check ratchet stays inside the repo in a nested checkout.
