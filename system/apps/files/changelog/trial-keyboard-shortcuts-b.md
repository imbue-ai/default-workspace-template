Every default shortcut is written once, with `meta` as the Command key on a Mac and the Control key elsewhere: Select everything ⌘A, Go up ⌘↑, Back ⌘[ and Forward ⌘], Open Enter or ⌘↓, Delete Delete or ⌘⌫, Save ⌘S. The Alt+arrow alternatives and the Ctrl copies are gone, and New folder moves to ⌘⇧F, since browsers keep ⌘⇧N for a private window.
