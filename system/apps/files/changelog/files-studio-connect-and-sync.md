Files says how each synced folder stands as Imbue Studio reports it, and, inside the Imbue Studio app, connects a file or folder with Studio's own picker.

- A synced folder's state comes from Imbue Studio on the computer instead of a guess made by comparing names on both sides. While it syncs or makes its first copy, its sidebar row shows a spinner and its tooltip how far along it is ("Copying the first time, 10 MB of 40 MB."); once the first copy has finished it is "Up to date, last synced today at 9:30 AM."; a sync that stopped shows the orange alert, its tooltip and the folder itself give Studio's reason and point to retrying it in Imbue Studio; a sync switched off reads "Not syncing right now". A copy whose computer is asleep, or whose Imbue Studio is closed, reads "Can't check" rather than a guess.

- An empty synced folder still on its first pass says it is being copied, and how much has arrived, in place of "Empty".

- In the Imbue Studio desktop app, Connected ends in "Connect a file or folder…". It opens Studio's own file picker on your computer; the file or folder you pick is shared read-only, Studio opens its settings so you can allow changes or keep a synced copy, and the list here shows it straight away. A plain browser, a phone, or a share link has no picker to open, so the entry is not shown there.
