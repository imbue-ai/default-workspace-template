- Chat presence is now tracked per page rather than per client. Every chat page mints an id when it loads and names it on each presence report, so a pulled-out chat and its hidden copy in the main window no longer overwrite each other's report (which made the chat flicker between shown and hidden for the memory prioritizer). Reports also say whether the page's document has focus, are sent again on every focus and blur, and heartbeat every 30 seconds instead of every 60.

- A chat page that is shown and focused, and has reported in the last 90 seconds, is *watching* its chat. The new `GET /api/chats/<chat-id>/watchers` (loopback only) lists the watching pages as `{"watched_by": [...]}`, which the notify-user script passes on to the Imbue Studio app so it can show nothing to a user who is already reading the chat.

- When a chat goes from nobody watching to someone watching, the chat app tells the Imbue Studio app the chat was read (`POST /api/v1/agents/<agent-id>/notifications/read` through the latchkey gateway, as the chat's current agent), so its notifications from that chat are marked read. The call runs off the request thread; an app without the route (404) or an unreachable gateway is ignored. A secondary (preview) chat makes no such call.
