Scrolling to the bottom of a chat while the agent is writing stays at the bottom. Before, the view could jump back up about a message's height just as it got there and then slide back down, so it looked like the wheel couldn't quite reach the end.

- Typing a long message no longer makes the transcript jump up a line each time the text wraps. When the message box grows, the transcript re-pins to its bottom before the screen redraws, not a frame later.

- Once a message outgrows the message box, the line being typed stays fully in view instead of sitting partly under the box's bottom edge.
