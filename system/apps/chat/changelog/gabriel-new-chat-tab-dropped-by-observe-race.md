A new chat no longer disappears from the chat list a few seconds after it is created. The observe stream reports a new agent several seconds after its create returns, and every observe event before that rebuilt the tracked agents without it, so the chat was briefly unlisted and the shell closed its tab. The chat app now keeps the agents it created until the observe stream reports them. An agent the stream never reports at all is let go after two of its full snapshots, so a create that died before the stream saw it cannot linger in the list.
