The provider chooser now asks again for its provider list when the request fails, waiting a little longer each time for about fifteen seconds before it shows "Could not load providers". The desktop app's connection to a new workspace can drop for a second or two, just as the welcome chat opens the chooser, and a single failed request used to leave a new user on that error screen until they pressed Try again. The chooser's load and the boot-time account load now share one retry loop; only the chooser's gives up, so a failure that persists still reaches the screen.

The screen's Try again button now carries `data-e2e="retry-providers"`, so the Electron end-to-end test in mngr can press it the way a user would.
