Two e2e tests sidestep the cursor glide of Fortress v156, which the workspace's browser tests run on: it replays a recorded human cursor trajectory around a click that moved the pointer. The auto-compact test picks the chat's Off option and the new-chats default with the keyboard rather than a click, since the glide from the Auto-compact row to the option crossed the menu's other rows, which took the hover and changed the submenu the test was still reading. The phone-drawer test hovers a chat row before tapping it, since a glide whose points land between the press and its release starts back at the list button, which the drawer read as a leftward drag that dismissed it without picking the row.
