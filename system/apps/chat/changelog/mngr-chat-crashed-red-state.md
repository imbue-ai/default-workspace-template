A chat whose agent stopped in the middle of its work (its process died mid-turn, as an out-of-memory shed, a crash or a kill leaves it) now shows the red dot a failed chat shows in the chat list, and a banner over the composer saying "This chat stopped before it finished." with a Resume button. Resume sends the agent a message to carry on; nothing resumes on its own. The red state stays until a message reaches the agent or it starts a turn again, including for the main chat, which restarts on its own without its turn. The tray lists such a chat as failed.

A message sent to a stopped agent now says "Waking up…" while the agent starts again, instead of "Connecting to …".
