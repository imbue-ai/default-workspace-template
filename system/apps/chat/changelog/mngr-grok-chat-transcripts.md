The chat app can read a grok agent's transcript, though no chat runs on grok yet. A new `harnesses/grok` package parses grok's session logs into the chat's events, loads and tails every top-level session as one conversation and each subagent's session as its own, and derives the activity dot from mngr's lifecycle and the shared `active` marker, refined to a running tool by the transcript. It finds the sessions through mngr's grok session helpers, so the chat app now depends on `imbue-mngr-grok`.

The shared message classifier names grok's own prompts and notes: a wake turn grok starts for finished background work is a notice, a Stop hook's continuation note is the Stop hook feedback chip, and a turn grok's process exited during is a "Turn interrupted" chip. A failed call grok reports as `Hook denied:` shows no error snippet, and a grok `spawn_subagent` call renders as a sub-agent card.
