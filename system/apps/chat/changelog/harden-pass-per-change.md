- Fixed the flaky `test_websocket_replays_the_provisional_chats_before_the_agent_list`. The tests' WebSocket client (`simple_websocket` 1.1.0) handles only the accept from the socket read that completes its handshake. If the server's first messages arrived in that same read, they stayed unread, and since the server sends nothing more, `receive` timed out. The tests now use a client that also delivers those messages.
