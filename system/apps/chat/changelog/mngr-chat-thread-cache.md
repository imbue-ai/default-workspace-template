Opening a chat in the chat list now shows its conversation at once. Each chat is its own page and only the four most recently shown are kept alive, so opening any other chat used to start from nothing and show a loading shape until its transcript arrived. The page now keeps the last 60 events of each chat it has shown (up to 12 chats, for the current session only, in session storage) and draws them the moment a chat opens; the transcript request then replaces them, and paging older history waits for that request to land. Deleting a chat forgets its cached events.
