Opening a chat in the chat list now shows its conversation at once. Each chat is its own page and only the four most recently shown are kept alive, so opening any other chat used to start from nothing and show a loading shape until its transcript arrived. Each page now keeps a snapshot of just what fills its chat's screen (plus a quarter screen, sized by the text on screen, so one long message cannot make it large) in the window's session storage, and draws it the moment the chat opens; the transcript request then replaces it. Scrolled up before the transcript arrives, the page shows "Loading earlier messages..." until it does. All snapshots share one budget of 250,000 characters (about 1 MB of memory per window), and the chat viewed longest ago is dropped first. Deleting a chat drops its snapshot.
