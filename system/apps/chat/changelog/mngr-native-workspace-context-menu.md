A right-click on a chat in the rail now goes through the element menu, so in the Imbue Studio desktop app on macOS its Rename, Make main chat, Stop or Restart, and Delete rows appear in the app's native menu, beside the macOS items and the reference rows. Elsewhere the rail draws its row menu as before. The chat's frame tests hand their windows a `shell:handshake` with the new `drawsContextMenus` flag, as the shell now sends one.
