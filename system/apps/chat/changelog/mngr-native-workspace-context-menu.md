A right-click on a chat in the rail now goes through the element menu: its Rename, Make main chat, Stop or Restart, and Delete rows lead the menu, followed by the standard rows (Copy, for a selection) and the reference rows. A right-click in a row's rename field is the field's. The chat's frame tests hand their windows a `shell:handshake` with the new `drawsContextMenus` flag, as the shell now sends one.
