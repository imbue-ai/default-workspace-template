A codex chat that launches fast (fast mode on, or auto with its fast turns still to run) now gets fast mode from a model switch once its agent is up, for a new chat and for a handoff's successor, instead of from a speed tier in codex's config. A configured tier was re-sent every time codex's agent terminal attached, so an auto chat that had already dropped to standard speed went back to fast after a restart. Claude chats still launch fast through the `fast` create template.
