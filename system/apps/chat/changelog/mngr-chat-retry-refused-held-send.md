A new chat's first message is no longer lost when Claude is still starting. A message held while its agent comes up (a new chat's first message, the messages sent during a provider switch, and the ones a cancelled switch hands back) used to get one try. If mngr refused it, the chat app only logged the refusal: the agent never saw the message and the page kept showing the agent as thinking. A common case is Claude taking longer than mngr's 30-second readiness window to draw its input box on a first start. A refusal that typed nothing and can clear by itself (a blocked input, a harness not ready yet, a host too loaded to answer) is now tried again after 5, 10, 20 and 30 seconds. A send the agent may already hold, such as one a dialog blocked after Claude took it, is still never sent twice.
