- The interrupt route (`POST /api/chats/<id>/interrupt`) takes `{"only_if_idle": true}`: it then restarts the chat only if its agent has ended its turn, and otherwise answers 409 with `busy_with` saying what the chat is doing (working, waiting on a dialog, receiving a message, or holding queued messages). update-self uses it to restart the workspace's idle chats after an update that changes their harness, leaving busy ones for the user to decide about.
