Changes to how the main chat behaves when it moves or goes away:

- Making another chat the main chat no longer leaves a chat called "Main" below it. The chat that was the main chat, if it is still named "Main", is renamed to the next free "Chat N" marked as the former main chat ("Chat 7 (was: Main)"), and no new chat is numbered like it. The new list shows the new name at once. If the rename cannot be made, the chat keeps its old name. A chat you named yourself keeps its name, and the chat you make main keeps its own name too.

- Deleting the main chat no longer promotes another chat. A new, empty chat named "Main" takes its place at the top of the list, and the list opens on it. If another chat is already called "Main", the new one gets the next free "Chat N" instead. Deleting the last chat leaves a new empty "Main" too, and an empty main chat that a restart of the chat app drops is replaced the same way.

- The main chat no longer moves to the most recently messaged chat when the chat app restarts and its chat list comes back empty for a moment.
