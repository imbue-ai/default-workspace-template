A chat no longer says you signed out of its account right after you signed in. Signing in from the chat list's provider chooser (what a message typed with no provider yet leads to) launched the chat waiting under it, and that chat's own page, which had read the account list before the sign-in, took the new account for a removed one: the message box gave way to "You signed out of the account this chat runs on. Choose a provider to continue it on." and the model chip said "Not connected" until the chat was reopened. A chat page now reads the account list again when its chat names an account the page does not know, and shows the signed-out notice only when that fresh read still lacks it, when it removed the account itself, or when a send was refused because the account is gone.
