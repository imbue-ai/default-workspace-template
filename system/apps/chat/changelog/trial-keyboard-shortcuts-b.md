Send the message defaults to Enter alone: `meta` is the Command key on a Mac and the Control key elsewhere, so the Cmd/Ctrl pair of alternatives is gone. Two new shortcuts, rebindable on the Keyboard shortcuts screen: Start a new chat (⌥⌘N, Ctrl+Alt+N elsewhere), which starts one as the New chat button does, and Stop the agent (⌘., Ctrl+.), which interrupts the selected chat's turn. Both work in the chat list and in the open chat. The chat's shortcuts follow where the workspace runs, so a shortcut a browser keeps for itself never runs in a browser, and the workspace-wide shortcuts reach the shell from inside the open chat.
