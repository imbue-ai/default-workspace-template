A message sent while a chat switches provider no longer disappears from the page while the switch delivers it. The switch took each held message off its list as it handed it to the new agent, a few seconds before its turn reached the transcript, so for that moment only the "Starting Claude Code…" line was left. The chat app now keeps listing a delivered message (the switch record's new `delivered_sends`) until the switch is done, and the page shows it until its turn appears.

The status row ("Thinking…", a running tool, a switch's "Starting …") now stays under the message that opened the turn it reports, until that message reaches the conversation. It used to jump above the message when the agent started working before the message landed, and above a held message once a switch's marker reached the transcript. A message sent while the agent is already working on an earlier turn still waits below that turn's status row.
