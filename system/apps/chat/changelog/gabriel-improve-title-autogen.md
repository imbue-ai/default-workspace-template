Automatic chat names are more reliable. The small model that names a new chat from its first message used to answer that message instead of titling it ("what's 2+2?" named the chat "4", and a translation request named it "Bonjour"), or obey instructions inside it. Now the message is handed to the model as text to describe, with worked examples. In testing on Claude Haiku 5.5, five of twenty tricky opening messages went wrong this way before the change and none of 105 did after it.

Chat names are shorter and no longer repeat themselves. A name used to come in two halves that often said the same thing twice ("Map app: build a simple map application"), and was usually cut off in the chat list. A chat is now named with a short title such as "Simple map app", which fits the list whole. When another chat already has that name, the new one is numbered ("Simple map app 2") instead of keeping "Chat N".

Chats opened in Japanese, Chinese, Korean, Russian, Arabic or another non-Latin script now get a name. Such a name used to come back in that script, which a chat's name cannot hold, so the chat kept "Chat N". The name is now written in English for those messages, and in the message's own language without accents (for example "Vacances en Italie") for languages that use the Latin alphabet.

Claude chats are still named on the `haiku` alias, which the pinned Claude Code resolves to Claude Haiku 5.5, and Codex chats on the newest Luna model the account offers; neither needed a model change. When Haiku fails, a Claude chat is now retried only on the account's default model, no longer on Sonnet first, so a failure that no model can fix (a rate limit, an expired login) costs at most two calls instead of three.
