The new `POST /api/chats/<chat-id>/notification` (loopback only, `{"message", "title"}`) takes each notification the notify-user script sends and posts it to the shell as a `notification` bubble over the agent's tray entry, titled with the chat's title. Every other post to the tray's feed is now marked a `message`; the shell raises a bubble for one only on the clients of the people it mentions.
