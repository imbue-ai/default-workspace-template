The new `POST /api/chats/<chat-id>/notification` (loopback only, `{"message", "title"}`) takes each notification the notify-user script sends and posts it to the shell as a `notification` bubble over the agent's tray entry, titled with the chat's title. The agent's turns in an agent chat are no longer posted to the tray at all: each text block of a turn was its own post, so the agent's bubble filled with mid-turn narration. Its posts into a room still are, now naming the people they @-mention, whose clients raise them as a bubble. Every other post is marked a `message`, which the shell raises as a bubble only on the clients of the people it mentions.
