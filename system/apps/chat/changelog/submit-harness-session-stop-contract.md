- Every chat harness session now inherits one constructor from its base class, so a field the base adds can no longer go missing in a subclass and strand a harness switch or a Stop. The stop button's shared path now runs in tests through every file harness's own session class, and the sessions that list their fields by hand in `build` (codex, room) are checked for a declared field left unset, so a harness that drifts from the shared session setup fails in CI instead of in a chat.
