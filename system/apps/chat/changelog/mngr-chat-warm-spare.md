New chats start instantly. The chat app now keeps one spare agent already running on the account a new chat would use, hidden from the chat list, and hands it to the next new chat instead of starting an agent then. The chat appears at once, already running, so its first message no longer waits on "Connecting...". A replacement spare starts in the background right away. The spare follows changes to the default account, project and fast-mode setting, and is replaced if its process dies. It survives a restart of the chat app. Chats created with their own name, labels or a pre-minted chat id still start the way they did.
