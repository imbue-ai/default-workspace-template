A message the chat could not confirm reaching the agent is no longer typed into the agent a second time. The chat sends a message to the agent where it last saw it, and when that send failed for any reason, it looked the agent up again and sent the message again. When the first send had already typed the message (for example when Claude never confirmed taking it), the agent could receive the same message twice, minutes apart. The chat now looks the agent up and resends only when mngr reports that the agent was not where the chat looked, which means nothing was typed. Any other failure is reported as it is. This needs an mngr that reports that difference (`agent_not_found` and `submission_unconfirmed` send failures).
