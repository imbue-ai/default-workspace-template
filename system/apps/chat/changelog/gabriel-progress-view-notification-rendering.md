A system notification in a chat (a finished background task, Stop-hook feedback, a browser-fleet nudge) now shows up in the order it happened. The work the agent did after being woken used to be drawn inside the step above the notification, so nothing appeared below it and the spinner and latest caption sat higher up the page. And for the few seconds before the agent's first tool call, the reply it had given before the notification jumped below it. The timeline now breaks at a notification the way it does at a permission verdict: the reply stays above it, and the agent's next work renders below it, in the step carried over from before. A notification that lands during a handoff summary stays with the handoff, as before.
