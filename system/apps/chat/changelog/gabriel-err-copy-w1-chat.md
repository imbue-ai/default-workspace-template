Chat's failures read as sentences for people, with the server's text, command output and ids behind a collapsed "See details", and native alerts replaced by styled notices. Where a sentence asks for a bug report, a "Report a bug" button asks the workspace's shell to open Imbue Studio's bug report; it shows only where the shell says Imbue Studio can open one. The chat app's own sentences that ask for a bug report carry `reportable: true` beside their `user_facing_message`, so the chat's pages and the desktop's launcher toasts offer the button for them.

- Sending: a refused send says "Your message wasn't delivered. Your text is back in the box, so nothing was lost." (with "Try again. If this persists, report a bug." when no reason came back); a send nothing answered is titled "Your message may not have been sent", says Imbue Studio can't tell whether it was delivered, and offers no one-click resend, since the chat app does not drop a repeated message. Per-case sentences replace the agent tool's words for an unreachable agent, an agent still waking up (now told apart from one that couldn't be started), a signed-out account, a chat that was deleted (with Start a new chat), and a first send whose launch failed (Try again launches it again). The terminal advice became a "Turn on Source view" button. A message whose arrival never comes is captioned "This message may not have been delivered." A message sent to a chat from outside it (the launcher) that the chat refuses says why: chat still starting, a chat that is gone, a signed-out account, or else "Chat couldn't take this. Try again. If this persists, report a bug."

- Stop, switch, cancel and the queued-messages tap: each failure has its own sentence and a Try again; a switch that can't move the chat to that account offers Start a new chat; a cancel with nothing to cancel is a plain notice; a tap whose messages went through but whose nudge failed is titled "Queued messages sent" with Nudge the agent. The model menu's Stop agent and the chat list's Stop, Restart and Delete use styled notices; a delete nothing answered keeps its row marked until the list updates, and a half-done delete says so.

- Pages: a transcript or side conversation that won't load says so with Refresh or Try again; a stale side conversation offers Back to the chat; a chat the app no longer has says "This chat is no longer here." with Start a new chat; a stopped chat with nothing to show offers Start this chat; a failed create says "The agent for this chat couldn't be started..." with its output behind See details and a Remove this chat button (Delete now drops a chat that never became an agent); an address chat no longer serves gets a page with a way back. When the chat's frontend is missing, its page says "Chat isn't available in this workspace right now. Restart the workspace. If this persists, report a bug." with a Report a bug button (the chat app now serves the shell's app contract at `/_static/app_contract.js` for it); it offers no agent, since starting one would open this same page.

- Transcript: a failed turn leads with a plain line, keeps a provider's prose and moves raw bodies behind See details; an ordinary 400 from the provider is no longer read as a dead account; a failed or killed background task gets a warning mark and "Background task failed"; a permission request that ended in an error says the agent didn't get permission, with Ask the agent to try again.

- Sign-in and providers: the provider list and sign-in failures say what happened instead of "[object Object]" or "null"; a provider tool's own failure line goes behind See details under "{Provider} didn't accept that sign-in."; sign-in start failures say Imbue Studio couldn't start the sign-in; the chip with no provider reads "Add a provider".

- Smaller copy: account lookups, create refusals, the switch's phase and retry refusals, Force's failed restart, a model pick the chat app refused, the stopped terminal face, the model list that won't load, the declined slash command and the declined /compact, the /login notice, and the secret card's refusals (with a 2000-character limit on the decline note).
