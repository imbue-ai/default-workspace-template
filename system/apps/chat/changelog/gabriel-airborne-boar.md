The "switch to another provider" link under a failed chat turn can now start the new chat on an account that is already signed in. It used to open the provider chooser with the signed-in accounts listed but not selectable, so the only ways forward were signing in to a new provider or signing in again to an existing one. When the chooser is opened to pick an account (that link, "+ Add a provider" in the composer's provider menu, or a new chat waiting for an account), clicking a signed-in account now uses it directly. The account the failed chat was running on stays listed, marked "Not working" and not pickable, and its "Sign in again" and remove buttons still work. Opened any other way, the chooser lists signed-in accounts as before.
