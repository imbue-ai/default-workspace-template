Imbue Studio's note that the user turned an app-data source off or back on, that its sync was stopped because Full Disk Access is off, or that Full Disk Access is back on (ending in `(app-data-access: revoked)`, `restored`, `sync_stopped`, or `readable_again`), shows as a notice, "App data turned off", "App data turned back on", "App data sync stopped", or "App data readable again", rather than as the user's own message.

A `full-disk-access` permission request's card is titled "Full Disk Access".
