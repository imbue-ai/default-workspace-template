Imbue Studio's note that the user turned an app-data source off or back on, or that its sync was stopped because Full Disk Access is off (ending in `(app-data-access: revoked)`, `restored`, or `sync_stopped`), shows as a notice, "App data turned off", "App data turned back on", or "App data sync stopped", rather than as the user's own message.

A `full-disk-access` permission request's card is titled "Full Disk Access".
