- Starting a new chat no longer asks you to pick an AI provider when one is already set up. The New chat button, and a new chat's first message, decided which account to start on from the chat page's account list. They did that even before the list had loaded, took the empty list for "nothing signed in", and opened the provider chooser. Both now wait for the list first. The chooser only appears when no provider is signed in.

- The Chat window is never open empty. With nothing selected, it shows your most recent chat. With no chats at all, it shows a new chat ready to type, which starts on your configured provider when you send its first message. Nothing is created before that message, and several Chat windows opening empty at once share the one new chat. A new route, `POST /api/chats/awaiting`, hands the chat list that waiting chat. The phone layout still shows the list alone when nothing is selected.
