The provider chooser that a chat with nothing signed in asks for now belongs to the chat list rather than to the chat's page. When the chat on screen is waiting for its first message and no account exists, the chat list opens the chooser over everything it shows, and its "Choose a provider" button opens the same one. The chooser stays open when the chat on screen changes, so when the seeded welcome chat replaces the chat an empty list opened, a sign-in the user has already started is kept and is not drawn again, and no second chooser opens behind it. The sign-in launches whichever chat is waiting on screen when it finishes. A chat page opened on its own, outside the chat list, still opens its own chooser.
