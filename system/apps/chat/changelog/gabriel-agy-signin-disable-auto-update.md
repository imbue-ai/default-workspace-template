Signing in to Google (Antigravity) no longer upgrades the workspace's agy. Every agy run outside an agent, including a signed-out `agy models`, starts a background updater that replaces the binary it ran from with Google's latest release. The sign-in and the `agy models` check that follows it ran with that updater on, so one sign-in swapped the image's pinned `/usr/local/bin/agy` out from under every Antigravity chat after it. Both now run with `AGY_CLI_DISABLE_AUTO_UPDATE=true`, the same switch mngr sets for Antigravity agents.
