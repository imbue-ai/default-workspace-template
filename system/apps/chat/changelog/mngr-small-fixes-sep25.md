The provider chooser describes Opencode Go and OpenRouter in our own words instead of echoing the providers' marketing, and no longer quotes their prices: Opencode Go is "A subscription to a selection of open models." and OpenRouter is "Models from many providers on one key." The Opencode Go key screen now reads "One key for every model on your Opencode Go subscription."

A message you queue while a Claude agent is working no longer disappears when the agent's reply comes in. The agent looks idle the moment its reply lands, but Claude only picks up the queued message after its end-of-turn hooks run; in that gap the chat used to drop the message and show it again once its turn started. It now stays below the reply, shown as being sent, until its turn arrives. A message still queued 10 seconds after the agent went idle is treated as stranded and removed.

The row under the composer (the model and provider on the left, Source view on the right) now always takes up the same space, so the composer no longer shifts when the row fills in. A new chat shows the provider it will start on from the moment it opens, instead of an empty row until its agent exists. With no provider signed in, the row says "Not connected", and pressing it opens the provider chooser.

A chat whose account is no longer signed in (typically: its account was signed out, then signed in again as a new account) no longer stays stuck. Its "Sign in again" link used to try to re-authenticate the account that was gone, or open a plain sign-in that left the chat unbound, so the chat kept saying it was not signed in however often you signed in. Now signing in, or picking an account already signed in, moves the chat onto that account. The model menu's Provider row for such a chat reads "No account" with "Pick one to move this chat to it" instead of "Not signed in", which contradicted the signed-in accounts listed right under it.
