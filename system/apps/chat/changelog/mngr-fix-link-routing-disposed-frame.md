- A custom-scheme link in a message (`[channel](slack://channel?id=C1)`, `sms:`) is now a link, opened by the app of the workspace registered for its scheme or else by the app of the user's system it belongs to. Before, it was unwrapped to its text. A file and line (`q4.md:12`) or a host and port with no scheme (`localhost:3000/app`) written as a link target still renders as text, by the shared link classifier's rule, and so does a custom-scheme link of that shape (`sms:5551234`; `sms:+15551234` is a link).
