A message with attached files no longer shows a "See attachment here:" label in its bubble: the images and file links appear on their own under your text. The agent still receives the label with the file paths.

An image you just sent shows in its bubble at once, drawn from the copy already in your browser; each chat keeps up to 25 MB of these copies and loads older ones from the workspace. An image that still has to load holds a box with a faint picture outline and a slow sweep of light, then fades in once it arrives, so a message that is only an image no longer shows as an empty bubble. Images uploaded from now on record their width and height in their stored path, so that box takes the image's own shape and nothing jumps when it loads, on any device; older uploads keep a fixed-shape box. The bubble shown the moment you press send draws its attachments the same way, instead of the raw file-path text. An SVG that declares only its shape (a viewBox) and no size now shows in your bubble instead of an empty one.
