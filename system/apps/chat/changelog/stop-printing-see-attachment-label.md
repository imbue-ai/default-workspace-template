A message with attached files no longer shows a "See attachment here:" label in its bubble: the images and file links appear on their own under your text. The agent still receives the label with the file paths.

An image you just sent shows in its bubble at once, at its own size, drawn from the copy already in your browser. An image that still has to load holds a shaded box until it does, so a message that is only an image no longer shows as an empty bubble. The bubble shown the moment you press send draws its attachments the same way, instead of the raw file-path text.
