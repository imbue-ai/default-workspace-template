The "switch to another provider" link under a failed chat turn now moves that chat to the account you pick, the same way the provider menu does, instead of opening a new chat. Picking an account on another harness opens the switch dialog, so the conversation is handed off; picking another account on the same harness and provider arms a rebind, which keeps the agent and its conversation. Either way your next message carries out the switch. The link now appears only once the page has loaded the chat, so the chooser always knows which account to mark "Not working". "+ Add a provider" in the composer's provider menu now marks the chat's current account "Current" and does not let you pick it.
