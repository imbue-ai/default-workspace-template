A Codex reply now shows in the chat while it is being written, as a Claude reply already does. Codex writes an agent message to its rollout file only once the whole message is finished, so on a reply of about 300 words the chat showed nothing for roughly 14 seconds while the agent's terminal was already streaming it. The chat app's live connection to the agent's Codex app-server already hears the reply as it is streamed (its `item/agentMessage/delta` notifications); the app now keeps the message being written from them, and while the chat is open in a window that is shown and focused, the page shows it at the end of the transcript until the real reply, matched by its message id, replaces it. Nothing extra is read for a chat in the background.
