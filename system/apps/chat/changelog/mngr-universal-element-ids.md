Every chat page and the chat root draw the element context menu (`docs/system/blueprint/element-reference-menu/`): a chat page drafts a reference into its own composer, the root into the selected chat's composer (else through the shell), a sub-agent view through the shell (its `shell:draft-text` relayed by the root), and the rail's row menu ends with the reference rows. A reference entering a composer is attached as a `REF-<id>.json` file through the ordinary upload path, with a chip that says what it points at, and the prompt in the composer names it ("Explain what I attached in REF-..."). Ready attachments now persist across a reload beside the draft text.
