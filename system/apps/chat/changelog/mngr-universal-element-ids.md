Every chat page and the chat root draw the element context menu (`docs/system/blueprint/element-reference-menu/`): a chat page drafts a reference into its own composer, the root into the selected chat's composer (else through the shell), a sub-agent view through the shell (its `shell:draft-text` relayed by the root), and the rail's row menu ends with the reference rows. `POST /api/element-references` writes a reference too large for a composer's block to a file under `element_references/` in the temporary directory, and the frontend swaps the block for the pointer form wherever a draft enters a composer.
