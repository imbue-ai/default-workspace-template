A Pi or Antigravity reply now shows in the chat while it is being written, as Claude and Codex replies already do. Pi writes an assistant message to its session file only once the message is finished; mngr's pi lifecycle extension now keeps the text streamed so far in `pi_reply_draft`, for any model pi runs, and the chat reads it. Antigravity writes a planner step's text into its conversation store while the step is still generating, which the chat used to skip until the step finished; it now shows that text at the end of the transcript until the finished reply replaces it. As before, only a chat open in a window that is shown and focused is read. OpenCode has no chat transcript yet, so it has no draft either.
