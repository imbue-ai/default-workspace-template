The chat's send shortcut becomes rebindable (user-profile-state spec, phase 3C): the app's `app.toml` declares the one `send-message` action under `[[keybindings]]` (default Enter, with Ctrl/Cmd+Enter also sending), a new `/api/keybindings/me` route answers its resolved chords, and the composer matches the resolved chords instead of a hard-coded Enter, re-fetched when the shell announces a change (`shell:keybindings-changed`, forwarded to the inner chat pages).

The gateway access the chat app's backend reads from its environment (`latchkey_gateway.py`) moves into the new `latchkey-access` library, shared with the shell; the call sites import `GatewayAccess` from there and the module is gone.
