Markdown in a chat stays inside the bubble or column it is drawn in, on a phone as on a desktop, so a message no longer makes the whole conversation scroll sideways. A table wider than its bubble scrolls sideways in a box of its own, at least 7em wide for each of its columns so their words stay readable, and it still fills the bubble when it fits. A URL or key with nowhere to break wraps wherever markdown is drawn (including a step's narration and its opened work), and a link or a piece of code may break anywhere inside a table cell. A video, audio player or SVG a message carries as raw HTML is capped at the column's width, as images already were. A table in a running step's narration draws its text in the narration's muted colour rather than the moving shimmer, which left its header cells blank and, in Safari, the whole table.
