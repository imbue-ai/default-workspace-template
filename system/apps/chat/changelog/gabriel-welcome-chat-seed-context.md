The first agent of a welcome chat now starts with the conversation that chat opened on.

A workspace's first chat is seeded with the conversation the Mind app had before the workspace existed, and the page showed all of it. The agent the user's first message started did not: it was launched with that message alone. So a reply like "1", picking one of the numbered options the last seeded turn offered, reached an agent that had never read the options and could not tell which one was meant.

The launch now carries the seeded conversation ahead of the user's words, in one message, so the agent answers the turn in its context. The chat still shows only what the user typed -- the context block is stripped for display and never appears as a bubble.
