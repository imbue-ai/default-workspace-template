The chat app's test suite now passes inside a real workspace. It plants stub binaries in a temp directory and hands them to code that runs them, but a workspace container mounts `/tmp` `noexec` -- and because a `PATH` entry that cannot be executed is skipped rather than reported, those runs fell through to the real `mngr` and the real `claude` instead of failing outright. 45 tests failed there, none of them naming the reason, while CI stayed green. The app carries its own pytest config and so roots separately from the repo, which is why it did not inherit the repo-wide fix; it now has its own root `conftest.py` calling the same shared probe. Measured in a staging workspace container: 45 failed / 1660 passed becomes 1705 passed, in half the wall time.
