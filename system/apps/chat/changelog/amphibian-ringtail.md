A turn's tool calls now read as one message instead of one message per call. A harness emits an event per model response, so the sentence an agent says before it works and the calls that carry that work out arrive separately -- and each became its own top-level row, stacking one lone chip per row a full message gap below the last. A row is now a run: one head event plus every chip-only event after it, so a turn lays out as the one message it is (the sentence, the chips tucked under it, then the result as its own message). Prose ends a run and heads the next, as does a sub-agent card. The chip row's spacing is deliberately uneven -- tight above, where it belongs to the line that introduces it, and a full message gap below, where the agent has moved on to what it found -- and collapses at a message's edges so it never adds to the message's own margin. The row also stops on the same edge as the prose now, including inside a progress block, which was the one place on that thread where a reply ran the full column while everything beside it stopped at the gutter.

A failed call is no longer painted red. Whatever the failure means, the agent explains it in prose a line or two below, which is the form a reader can act on; colour on a chip now says only which one is open.

Opening a tool call gives you a header naming the call with a control to close it, a dashed seam between the input and the output, and -- for an output past 20 lines, or past 2000 characters when it has no line breaks at all -- its first part with a "View all N lines" control rather than a whole log dumped into the transcript. Unfolding one is forgotten when the chip is closed, so reopening it starts short again.

A path named in a tool chip keeps a trailing slash when it had one, so a directory reads as `chat/` rather than as a file with no extension. The slash is kept, never added: a directory written without one still reads bare, since nothing else in the path distinguishes the two.
