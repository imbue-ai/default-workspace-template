New chats name themselves from their first message. A chat still starts as "Chat N"; once its first message is sent, a small model on the chat's own account (Claude Haiku, run outside the chat so nothing appears in its transcript) suggests a name in the form "Short name: brief description" -- for example "Rome trip: plan five days in May" -- and the chat is renamed to it the way a rename from the chat list would. The name is set once and does not change as the conversation moves on. An opening with no clear subject ("hi") keeps "Chat N" and the next message is tried instead, up to three messages. A chat the user or an agent has already named, or a seeded "Welcome" chat, is never renamed. Chats on Codex, Pi, Antigravity and OpenCode keep "Chat N" for now.

Signing out of a provider account (removing it) now actually stops its chats from being used. Before, the chat's menu said "No account" but the chat kept answering, because its agent still held the credential it had loaded. Now a chat whose account was removed takes no more messages: in place of the message box it says you signed out of its account and offers "Choose a provider", which moves the chat to the account you pick. A turn already in progress still finishes, and the chat's history stays. The Remove account dialog says what will happen.
