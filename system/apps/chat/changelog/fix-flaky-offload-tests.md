Hardened the chat file watcher against OS thread exhaustion: when the OS refuses a new thread midway through starting a directory watch (watchdog starts the inotify helper thread and only then the emitter thread), the watcher now reaps the orphaned helper thread and keeps running so it retries, instead of leaking the thread and dropping the watch. Also fixed an intermittent failure in the auto-compact-notice end-to-end test by waiting for the chat transcript to load before triggering the compaction, so the streamed compaction event is no longer dropped before the page has subscribed.
