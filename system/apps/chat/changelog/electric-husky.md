The report that `system/scripts/run_in_background.py` sends an agent when its background command finishes shows as a one-line notice ("Background task: <what it was> (finished)"), like claude's own background-task notices, instead of as a message the user seems to have typed. The full report still reaches the agent. A report waiting in the chat's queue, because the agent is still mid-turn, shows as the same notice rather than as its raw text. Stopping the agent no longer drops a queued report into your composer: it is sent straight back to the agent, which starts its next turn with it. It only lands in the composer if that send fails, so it is never lost. When codex, pi or antigravity flush their queue as one message, a report merged into your turn is hidden from the bubble, which shows only your words, and reports flushed together with nothing else show as one notice naming each; the agent still gets every report.
