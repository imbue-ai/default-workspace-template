The chat transcript is restyled and an agent's tool calls now render as a row of inline chips instead of a stack of full-width blocks.

The agent's side of the conversation stops short of the column's right edge (a new `--width-agent-gutter`): its prose, its wrap-up reply, and the timeline's task rows, so a reply reads as one side of a conversation rather than full-bleed text. An opened-up timeline step drops the left rule and indent that read as a nested timeline. A task title takes its colour from its state -- only a closed one greys out, and the live one shimmers together with its narration -- and the status bullets soften (a done step's check is the accent pulled toward grey, a pending one sits below faint, the live spinner runs a thinner ring). The bullet is re-centred on the title's x-height so it lines up across rows regardless of the glyphs a title contains. Type moves back onto the design-system scale (body titles, helper captions) from the sizes the prototype had invented.

A turn's tool calls collapse into one wrapping row of small chips, each a glyph and a short phrase, and only the chip a reader picks opens its detail below it. The detail opens directly under its own chip even when the row has wrapped onto several lines. A run of calls merges into one row even across the separate assistant messages a harness emits, so a sequence reads as a single line of what the agent did; a sub-agent call and a permission request stay as their own cards. What a chip says comes from the agent's own words when the tool records them (a shell command's or a delegation's `description`), otherwise a past-tense verb and the thing the call acted on -- a file by its name, a search by what it looked for. The name is never inferred for a tool that records no reason; those chips read from the live activity strip's present-tense caption, then the bare tool name as a last resort. Opening a chip shows the tool's input as readable text rather than the raw JSON object, led by the verb where the chip is showing the note instead, with the field the chip already said dropped so it is not printed twice. Claude's parser stamps `action_verb`, `action_target`, and `action_note` onto each tool call; the other harnesses fall back to their existing caption.
