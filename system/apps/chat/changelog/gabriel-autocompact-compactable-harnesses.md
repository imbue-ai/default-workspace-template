The chat app's background autocompact sweep now only runs `mngr autocompact run` for chats on a harness mngr can compact, which today is Claude, Codex and pi. It used to run it every minute for every running chat, so each opencode or antigravity chat started a full mngr process (agent discovery included) once a minute, only for mngr to refuse with "does not support context compaction". On memory-tight workspaces that is a real cost, and it filled `chat-stderr.log` with thousands of those lines. Each harness now declares `supports_compaction` in the harness registry, and a test keeps that flag in step with which mngr agent classes implement compaction.
