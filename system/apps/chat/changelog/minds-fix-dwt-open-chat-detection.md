Opening a chat's notification in the Mind app now shows the chat in the full chat window (the chat list beside the chat): a window already showing the chat is brought forward, else the chat is selected in the chat list window on screen, else in the pinned one, else a new chat list window opens with it selected. The chat app now handles the Mind app's `minds:focus-chat` itself: its manifest registers the message, and the new `POST /api/focus-chat` asks the shell's `show` op for the chat list with the chat selected, counting the chat's own page as already showing it. A refusal from the shell is reported as an error rather than a success.
