The chat app no longer retains the `mngr observe --stream-events` subprocess's entire output in memory for the life of the process. The stream carries full agent-state JSONL (hundreds of megabytes per day on an active host), and the default output accumulation of the background-process runner kept every line ever printed, which was the chat app's dominant long-run memory growth -- multi-gigabyte RSS after days of uptime. The subprocess now runs with accumulation off; the observe watchdog's exit diagnostic reads from a new bounded tail of recent stderr lines instead of the full recorded output.
