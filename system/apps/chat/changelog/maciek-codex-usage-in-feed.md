A codex chat's assistant messages carry token usage, as claude and pi messages already do. Each model response's usage (from the rollout's `token_count`) lands on that response's last assistant message in the same `usage` shape the other harnesses use: `input_tokens` excludes the cached and cache-written tokens, which are reported as `cache_read_tokens` and `cache_write_tokens`, and `output_tokens` includes reasoning. Summed over a chat, the usage matches codex's own session total.

A message still appears as soon as codex writes it. Its usage arrives once the response finishes, after any tool it called has returned, and the message is re-sent with the usage filled in. A message whose response never reported usage (an interrupted one, or a codex that writes no `token_count`) keeps `usage: null`.
