Experimental: every message sent to a chat is first checked by Jev (TypeSafe's decision model) with one question, whether it is a quick look-and-feel change to an app. When it is, the chat app forwards the message word for word to a workspace-wide quick-change chat running on Sonnet, which edits the live app and refreshes its window, and the chat's own agent receives the message with a routing note telling it not to make the change itself (the page shows only the user's words). When Jev says no, cannot be reached, or takes longer than 10 seconds, the message is delivered unchanged. Jev is reached with an OpenRouter key in the chat app's data folder (`openrouter_api_key`) when one is there, else through the account's Imbue proxy. Every decision and forward is appended to `quick_change_routing.jsonl` in the chat app's data folder.
