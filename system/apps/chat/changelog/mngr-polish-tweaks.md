A new chat's auto fast mode now runs fast for the first 2 of your turns instead of 5 before switching to standard speed (the limit is still adjustable in the model picker).

The one-time notice shown when that switch first happens now reads "Fast mode is off now: this chat ran fast for its first N turns. Change this in the model picker." and, for a Claude Code chat only, adds "Fast mode always uses API billing, not subscription usage."
