The chat manifest references the paths outside the app that the chat suite reads or runs, so a change to any of them runs the chat suite in a harden gate: `.mngr/settings.toml`, which holds the create template every chat launch stacks on; the `connect-external-service` skill, whose `request_secret.py` files secret requests through the chat's `/api/secret-requests`; `.agents/shared/references/continue-chat.md`, the handoff prompt template; and `system/scripts/message_chat.py`, `claude_status_line.sh` and `with_secrets.py`.
