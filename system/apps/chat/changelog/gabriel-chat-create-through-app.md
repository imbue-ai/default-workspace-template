`POST /api/chats/create` can now make a chat on a caller's terms from outside the chat page: `labels` puts extra labels on the chat's agent (`auto_open=true` has the shell surface its window; the labels the app sets itself are refused), `is_installation_check_skipped` waves the claude version check the in-container mngr would otherwise fail the create on (`message_chat.py --create` sends it on every create, so the update chat that repairs a pin mismatch can still be made), and `should_wait` holds the answer until `mngr create` has finished, answering with the chat when it landed, a 500 carrying the create's own reason when it failed, or a 504 when it is still running at the wait's ceiling. Before this, a chat the Minds app started from outside (the assist and update chats) had to be a bare `mngr create` inside the workspace, which the chat app only learned about from the observe stream.
