A stop or shoulder-tap key press that the agent refused, or that failed after reaching it, is no longer pressed a second time at a freshly looked-up location, where it could cancel a turn the agent had started meanwhile or press an interrupt key twice. The chat looks the agent up again only when the press reached no agent: it was not where the chat expected, or it was not running there. A stop whose key press fails falls back to its restart, as before. This applies to every harness.
