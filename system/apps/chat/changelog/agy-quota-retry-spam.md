An agy chat that runs out of Gemini usage quota no longer fills its transcript with repeats of "The stream was interrupted. Please continue the task you were working on." That sentence is agy's own auto-continue nudge -- a constant compiled into the agy binary, which agy re-prompts itself with whenever a model stream dies -- so it is now suppressed the way the claude harness already suppresses its own interrupt sentinels. Against a persistent failure agy retries indefinitely, and every retry was reaching the user as another message.

The error those repeats were burying is now actionable: agy reports a spent subscription as `Individual quota reached. Please upgrade your subscription to increase your limits. Resets in <duration>.`, which carries neither an HTTP status nor a structured error type and so matched nothing in the shared vocabularies. It joins the entitlement family in `auth_errors`, alongside claude's credit balance and codex's `usage_limit_exceeded`, so the chat renders it as an auth-family failure with a re-auth action instead of as ordinary assistant prose. Google's per-minute "Quota exceeded for quota metric ..." is deliberately still excluded -- that one clears on its own.
