A Claude or ChatGPT browser sign-in no longer drops to the paste-a-code flow just because the port the CLI drew for its callback is already in use on the user's machine, often by a Docker container's published SSH port. When Imbue Studio says the port is taken, the chooser starts the same sign-in again, which draws a fresh port, up to three times. Only then does it fall back as before. Any other reason the desktop app cannot relay still falls back at once.
