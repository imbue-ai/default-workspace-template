A Claude browser sign-in no longer drops to the paste-a-code flow just because the port Claude's CLI drew for its callback is already in use on the user's machine, often by a Docker container's published SSH port. When Imbue Studio says the port is taken, the chooser starts the same sign-in again, which draws a fresh port, trying up to three ports in all before it falls back as before. ChatGPT's CLI listens on a fixed port, so its sign-in usually still falls back to the one-time code. Any other reason the desktop app cannot relay still falls back at once.
