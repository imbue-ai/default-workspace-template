A message is no longer delivered twice when the chat cannot confirm its delivery, and a message sent to a Claude chat while it is still starting is no longer reported as possibly unsent, or lost when its process exits.

- A message the chat could not confirm reaching the agent is no longer typed into the agent a second time: the chat looks the agent up and sends again only when mngr reports nothing was typed (`agent_not_found`). For an unconfirmed send (`submission_unconfirmed`) the notice reads "Couldn't confirm your message arrived", says the agent may already have it, and offers Cancel and Send again, without Force or mngr's diagnostic text. The message goes back in the composer, and comes back out once the agent's turn for it shows up.

- A message sent to a Claude chat while it is still starting is no longer reported as possibly unsent. Claude takes a message at once but writes it down only after its startup hooks finish; mngr now reads Claude's screen when it has waited out its window, so a message Claude holds counts as sent, and one Claude never took is cleared from its input box and sent again automatically, once, where the agent is (`not_submitted`). The unconfirmed notice now remains only where the screen cannot settle a send: Codex, Antigravity and pi chats, and the rare Claude screen that shows neither.

- A message a Claude chat showed but had not written down yet (while its startup hooks run) is no longer lost when the agent's process exits before it does, from a crash or a kill. The chat reads the agent's final transcript and sends again, once, each delivered message sent after the last message it wrote down, restarting the agent to do so. Nothing is sent again after a deliberate stop, after Stop takes the turn back, to a chat that is switching or has moved on, for a message older than half an hour, or for a message that was itself such a resend.
