The chat's pages (the chats list, a chat, the not-built placeholder) now carry a `Content-Security-Policy`: scripts only from the chat's own origin, fetches and streams only to the chat, frames of any http(s) page (the terminal it shows), images, video and audio from anywhere (markdown embeds them, and the sanitizer admits all three tags), no plugins. An SVG served inline keeps the stricter policy it already had; a file download, never a page, carries none, and an HTML attachment previewed from `data/uploads/` now gets the page policy like any other page.
