In a shared workspace, a message that has not reached the agent yet is now drawn under its sender, like the turn it becomes. Previously a visitor's queued message showed the raw `[from: <name>]` prefix the agent is handed, in the viewer's own bubble on the right, until the agent took it. Sends held while a chat is still being created showed the prefix the same way, and they and sends held while a chat switches harness or account showed every sender's message as the viewer's own.

The chat snapshot now joins each queued entry and each held send to the chat's author annotations: queued entries the way a transcript turn is joined, held sends by their message id. Each one carries `author` and `author_name`, and a queued entry carries the words behind the prefix as its `display_body`. The provisional chat's `held_sends` are now sent as they render (the words, the display decision and the author) rather than as the stored record. Queued, held and returned-after-a-switch bubbles all draw through the same own-or-other bubble a transcript turn uses.
