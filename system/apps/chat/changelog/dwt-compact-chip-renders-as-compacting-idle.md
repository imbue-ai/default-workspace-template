An idle compaction in a Claude chat no longer shows the `/compact` the idle sweep sent as a user bubble: the command shows on the "Compacting while idle…" chip instead, which opens on why it ran and then that `/compact`. That `/compact` no longer counts as a new turn either, so the last turn's "Done" mark stays once the compaction lands, and it does not use up one of auto fast mode's turns. The "Compacted" chip opens on why it ran and then the summary; the start chip of every compaction no longer repeats the summary.
