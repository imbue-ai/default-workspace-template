When the chat cannot confirm that the agent received a message, its notice no longer offers a plain Retry or Force. mngr reports this case (`submission_unconfirmed`) when the message was typed into the agent and Enter was pressed but nothing confirmed the agent took it, so the agent may already have it and sending it again could deliver it twice. The notice is titled "Couldn't confirm your message arrived", says the agent may already have the message and to check its terminal before sending it again, and offers Cancel and Send again. Force is not offered, since restarting could cut off a turn the agent is already running on that message and then send it a second time. The notice no longer shows mngr's diagnostic text (which included the whole terminal screen) for this case. The message is still put back in the composer. This needs an mngr that reports `submission_unconfirmed`.
