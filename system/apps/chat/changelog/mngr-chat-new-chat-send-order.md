A message sent while a new chat is still starting now stays where it was typed instead of sitting at the bottom of the "Starting the chat..." screen and jumping to the top once the chat came up. The starting screen lays it out exactly as the empty transcript that follows does.

New chats are no longer greeted: a chat started with nothing to say is created without a first message and waits for the user's, so a message sent during startup is no longer queued behind a `/welcome` turn. Older chats' transcripts still hide the `/welcome` turn they began with.
