Renaming a chat to a name another chat already has now keeps you in the name field, with a red line under it saying so ("A chat named "Alpha" already exists. Pick another name."). Keep editing, or press Escape to go back to the old name. No dialog appears for this.

Any other refused rename, delete or New chat from the chat list now says why in one dialog over the list, in place of the browser alert. The dialog gives a fixed line saying what did not happen, with the chat app's reason under it, or says the workspace didn't answer, so it isn't known whether it happened. Rename again reopens the name field on what you typed; Try again repeats the delete. A dialog that comes while you are typing a chat's name waits until you finish.

Before, a refused rename showed its reason only as a tooltip on a red-ringed field, and showed nothing at all when another chat's name field was open.
