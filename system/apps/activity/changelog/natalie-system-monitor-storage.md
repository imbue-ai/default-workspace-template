System Monitor gains a Storage tab: what is taking up disk space, grouped into your files, chats and agents, app data, installed tools, download caches and logs, with the total of the measured folders, each group's folders and the largest folders. It measures the first time the tab opens and then only when you ask, never on a timer (`du` walks every file), and shows no disk size or quota, because the workspace cannot read its quota. The Memory and Storage tabs follow the accessible tabs pattern (arrow keys move between them).
