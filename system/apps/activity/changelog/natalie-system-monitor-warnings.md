System Monitor warns when memory has stayed tight: after five minutes or more at or above "getting tight" (five readings a minute apart, none missed), the memory tab says for how long, since when and the peak, and that stopping something unused makes room; for an hour after it eases, a quieter line says it was tight earlier. The warning is worked out from the once-a-minute history plus the live reading each time the page refreshes, so it never lingers after memory recovers, and it is shown while System Monitor is open (nothing notifies you while it is closed).
