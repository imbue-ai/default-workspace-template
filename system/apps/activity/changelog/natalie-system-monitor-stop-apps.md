System Monitor can stop an app: a running app's row offers Stop, which asks first and then quits the app through the desktop's own Quit, so its windows close, it stops using memory, and it starts again the next time it is opened. It is not offered for the apps the workspace keeps running (chat, terminal), for the browser, which shows "Running because agents use it" because agents drive it, or for System Monitor itself. The backend checks the same rule again before forwarding the request, and a stopped app's row now reads "Not running · starts when you open it". A preview of a proposed System Monitor change shows the live workspace but offers no Stop or Start, and its backend refuses them, so trying a change never closes your real windows or stops your chats.
