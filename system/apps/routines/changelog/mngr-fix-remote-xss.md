The Routines app installs the request guard ahead of its routes (`app_schema.request_guard`): a request the workspace's own browser marks as a page of another origin's is refused with 403, and a request with no `X-Imbue-Identity` header reads as the owner's only from loopback under a loopback `Host`, so a page shown on the Screen's browser can no longer start, reschedule or remove a routine as the owner (imbue-ai/mngr-internal#2816).
