A run's log that could not be read is told the way every other failed request in the workspace is, through the shared reader in `workspace_ui`, so a request nothing answered says so. A note that says the same as one already on screen replaces it rather than stacking a copy beside it.

A chat the list's "describe a routine" field could not start (no app can start one, the launch failed) is told in a note at the foot of the page, where the desktop used to toast it.
