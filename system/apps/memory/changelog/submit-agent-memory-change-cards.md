New built-in app: Memory, the notes the agent remembers about the user across chats, to view and edit, and every change an agent made to them, with Undo (port 8070, the `memory-app` package, a root workspace member). It reads and writes the notes and the change records through the `agent_memory` library the chat's memory cards use, so an Undo here and one on a card are the same Undo, and a save here is never shown as the agent's change. The chat's cards link a note here as `/?note=<id>`.
