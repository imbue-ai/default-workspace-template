New built-in app: Memory, the notes the agent remembers about the user across chats, to view and edit (port 8070, the `memory-app` package, a root workspace member), with a desktop shortcut and a place in the launcher after Routines. It reads and writes the notes through the `agent_memory` library the chat's memory cards use, so a save here is never shown as the agent's change; the agent's changes are shown and undone on the cards. The chat's cards link a note here as `/?note=<id>`, and the window reopens on the note it was showing.
