A new icon: the prompt as a two-layer tile.

- The terminal's icon is Comfort on Envy, drawn on Gleb's Copyboard and built to the rules in `docs/system/app-icons.md` -- a flat 48x48 background under one fill-only glyph inside a centred 32x32 box, with the 32 per cent corner radius the shell's `--desk-icon-radius` computes. It replaces the `currentColor` line glyph, so the terminal wears its own colours wherever the workspace draws it.
