The terminal serves the shell's app contract module from its own origin (`GET /_static/app_contract.js`, the file the shell's frontend build writes), and the wrapper page imports it by that same-origin path. It used to import the module from the shell's origin, and a module import is a fetch without cookies, which the desktop client's forwarder answers with a bare 403: the browser reported a CORS error, the wrapper never connected to the shell, and a terminal window reported no path or title, never raised on focus, and ignored `shell:navigate`. The page no longer needs the shell's origin label. A workspace whose shell frontend is not built gets a 404 naming the missing file.
