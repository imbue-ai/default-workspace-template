A new built-in app, Skills (`skills`): one read-only window over every skill the workspace's agents have. The list shows each skill's name, where it came from and its description, with a search field, a filter per origin, and markers for unsaved changes and layout problems; a skill's page adds when it was last saved, the lock file recording its install source, its files, and its `SKILL.md` exactly as written (shown as text, since an installed skill is untrusted content). It reads `.agents/skills/` through the skills catalog on every request, serves on 8060, stops when no window shows it, sits between Routines and Memory & disk in the launcher (`launcher_rank = 48`), and is listed under the Share tab's System group.
