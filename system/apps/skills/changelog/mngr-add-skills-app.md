A new built-in app, Skills (`skills`): one read-only window over every skill the workspace's agents have. A sidebar lists each skill by name with the first line of its description, under "Yours" (made or installed here) and "Built in", with a search field; beside it is the skill being read: where it came from, its description, and its instructions rendered from its `SKILL.md` (raw HTML escaped, since an installed skill is untrusted content; links to its files open in Files), with the file as written behind "Show source". The arrow keys walk the list, the window reopens on the skill it was showing, and a narrow window shows the list or one skill. "Show in Files" opens the skills folder, or one skill's folder, in Files. It reads `.agents/skills/` through the skills catalog on every request, serves on 8060, stops when no window shows it, sits between Routines and System Monitor in the launcher (`launcher_rank = 48`), and is listed under the Share tab's System group.
