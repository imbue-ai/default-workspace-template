A new built-in app, Skills (`skills`): one read-only window over every skill the workspace's agents have. A sidebar lists each skill by name with the first line of its description, under "Made in this workspace", "Installed" and "Comes with Studio" (by the skill's author and the skills lock files), with a search field; beside it is the skill being read: chips for who made it ("Made by <author>", "Installed from <repo>", "Comes with Studio") and when it was last updated, its description, and its instructions rendered from its `SKILL.md` below a faint rule (raw HTML escaped, since an installed skill is untrusted content; links to its files open in Files). The arrow keys walk the list, the window reopens on the skill it was showing, and a narrow window shows the list or one skill. Icon buttons open the skills folder or one skill's folder in Files, edit a skill's `SKILL.md` in Files, and (the sidebar's +) draft a request to make or find a new skill into the chat on screen; "Use in chat" drafts `/<name>` there, unsent, and a hint says to type `/<name>` in a chat. The list rereads every 10 seconds and on focus, so a skill made in a chat beside it appears. It reads `.agents/skills/` through the skills catalog on every request, serves on 8060, stops when no window shows it, sits between Routines and System Monitor in the launcher (`launcher_rank = 48`), and is listed under the Share tab's System group.
