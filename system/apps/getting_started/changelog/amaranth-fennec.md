A new icon: the flag as a two-layer tile.

- Getting Started's icon is a planted banner in Confusion on Energy, the only yellow tile in the set, built to the rules in `docs/system/app-icons.md` -- a flat 216x216 background under one fill-only glyph inside a centred 144x144 box, with the 32 per cent corner radius the shell's `--desk-icon-radius` computes.

- It is the one glyph of the five not drawn on Gleb's Copyboard: it was drawn in the repo to those rules, as a bowed pole under a cloth that droops unevenly, so the line reads as drawn rather than ruled. The line glyph it replaces was the last `currentColor` icon left.

- Getting Started's `launcher_rank` moves from 5 to 15, which puts it after the chat and before the file viewer. The desktop seeds its shortcuts in this order too, so the built-ins read Chat, Getting Started, File Viewer, Browser, Terminal both on the backdrop and in the launcher, and the chat leads, since it is what the workspace is for.
