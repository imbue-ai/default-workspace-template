The catalog on the Getting Started page lists published apps beside templates: on the shelves that name them (`app:<name>`) and in an "All apps" row, each card showing the app's icon. An app's detail page offers "Add to this workspace", which starts a chat on `/install-app <repository_url>`, and "Create a new workspace with this". `GET /api/templates-catalog` answers the apps as `catalog.apps`, empty for a catalog that lists none; a shelf entry that names nothing the catalog carries is dropped.
