Getting Started says what to do when it cannot show something.

- "Templates couldn't be loaded. Try again. If this persists, report a bug." with a Try again that fetches afresh rather than waiting out the app's one-minute hold, and a "Report a bug" button, carrying what went wrong, wherever the shell that frames the page says Imbue Studio opens one. What went wrong is behind "See details".

- While the page is not built it says it comes back on its own once rebuilt, checks for that by itself, and offers Reload and an agent to rebuild it in a new chat (the button reads "Asking an agent…" until the chat is up, and a failed ask is told under it), with the build command behind "See details".
