The Datalib launcher passes `DATALIB_ALLOWED_HOSTS=*.<share domain>` to `datalib-http` once the workspace has been shared, reading the domain from `data/.state/share_domain`. datalib-http is about to refuse any request whose `Host` is not loopback, a name under `localhost`, or a listed name (imbue-ai/datalib#1269), and the share gateway passes the browser's `Host` (`<label>.<share domain>`) through, so without this every window over a share would get a 403. Releases that predate that check ignore the variable. A workspace shared for the first time while datalib runs needs `supervisorctl restart datalib` before the share reaches it.
