The app's supervisord program is defined in `datalib.conf` here and is not in `system/supervisord.conf.d/` until the `datalib` skill's install script copies it there on first use. It autostarts from then on. `test_datalib_pin.py` checks that no tracked file under `system/supervisord.conf.d/` defines the program, that the installed copy is gitignored, and that the program still starts in the `user` memory band.
