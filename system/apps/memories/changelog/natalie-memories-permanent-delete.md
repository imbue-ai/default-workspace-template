"What agents know" now deletes a note for good instead of moving it aside, and says plainly where copies still exist.

- Delete erases the note and its line in the list every chat reads. There is no "bring back": nothing in the workspace keeps a copy.

- Before deleting, it asks, and says what still holds the note: the workspace's backups until they expire (the page reads the actual retention, 24 months by default), chats that are open until they restart, and the history of the chat that wrote it.

- The "Who can see these notes" panel now lists the backups too, so it is clear before you delete anything that backups keep these notes, including deleted ones.
