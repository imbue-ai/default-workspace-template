"What agents know" now covers pi chats as well as Claude chats, since both keep the same notes.

- The page says Claude and pi chats share the notes (Codex, OpenCode and Antigravity don't yet), and a note a pi chat saved is marked "Saved by a pi chat".

- After an edit, it says open pi chats see the change on their next message and open Claude chats when they restart.

- Deleting or editing a note now tells the chats that are already open. They still have the note in their conversation, and before this a chat could write a deleted note back, or undo an edit, the next time it saved. Each change is recorded by file name and time only, never what the note said, and every chat is told before its next message not to undo it.

- A note a pi chat saved is credited to that chat by name, from pi's own transcripts, even when pi didn't mark the note itself.
