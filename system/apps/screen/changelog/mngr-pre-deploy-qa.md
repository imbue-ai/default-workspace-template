The Screen viewer no longer sticks on "Connecting to the screen" after it hid its own stream. Its 1.5 s belt used to clear the viewer's intersection flag whenever the stage momentarily had no size, with nothing but a later IntersectionObserver change able to set it back, so a transient relayout left the viewer hidden for good; the belt now owns a separate laid-out input that it both clears and restores. A media request the viewer could not make yet (no stream, state, or socket) used to count as made, so it was never retried; it now leaves the viewer wanting media, and a failed connect-info fetch forgets the media, so the next evaluation asks again.
