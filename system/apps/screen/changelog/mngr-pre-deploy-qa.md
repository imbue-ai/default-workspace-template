The Screen viewer no longer sticks on "Connecting to the screen" after it hid its own stream. Its 1.5 s belt used to clear the viewer's intersection flag whenever the stage momentarily had no size, with nothing but a later IntersectionObserver change able to set it back, so a transient relayout left the viewer hidden for good; the belt now owns a separate laid-out input that it both clears and restores. The stream now fetches connect-info itself, ignores the answer of a fetch a later request or a release superseded, and tries a failed fetch again after a moment, where a failed fetch used to leave the viewer believing it held media until hidden and shown once more; and the viewer now knows when its neko socket closed, so a request made during a reconnect is no longer counted as delivered.

Keys typed at the Screen now land in a hidden text input inside the stage, which takes the focus the stage is given. A browser extension that binds letters as commands (Vimium and its kin) stands down for an editable element and for nothing else, so a visitor with one installed used to see "n" open its find bar instead of reaching the Screen.
