The Screen viewer no longer sticks on "Connecting to the screen" after it hid its own stream. Its 1.5 s belt used to clear the viewer's intersection flag whenever the stage momentarily had no size, with nothing but a later IntersectionObserver change able to set it back, so a transient relayout left the viewer hidden for good; the belt now owns a separate laid-out input that it both clears and restores. A failed connect-info fetch used to leave the viewer believing it held media, so it never asked again until hidden and shown once more; it now forgets the media, and a request the viewer could not make yet no longer counts as made, so the next evaluation asks again.
