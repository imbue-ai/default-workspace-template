An app's `app.toml` may declare the files and directories it owns outside its own folder (`[[references]]`) and the globs no pass should consider (`[scope] exclude`); `contracts.md` section 2 and `system/apps/README.md` document both, including the rules that a reference must exist and may name neither the app's own directory nor another app's. Registration is unaffected -- `forward_port.py` still copies only the keys it owns, so neither table reaches the registry row and a stale reference can never stop an app from starting -- and `forward_port_test.py` pins that. `system/test_app_manifests.py` loads every manifest in the tree (user-built apps included) against the real repo root, so a reference to a deleted skill, script, or doc fails loudly instead of leaving a review pass pointed at nothing.
