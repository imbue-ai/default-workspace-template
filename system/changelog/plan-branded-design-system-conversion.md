The standard theme is now the Imbue brand, and the shipped themes are on theme contract 2.

- Classic Mac and Windows 2000 set the contract-2 roles and turn off computed hover shading, so they look as they did.
- On boot, `system/scripts/env.d/1300-migrate-workspace-themes.sh` moves any theme made in the workspace onto contract 2.
- The shared UI library and the page kit carry the brand's color table (keys, ramps, roles, and computed hover and active shades) and its type: Atkinson Hyperlegible Next for text, Atkinson Hyperlegible Mono for static labels and code, and Besley for headings, bundled under the SIL Open Font License, on the brand's ramp (`type-heading-lg` through `type-badge`, with `type-title-sm` for the title of a card, a request, or a row, and 13px `type-body-dense` for menus, segmented controls, and list rows).
- `docs/system/themeable-apps.md` names the contract-2 color roles.
- The shared components take the brand's shapes: buttons 32px (28 small, 36 large) with 12px corners and their own disabled colors, a new `accent` button for brand actions such as Send, 36px fields with a 2px focus ring and an error edge, 16px corners on menus, dialogs and cards, tinted status badges, and the focus color on every keyboard focus ring. The radius scale is the brand's (`--radius-xl` 12px, new `--radius-2xl` 16px).
- The shared UI library has a `Checkbox` (16px), a `Switch` (32 by 18) and its drawing (`switchVisual`), a field label (`FORM_LABEL_CLASS`, the brand's mono label) and a field error line (`FIELD_ERROR_CLASS`); "on" is the primary color. Chat's model menu and Source view toggle, the shared menu's check rows, the switch dialog, and the theme chooser use them, and a plain-HTML page's bare checkbox wears the brand's.
- The shared UI library has a notice (`noticeClass`: neutral, info, success, warn, and danger, each a tint with a matching edge), and toasts take a tone (`show(message, tone)`): a failure is the danger tint, a plain note stays the dark chip. Files' stopped-sync note and chat's one-time tips are notices.
- The shared UI library has a card (`cardClass`: 16px corners on the raised surface, lifting under the pointer when interactive, the focus colour round a chosen one, the overlay surface and floating shadow when it floats). Chat's permission and secret requests, Getting Started's tiles, the tray cards, Files' uploads panel, and the theme gallery's tiles are cards; chat's mention list is the shared menu's card and rows. The launcher field is the brand's 32px field with 12px corners, its edge turning the focus colour while open.
- The System Monitor frontend joins the npm workspace (`system/package.json`, its lockfile, and the Dockerfile's manifest copies), and its built bundle is ignored like the other frontends'.
