- Service-per-origin forwarding redesign: every registered service owns its own browser origin (locally `http://<name>.<workspace-host>/`, on shared workspaces `https://<name>--<host>--<user>.<domain>/`); the `/service/<name>/` path-prefix proxy and all its HTML/cookie/service-worker rewriting are gone. `forward_port.py` names must be DNS-safe hostname labels (lowercase letters/digits with single hyphens, no underscores, not starting with `agent-`), and the shell service is renamed `system_interface` -> `system-interface`. Docs (`docs/system/workspace-internals.md`) are updated to describe the new scheme.
