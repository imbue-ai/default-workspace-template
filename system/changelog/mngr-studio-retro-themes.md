The desktop interface's contracts (`docs/system/blueprint/desktop-interface/contracts.md`) note that the retro themes Imbue Studio's chrome can hand the workspace (`minds:ui-theme`, embed contract version 7) redeclare design tokens, `--desk-title-bar-height` outside touch mode among the metrics the shell reads, so the shell reads its metrics again when a theme arrives. The themes themselves are described in the `workspace_ui` and `system_interface` entries.
