Bake the Grok Build CLI (`grok` 1.0.62) into the workspace image. `system/scripts/install_grok.sh` downloads xAI's per-arch `.gz` release, checks it against the SHA-256 recorded in the script (xAI publishes none), decompresses it beside `/usr/local/bin/grok`, checks that it reports `grok 1.0.62 (`, and renames it into place, so a running grok is never overwritten and a bad download never replaces a good binary. It does nothing when the installed grok already reports the pinned version, so a forced re-provision does not download it again. `setup_system.sh` runs it under its repo name or its image name and then runs a bare `grok --version`; the Dockerfile copies it in as `default-workspace-template-install-grok`, and the three offload configs list it as a checkpoint build input. The version is the one mngr's `imbue-mngr-grok` plugin is tested against.

Hold grok agents to the workspace's tool-call policies. `.grok/hooks/policy.json` runs one PreToolUse hook, `system/scripts/agent_grok_policy_guards.py`, which hands each grok tool call to the same guard scripts claude runs, in claude's order: `run_terminal_command` and `monitor` reach them as claude's `Bash`, with the background flag grok itself applies (a `monitor` always counts as backgrounded), and every other tool reaches the guards that police every tool under its grok name. A `use_tool` call is judged by the call inside it; `workflow`, and a shell call whose input grok truncated past 128 KiB, are refused. A refusal reaches the model with the guard's whole reason, an allowed shell call runs with the OOM-band and git-identity prefix, and the require-a-step nudge rides the call's `additionalContext`. grok drops anything a UserPromptSubmit hook prints, so the open-steps reminder is delivered on the first allowed tool call of each turn instead. Each guard fails open on its own and logs to `grok_policy_guards.log` in the agent's state dir. The same hooks file runs the stop nudge and code-guardian's stop gate on `Stop`, and every handler sets its `timeout`, in seconds as grok 1.0.62 reads it. `agent_hook_wiring_test.py` now holds grok's guard list and order to claude's, and checks every grok handler's timeout and variable references.
