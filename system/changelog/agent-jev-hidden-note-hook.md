New `agent_quick_change_notes.sh` hook (PreToolUse and UserPromptSubmit, claude and codex): when the quick-change agent reports a change routed from a chat, that chat's own agent gets one line of hidden context saying what changed and to keep it when editing the app. Each report is passed on once per chat (state under `data/.state/quick_change_notes/`); the quick-change agent, launch-task workers and claude subagents get no note. pi does not run it.
