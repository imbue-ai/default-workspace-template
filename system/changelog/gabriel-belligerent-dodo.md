The CLAUDE.md ModuleNotFoundError workaround now gives the correct recovery. A standard workspace carries two mngr installs -- the root venv behind `uv run mngr ...`, and the uv-managed tool the bare `mngr` on PATH is, installed by `system/scripts/build_workspace.sh` -- so the entry now says which refresh fixes which: `uv sync --all-packages` for the venv, `uv tool uninstall imbue-mngr && uv tool install -e system/vendor/mngr/libs/mngr` followed by a `mngr plugin add` of the tool's plugin packages for the tool. The tool target is corrected too: it is the installable package inside the vendored monorepo, since installing the vendored root fails with a setuptools flat-layout error. The plugin re-registration is part of the recovery because reinstalling the tool rebuilds its environment from the base package alone, which would otherwise leave an `mngr` that cannot parse its own plugin config.
