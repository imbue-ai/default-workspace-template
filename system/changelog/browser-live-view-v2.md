The browser fleet now runs headful with one virtual display per browser (selected via `BROWSER_HEADLESS=0` in supervisord), rather than a single shared `:99` display. The shared `:99` display service remains only for ad-hoc headful Playwright an agent might run directly. Two Python dependencies were added to the browser service: `pixelflux` (the display capture/encode library) and `python-xlib` (display-level input).
