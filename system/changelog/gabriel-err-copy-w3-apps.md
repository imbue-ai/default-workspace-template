Files tells failures the way the rest of the workspace does: the server's own sentence where it wrote one, else a sentence naming what failed, with the status and the server's text behind "See details", and "Report a bug" on one that asks for a bug report where Imbue Studio can open one. A file that cannot be loaded says so in place of the editor with Try again, a failed upload's row says why, and a file too deep for a window of its own says to download it (see `system/apps/files/changelog/gabriel-err-copy-w3-apps.md`).
