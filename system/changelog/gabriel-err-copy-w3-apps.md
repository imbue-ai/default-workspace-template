Files tells failures the way the rest of the workspace does: a sentence naming what failed and then the cause the server gave ("Couldn't move "notes.txt" into "reports". That folder is read-only."), with the status and the server's text behind "See details", "Report a bug" on one that asks for a bug report where Imbue Studio can open one, and "Ask an agent to free up space" when the disk is full. A file that cannot be loaded says so in place of the editor with Try again, a failed upload's row says why, and a file too deep for a window of its own says to download it (see `system/apps/files/changelog/gabriel-err-copy-w3-apps.md`).
