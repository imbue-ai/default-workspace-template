`forward_port.py` copies a manifest's `message_handlers` onto its registry row. The shared embed module (`system/libs/workspace_ui`) lets a page observe every message the minds chrome sends it, whatever the type, which is how the shell relays one to the app that registered for it; `FOCUS_CHAT` is no longer exported. The desktop interface and workspace app model contracts describe the manifest table, the relay route, and the `show` op.
