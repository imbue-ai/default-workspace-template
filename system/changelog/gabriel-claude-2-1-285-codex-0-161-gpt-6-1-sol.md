Claude Code bumped from 2.1.280 to 2.1.293, the current `latest` release (`stable` is still 2.1.285), in both places that pin it: `CLAUDE_CODE_VERSION` in `system/scripts/setup_system.sh` and `[agent_types.claude].version` in `.mngr/settings.toml`. 2.1.284 added Claude Sonnet 5.5 (`claude-sonnet-5-5`) and 2.1.293 added Claude Haiku 5.5 (`claude-haiku-5-5`), and the `sonnet` and `haiku` aliases now resolve to them, so a claude agent switched to Sonnet or Haiku runs the 5.5 model. 2.1.293 is the first release that carries Haiku 5.5, which is why this pin is ahead of `stable`. Since 2.1.281, a recursive `rm` whose target is command-substitution output (such as `rm -rf "$(pwd)"`) asks for confirmation even under `--dangerously-skip-permissions`; an unattended agent waits 2 minutes for an answer, then the command is denied with a hint to rewrite it.

Codex CLI bumped from 0.157.0 to 0.161.0 (`CODEX_VERSION` in `system/scripts/setup_system.sh`). New codex agents now start on GPT-6.1 Sol: `[agent_types.codex]` pins `model = "gpt-6.1-sol"` instead of `gpt-6-sol`. Codex's bundled catalog has GPT-6.1 Sol from 0.159.1 and lists it for every ChatGPT plan GPT-6 Astra is listed for, including `promax`, which GPT-6 Sol was not. An account that is not offered it still starts on the account's default model. GPT-6.1 Sol's own default effort is `low` (GPT-6 Sol's was `medium`), and no effort is pinned, so a new codex agent now starts at low effort. Its default speed tier is standard, but `service_tier = "default"` stays pinned for models such as GPT-6 Sol whose default is the fast tier.

mngr is pinned to `d00a41f203`, the public export of mngr-internal#1684, the paired mngr change. It moves mngr's own Claude Code pins and dialog snapshot to 2.1.293 and prices Sonnet 5.5, Haiku 5.5 and GPT-6.1 Sol. Once that PR merges, the twice-daily bump moves the pin to the mirror of mngr `main`.
