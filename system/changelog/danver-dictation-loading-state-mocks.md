`system/libs/workspace_voice/` (a member of the npm workspace, filed here as it has no project of its own) lets dictation load the speech model without opening the microphone (`Dictation.prepare()`, with `onEngineReady` from every load), tells a page whether the model is already on this device (`probeEngineDownload`, over the device pick now in `devicePick.ts` and the store's new `has`), and plays a ready chime; see the library's own entry under `system/libs/workspace_voice/changelog/`. The chat's composer uses all three for its redesigned mic (see the chat's entry).

The library also gains `speechModel.ts`, one managed speech model load per engine for the page, built on `@tanstack/query-core` (a new dependency of the library, so `system/package-lock.json` changes with it) and kept in step across the workspace's pages by the engine worker, which now tells each page what it holds as the page connects; see the library's own entry.

The chat's composer takes its speech model from `speechModel.ts`, so `Dictation` no longer loads one (its `loading` state, `prepare()`, `onProgress` and `onEngineReady` are gone; see the library's own entry), and the chat frontend declares `@tanstack/query-core` itself, which adds one line to `system/package-lock.json`.
