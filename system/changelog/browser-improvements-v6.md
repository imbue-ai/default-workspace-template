The live browser view can now stream over WebRTC: the browser service re-encodes the CDP screencast as real video (VP8/H264 delta frames with congestion control) over a peer connection negotiated on the existing cast WebSocket, bypassing the HTTP proxy and its 1 MiB message cap; the JPEG-over-WebSocket stream remains the automatic fallback whenever a peer connection can't be established.

Viewers that can't reach the workspace directly (e.g. behind the cloudflared HTTP-only tunnel) relay their media through TURN: the client's ICE servers are minted per session by a trusted endpoint (`BROWSER_TURN_ICE_ENDPOINT`, e.g. an mngr cloud service holding a Cloudflare TURN key that tags each credential with the user for per-user billing), with static `BROWSER_TURN_URLS`/`USERNAME`/`PASSWORD` env as the bring-your-own-TURN fallback and STUN-only as the default.
