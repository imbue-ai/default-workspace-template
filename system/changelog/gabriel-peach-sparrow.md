The shared embed module (`system/libs/workspace_ui`) now handles the minds embed contract's new `minds:focus-chat` message (contract v4): the Mind app sends it when the user opens a chat's notification, and the system interface shows that chat. Its payload names the chat by `chatId` (a chat's id is its first agent's id).

The module also announces `minds:workspace-ready` (contract v5) once the page's endpoint is listening. The app holds a focus-chat ask until that arrives, instead of guessing when a freshly-mounted frame's page is live; a send into a page whose listener is not up yet is simply lost. Like the other newer contract types, both constants are probed off the vendored snapshot so a build against an older snapshot still compiles.

Chat agents now tell the user when they finish. A Stop hook (`system/scripts/agent_notify_user_stop_nudge.sh`) asks for a notification at the end of every turn; a turn that does not warrant one declines by replying with nothing at all, so the judgement stays with the agent instead of being guessed from the outside. The reminder reaches the agent by refusing the stop, and claude's `stop_hook_active` is what lets the resulting continuation through, so the hook keeps no state of its own. Workers, automations and claude subagents are never asked -- it gates on `MNGR_AGENT_ROLE=chat`, which the `chat` create template now sets. Wired for claude only; codex is left unwired until it is known whether it reports a continuation the same way. `AGENTS.md` carries the rule for every harness.
