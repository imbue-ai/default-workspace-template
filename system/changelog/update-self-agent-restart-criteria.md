- `message_chat.py --interrupt` restarts a chat's agent through the chat app's interrupt route (what the stop button does; the conversation carries over), then sends the message if one was given. A refusal, such as a chat mid-handoff, is final. Only when the chat app cannot take the restart does `mngr start --restart --no-resume` do it, with `mngr message` carrying the text. update-self uses it to restart agents after an update that changes their harness.
