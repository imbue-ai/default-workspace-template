New `system/scripts/start_early_sign_in.sh`: the command the Imbue Studio app runs over SSH to start the chat app's early sign-in program while a new workspace is built, before supervisord runs anything. It starts the program the way supervisord starts the chat app: from the repo root, with the workspace venv active, and with supervisord's environment, so the sign-in CLIs run in the environment they have once the workspace is up.
