The Datalib app serves `data/.datalib` instead of `data/.skills/datalib/Default`. The folder is the store's data root itself; the libraries folder with its `Default` library is gone, since the layout only ever had room for one store. The store is what datalib mirrors and processes, shared by the `datalib` skill and the app, rather than the skill's own state or one app's data, which stays in that app's `data/.apps/<app>/`. The launcher no longer moves a store written before the libraries folder existed into `Default`: datalib is dark-launched, so no workspace holds such a store.
