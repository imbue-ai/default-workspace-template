The Datalib app serves `data/.shared-data` instead of `data/.skills/datalib/Default`. `data/.shared-data` is the workspace's shared data folder, a category of its own under `data/` beside `.apps/` and `.skills/`: data shared across the workspace rather than one app's own, which stays in that app's `data/.apps/<app>/` (datalib may manage either). The folder is the store's data root itself; the libraries folder with its `Default` library is gone, since the layout only ever had room for one store. The layout rule (`docs/system/blueprint/workspace-app-model/contracts.md` section 17) and `data/README.md` record the new folder. The launcher no longer moves a store written before the libraries folder existed into `Default`: datalib is dark-launched, so no workspace holds such a store.
