The Datalib app serves `data/.apps/shared-data/Default` instead of `data/.skills/datalib/Default`. `data/.apps/shared-data` is the workspace's shared data folder: the one folder under `data/.apps/` not named for an app, holding data shared across the workspace rather than one app's own, which stays in that app's `data/.apps/<app>/` (datalib may manage either). The layout rule (`docs/system/blueprint/workspace-app-model/contracts.md` section 17) and `data/.apps/README.md` record the distinction. The launcher no longer moves a store written before the libraries folder existed into `Default`: datalib is dark-launched, so no workspace holds such a store, and the move was dead code at the new location.
