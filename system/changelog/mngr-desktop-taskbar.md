A new blueprint, `docs/system/blueprint/launcher-and-getting-started/plan-launcher-and-getting-started.md`, specifies the launcher's next shape and a Getting Started app: the taskbar's field opens a compact menu of rows in which one row is always highlighted (Enter runs it; with no match, Enter starts a new chat with the typed text and Ctrl+Enter sends it to an existing chat, both in the chat's pinned window); a launch path declares which param takes typed text (`text_param`); an app's manifest may ask for one first-visit window (`[first_window]`) on the desktop a workspace is born with, placed to the left of the pinned chat; and the "Start something" intents and the template catalog leave the shell for a Getting Started app that starts chats through one new contract message, `shell:start-with-text`. Nothing is implemented yet.
