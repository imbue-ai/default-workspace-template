`system/scripts/migrate_workspace_layouts.py` writes the shell's params-only layout seeds: each migrated panel's `params` carry `kind`, `address`, `tabId`, and `lastFocusedMs` (from `member_last_used.json`), and the record no longer carries a separate `tabs` block. `contracts.md` sections 6 and 7 and the workspace-app-model plan describe the layout file as dockview's document alone, with a panel's identity in its params.
