Codex chats keep fast mode when it is turned on from the model bar, including in a chat that was just created. Codex is bumped from 0.161.0 to 0.166.0 (`CODEX_VERSION` in `system/scripts/setup_system.sh`, and `[agent_types.codex]`'s `version`): when the agent terminal's codex TUI attaches, codex rebuilds the chat's thread, and before 0.164.0 the rebuilt thread came back at the standard tier. `[agent_types.codex]` also no longer pins `service_tier = "default"`, which the TUI sent on attach and which reset the tier the same way. Turns sent from the chat still run at the standard tier until fast mode is turned on. A turn typed directly in the agent terminal on a model whose default is the fast tier (GPT-6 Sol) now runs fast, and the model bar shows it.
