Codex chats keep fast mode when it is turned on from the model bar. `[agent_types.codex]` no longer pins `service_tier = "default"`: the agent terminal's codex TUI sent that tier when it attached, and codex reset the chat's thread to it, so a fast switch made before the TUI attached (as in a new chat) never reached the model. Turns sent from the chat still run at the standard tier until fast mode is turned on. A turn typed directly in the agent terminal on a model whose default is the fast tier (GPT-6 Sol) now runs fast, and the model bar shows it.
