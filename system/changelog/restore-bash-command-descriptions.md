Claude agents (chats, background workers, automations) are told to give every Bash call a `description` again (a line added to the Claude-specific instructions in `[agent_types.claude].append_system_prompt` in `.mngr/settings.toml`). Since workspaces moved to Claude Code 2.1.280 and Opus 5.5, most chats had stopped writing one: whether a chat does is settled by its first Bash call (usually a `tk create` batch), and a chat that skips it there never writes one afterwards. The chat's activity strip and tool chips then showed the raw shell command instead of a plain-language description. On one production workspace, 38 of 50 chats since the switch had no descriptions at all, against 1 of 45 before it. Replaying a real chat's opening message, 3 of 6 Opus 5.5 chats started without descriptions; with the new line, 0 of 8 did.
