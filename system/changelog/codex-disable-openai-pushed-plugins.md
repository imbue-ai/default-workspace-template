New Codex agents no longer load OpenAI's plugins or Codex's built-in skills: only the plugins enabled in `[agent_types.codex]` (code-guardian) are loaded. Before this, every plugin on the signed-in ChatGPT account (`visualize`, `sites`, ...) and the built-in skills (`imagegen`, `skill-installer`, ...) competed with the workspace's own skills. In one case `visualize` had the agent reply with raw `visualize{...}` markup in place of a mock, because the chat cannot render that markup.
