Removed the Claude Stop hook that refused to end a turn until the agent's shell was back at the repo root. Claude Code runs Stop hooks in whatever folder the agent's shell is in, and the hook was there for review hooks that need the repo root. Those hooks are off in workspaces, and every Stop hook a workspace agent runs finds its files from its own location or the agent's environment. So the hook protected nothing, while answering it cost the agent a second reply: a `cd`, usually followed by "I'm back at the repo root." In the chat, that reply also broke the turn, so a step left open for the next turn was drawn a second time beneath the hook. Agents can still `cd` into a folder and keep working there across commands.
