Claude agents now set `CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR=1`, so the session goes back to the workspace folder after every command. Claude Code runs Stop hooks in the session's current folder. Before this, an agent whose last command `cd`ed into a subfolder had its Stop hooks run there. The repo-root Stop hook then made it answer again with a `cd` and a line about it, and in the chat a step left open for the next turn was drawn a second time under the hook. The Stop hooks now always run at the root. The repo-root hook stays as a safety net. For agents, each Bash call now starts in the workspace folder, so a command meant for another folder needs `cd x && ...` in the same call.
