Removed the Claude Stop hook that refused to end a turn until the agent's shell was back at the repo root. Claude Code runs Stop hooks in whatever folder the agent's shell is in, and the hook was added to protect hooks that assumed the repo root. Every Stop hook a workspace agent runs now finds its files from its own location or the agent's environment, including the code-review hook workers run, which moves to the project folder first. So the hook protected nothing, while answering it cost the agent a second reply: a `cd`, usually followed by "I'm back at the repo root." In the chat, that reply also broke the turn, so a step left open for the next turn was drawn a second time beneath the hook. Agents can still `cd` into a folder and keep working there across commands.
