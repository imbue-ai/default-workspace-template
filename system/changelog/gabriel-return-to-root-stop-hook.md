Claude agents now set `CLAUDE_BASH_MAINTAIN_PROJECT_WORKING_DIR=1`, so their shell goes back to the workspace folder after every command. An agent therefore no longer ends a turn in another folder, which is what made the repo-root Stop hook fire. When it fired, the agent answered with a `cd` and a line about it after its reply. In the chat, that answer also broke the turn: a step left open for the next turn was drawn a second time under the hook. The hook stays as a safety net. One thing changes for agents: each Bash call starts in the workspace folder, so a command in another folder needs its own `cd x && ...`.
