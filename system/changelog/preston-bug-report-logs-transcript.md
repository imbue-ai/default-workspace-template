# Resident bug-report diagnostics collector

Added `system/scripts/collect_bug_report_diagnostics.py`, a stdlib-only resident script the minds desktop app invokes (via a small `mngr exec`) when a user files a bug report. It replaces the old approach of base64-injecting a collector plus its own scanner copies into the container on every report, which broke on Linux's 128KB single-argument limit.

The collector gathers the workspace service logs (`--logs`: host health, workspace version, supervisord log tails with user-created apps excluded) and the recent chat transcripts (`--transcript`: every chat written to inside a two-hour window, newest first, with a best-single-chat fallback), secret-scans everything as plaintext through the template's own scan gate at `.agents/skills/publish-inspiration/scripts/scan_secrets.sh`, and prints one JSON line: `{"contract_version": 1, "zip": "<base64 zip>", "omissions": {...}}`. One finding in any chat withholds all chats; a finding in the logs withholds the logs; a broken, missing, or timed-out scanner fails closed for everything it was scanning. The base64 payload is capped at 8MB, dropping the oldest chats first and recording every drop in a `DROPPED-CHATS.txt` member inside the zip.
