Workspace claude chats no longer show Claude Code's session quality survey or feedback drafts: `[agent_types.claude]` in `.mngr/settings.toml` now sets `feedbackSurveyRate = 0` and `feedbackDrafts = "off"` through `settings_overrides__extend`. Both prompt a human mid-session, which garbles an unattended chat's automated input and output. They ride the mngr-managed `--settings` overlay, like `skipDangerousModePermissionPrompt`, because in shared config-dir mode nothing else provisions the shared `settings.json`, and mngr's own unattended flags never apply to chats created inside the container.
