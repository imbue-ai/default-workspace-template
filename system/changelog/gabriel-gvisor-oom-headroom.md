The workspace now installs earlyoom v1.9.0-imbue.3 and runs it with `--host-meminfo /mngr-vol/.host-meminfo`. The release never picks a gVisor zombie or exiting task (v1.9.0-imbue.2 could signal one over and over until the sandbox was killed), and under gVisor it counts each process's smaps `Anonymous:` total rather than the inflated `VmRSS`. On a gen-2 slice VM, `--host-meminfo` reads the headroom the VM publishes into the workspace's volume, which includes the memory gVisor itself is charged, so earlyoom sheds before the container's cgroup kills the whole sandbox. Where nothing is published there (local docker, lima), earlyoom logs that once and uses `/proc/meminfo` alone.
