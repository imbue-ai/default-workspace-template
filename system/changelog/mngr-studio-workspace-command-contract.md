- Added `system/test_studio_command_contract.py`, the template half of Imbue Studio's workspace command contract. `fetch_mngr_assets.sh` now vendors the app's `workspace_command_contract.json` from the pinned mngr commit. The new guard checks every command the app runs here against it: `message_chat.py`, `seed_welcome_chat.py`, `collect_bug_report_diagnostics.py`, `background_tasks.py`, update-self's `run-status verdict`, `workspace-layout open` and `agent-access`. Each must run as the app runs it, take every option and fixed value the app passes, and exit with the status the app reads for an unknown argument. The guard also checks every path the app tests for, and pins the contract version the scripts were reviewed against. It sits in `system/`, so the workspace test gate runs it on every change, and its failures say the command is Imbue Studio's interface and how to fix it.
