The shared frontend library (`system/libs/workspace_ui`) gains `hideCursorWhileTyping.ts` and a matching rule in `base.css`: the mouse pointer hides while a keystroke inserts or deletes text in a focused field and comes back on the first real pointer movement, press, or scroll, so it never sits over what is being typed. Shortcuts such as Cmd+C, bare modifier presses, keys pressed outside a field, and Space on a checkbox or radio leave the pointer alone; keystrokes an input method editor is composing hide it. Because `cursor` never crosses a frame boundary, the shell, the chat page, the chat root, and the Getting Started page each install it on their own document.
