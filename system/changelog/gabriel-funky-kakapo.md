`AGENTS.md` no longer asks chat agents to put engineering detail in front of the user. Git is declared invisible plumbing like `tk`: agents commit silently and keep git vocabulary (commit, branch, push, merge, PR, revert) out of chat and progress-view text, saying only "your work is saved and I can undo it" when the record itself is the question. The test-reporting rule no longer requires the exact test command and pass/fail counts in the reply; the user hears "checked it works" or what still fails and what it means for them. The final-reflection, flaky-test, and no-PR rules now say to surface only what affects the user, in plain terms. The skill-driving rule says the progress view mirrors a skill's rough shape, collapsing steps the user would see as one thing into a single non-technical title. All of it points at the new shared vocabulary in `.agents/shared/references/user-facing-language.md`.
