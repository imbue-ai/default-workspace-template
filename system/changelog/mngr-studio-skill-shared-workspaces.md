- `system/scripts/vendor_mngr_skill.py` is the one writer and checker of the vendored `.agents/skills/imbue-studio/SKILL.md`: `--write --mngr-repo <checkout> --rev <commit>` copies `apps/minds/skills_plugin/skills/imbue-studio/SKILL.md` from that commit (the mngr repo's pin bump runs it after every pin move), and `--check`, which CI's `pin-is-public` job runs, fetches the skill at the pinned mngr commit and fails when the committed copy differs, so the vendored skill can no longer drift from the mngr the workspace runs. `--check --mngr-repo <checkout>` compares against a local checkout, which a private pin without `MNGR_INTERNAL_GIT_TOKEN` needs.
