The agentic browser fleet runs as a supervised program at slightly elevated CPU priority so agent build/test bursts cannot starve the live pixel path, and the base image now bakes the small runtime libraries (libva, x11-utils, pulseaudio) its media encoders load at import, so it works from first boot. The standalone streamed-browser prototype app has been removed: the fleet now carries its entire streaming stack (pixelflux video, pcmflux audio, XTEST input, the XFixes clipboard), so the separate service was pure duplication.
