The Datalib app (`system/apps/datalib`) now serves `data/.skills/datalib/Default`: the skill's folder is a libraries folder laid out like the desktop app's `~/Datalib`, with one folder per library. The launcher moves a store that an earlier workspace wrote at `data/.skills/datalib` itself into `Default` on the app's next start, keeping its contents and its API token; the library is known by where it is on disk, whatever spelling of its path the launcher is given.
