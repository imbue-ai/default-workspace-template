The desktop-interface contract documents `opensHelp` in the embedder's capabilities: "Report a bug" is offered only where the chrome says it opens its bug report, and the report carries the failure as `minds:open-help`'s `errorDetails` (embed contract v20). The app contract carries it to app pages: the handshake gains `canReportBug` (sent again to every loaded page when it changes), and a page asks the shell for the bug report with the new `shell:report-bug {message, details}`.
