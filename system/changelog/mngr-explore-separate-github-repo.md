The workspace now installs the app SDK (`imbue-app-sdk`, imported as `imbue.app_sdk`) from the mngr commit `pyproject.toml` pins, beside `imbue-common` and the mngr packages. It carries the request guard, the route helpers, the API document, and the request identity that `system/libs/app_schema` and `workspace_layout.identity` used to hold, so that an app can lock and run outside a workspace; every built-in app imports it directly. The pinned `imbue-common` no longer installs `boto3`, `sentry-sdk`, `cryptography`, and their dependencies, which nothing in the workspace imported through it.
