`AGENTS.md` now says that `/tmp` in the workspace container is memory, not disk: anything that can run to gigabytes (a copy of an app's data, a clone, a download, a backup export or restore) belongs on disk under `/var/tmp`, and a copy of an app's data goes through `update-app`'s copy tools. The workspace app model contract (section 17) lists the new `data/.state/app-data-snapshots/` location.
