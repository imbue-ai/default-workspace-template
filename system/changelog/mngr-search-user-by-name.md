The What Studio knows about me app (`system/apps/about_me`) joins the built-in apps: a root workspace member and dependency (`pyproject.toml`, `uv.lock`), and its program runs on port 8070 at boot (`system/supervisord.conf.d/about-me.conf`). `test_app_manifests.py` lists it among the apps that stop when no window shows them and under the Share tab's System group.

The Classic Mac and Windows 2000 themes ship its icon (`icons/about-me.png`): an ID badge with a portrait and lines of text, one bit deep for Classic Mac, with a blue header band for Windows 2000.
