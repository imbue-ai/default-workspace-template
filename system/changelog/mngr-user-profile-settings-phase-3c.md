Phase 3C of the user-profile-state spec (rebindable keyboard shortcuts) wires `workspace-profile` into the uv workspace sources and the four built-in apps' dependencies (lockfile regenerated), and adds the shared browser-side chord utilities to `system/libs/workspace_ui`: the canonical chord spelling of a keydown (`keybindings.ts`), and the `shell:keybindings-changed` app-contract message every framed page re-fetches its resolved chords on. The desktop-interface contract (`docs/system/blueprint/desktop-interface/contracts.md`, sections 5.1, 6, and 7) and the workspace app model's browser-side contract (section 10) record the shell's keybindings routes, the `keybindings_changed` event, and that message.

The new `latchkey-access` library joins the uv workspace (members, sources, and the lockfile) and the `system/libs/` index: the shared spelling of the agent-to-gateway environment and header contract, replacing the chat app's and the shell's identical copies.
