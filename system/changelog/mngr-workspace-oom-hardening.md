Test runs in a workspace no longer leave their temporary files piling up in `/tmp`. Every pytest run in the container, and every agent's, now deletes a passing test's `tmp_path` as soon as the test finishes and keeps only the latest session's leftovers (`PYTEST_ADDOPTS="-o tmp_path_retention_policy=failed -o tmp_path_retention_count=1"`, set in the image and in the agents' host env). pytest's default kept every test's directory for the last three sessions. `/tmp` is a tmpfs, and under gVisor each file or directory there also costs sandbox memory that only deleting it gives back, so after a couple of suite runs the leftovers (73,000 entries in one measurement) held about 300 MB of the container's memory.
