New design spec docs/system/specs/rail-shortcuts-and-app-lifecycle.md: generalizes the rail's top section into per-project shortcuts with a focus-vs-new mode (Chat defaulting to "New Chat"), and gives apps a real lifecycle -- a supervisord-program capability field in the port registry, derived liveness, and reversible Stop/Start replacing the deregister-flavored "Quit" (with system_interface and terminal as the only unstoppable services).

The workspace ships a file viewer: dufs (a pinned single static binary, installed at image build by system/scripts/install_dufs.sh with per-arch sha256 verification) runs as the new [program:files] supervisord service, serving data/ on loopback with all operations enabled and registered as the "files" app behind the rail's File Viewer row.
