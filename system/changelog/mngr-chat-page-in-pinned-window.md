The automation agents' system prompt (`.mngr/settings.toml`) surfaces the agent's chat with `workspace-layout show chat ...` instead of `open chat ...`, so a scheduled run shows its chat in the pinned chat window rather than opening another. The desktop contracts document the shell's new `POST /api/clients/<client_id>/show` route and how a link to an app's pin page with a query of its own is shown through it.
