Working branch for shared workspace desktops: every desktop is shared, and a user arriving for the first time gets a desktop seeded from the primary one (design in progress). The branch carries the desktop-interface work (`mngr-desktop-ui-*.md`) and, in the system interface and the share gateway, the sharing identity cleanup merged from `josh/sharing-cleanup` (`mngr-sharing-cleanup.md`); those entries describe the changes in full. The desktop-interface blueprint documents (`docs/system/blueprint/desktop-interface/`) now list the presence routes, the `presence_updated` push, and the Presence tray widget.
