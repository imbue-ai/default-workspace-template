The Skills app joins the built-ins: its supervisord program (`system/supervisord.conf.d/skills.conf`), the `skills-catalog` workspace source in the root `pyproject.toml`, the built-in manifest suite's tables, and the app lists and contract tables in the docs (`workspace-internals.md`, `stop-when-no-windows.md`, and both `contracts.md` blueprints). A new CI job in the template repository only, `skill-authors` (`system/scripts/check_skill_authors.py`), fails when a skill the template ships lacks `metadata.author: imbue`, which the Skills app groups by; the vendored imbue-studio skill is left to the mngr repository's own test. The desktop-interface contracts doc lists the Files manifest's new `edit:file` handler beside `open:file`. The `skill-authors` check also fails a skill whose `metadata.audience` is anything but `system`, the one value the Skills app reads. The scripts README lists `check_skill_authors.py`.
