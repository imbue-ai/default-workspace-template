Desktop interface phase 3 (the apps): the built-ins gain the pages of the desktop plan's section 9 while the tabbed shell still runs them.

A new `terminal-pty` supervisord program and manifest (`system/apps/terminal_pty/app.toml`, internal and critical, in the terminal's memory band) runs ttyd on its own origin, framed by the terminal app's wrapper page.

The browser-side app contract module reads a shell handshake that carries only a client id, so pages keep working under a shell that sends no tab, view, address, or device kind.
