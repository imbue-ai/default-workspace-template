- At boot, the programs nobody waits on (env-converge, host-backup, Files, Getting Started, Routines, System Monitor and its resource sampler, the Screen service and its watcher, and Datalib once installed) now start only once the system interface and the chat app accept connections, through the new `system/scripts/wait_for_critical_path.py` command prefix. supervisord had spawned every program at once, so their cold starts competed for the CPUs with the two apps a new workspace's user is waiting on. A prefixed program still starts after 30 seconds if either app never comes up, and starts at once when both already serve (a restart, or a wake by the shell).
