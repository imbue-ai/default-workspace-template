A new script, `system/scripts/run_in_background.py`, runs a command in the background and, when the command exits, sends its exit code and output to the calling agent's own chat as one message. That message starts the agent's next turn, so it works on every harness. Only claude's own background tool wakes the agent when its command finishes; codex, pi and opencode have no such tool. The chat shows the user only a one-line summary. The run's output and exit code are also kept in `data/.tasks/run-in-background/<task>/`.

`message_chat.py --system` now says what it does: it wraps a message in the browser fleet's tag, which the chat shows as a "Browser fleet" chip. A codex lead had used it to report a worker's result, and the chat showed that report as a browser-fleet message.
