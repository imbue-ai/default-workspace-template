Codex agents no longer load the ChatGPT account's apps/connectors. Before, a codex agent signed in with ChatGPT got a hosted `codex_apps` MCP server carrying every connector the user had added on chatgpt.com (52 tools on a test account), an OAuth side channel to third-party services that bypasses the latchkey gateway. `[agent_types.codex]` now sets `features.apps = false`, codex's counterpart of the `ENABLE_CLAUDEAI_MCP_SERVERS=false` claude already runs with. Plugin skills and hooks (code-guardian) are unaffected.
