- `.mngr/settings.toml` turns idle compaction on for every workspace built from the template: `[plugins.autocompact] mode = "proactive_timer"`, with every other plugin key left at its default. The chat app's sweep re-reads the mode every tick, so one workspace switches it off without a restart with `mngr config set --scope local plugins.autocompact.mode disabled`. The chat app's changelog entry describes the feature itself.
