The `test-offload` CI job no longer drops a whole batch of root-suite tests when a commit adds or deletes a file. offload applies each run's source diff to the files but not to git's index, so in the sandbox a new file was untracked and `git ls-files` returned the checkpoint's file list, not the run's. `system/test_mngr_pin.py` then parametrized differently there than on the runner that picked the test IDs, pytest rejected the unknown ID, and the whole batch of about 160 tests went unreported. `system/scripts/offload_post_patch.sh` now stages the patched tree (`git add -A`) before anything else runs.
