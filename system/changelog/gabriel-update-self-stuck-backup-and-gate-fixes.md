New root ratchet `test_prevent_playwright_session_fixtures_in_root_suite_tests` (count 0): a test, or a fixture in a test file or conftest, that the root suite collects may not take pytest-playwright's `page`, `context`, `browser` or another fixture sharing its session Playwright without defining it locally. Those leave an asyncio loop running in the xdist worker, so every later browser test on it errors, as 150+ `module_browser` tests did in one workspace's update. Browser tests use the root conftest's `module_browser`. Paths the root config ignores (the chat and the shell, which run their own sessions) are out of scope.
