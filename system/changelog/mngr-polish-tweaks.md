The File Viewer now opens at the workspace folder (`/home/user/workspace/`) and can browse upward from there: dufs serves the container's filesystem root instead of `data/`, so the breadcrumb reaches the workspace's own folders (`system/`, `skills/`, `docs/`) and anything above them that the workspace user can read. Folder paths given to the viewer (`layout.py open files --path ...`, the `path` launch parameter, the `open=files:` deep link) are absolute paths now rather than paths under `data/`.

Pi chats on OpenRouter now start on GLM 5.3 instead of pi's own first pick (Kimi K2.6): the workspace seeds pi's `defaultProvider` / `defaultModel` into `~/.pi/agent/settings.json` at boot. Pi only honors that default when an OpenRouter key is present and otherwise falls back to its usual choice, and the seed never overwrites a default you saved yourself from pi's model picker.

The pi coding agent baked into the image moves from 0.83.0 to 0.87.1. That release bundles OpenRouter's GLM 5.3 in pi's model catalog, which is what lets the seeded default actually take effect: 0.83.0 only knew GLM up to 5.2, so pi ignored the saved default and fell back to its first available model.
