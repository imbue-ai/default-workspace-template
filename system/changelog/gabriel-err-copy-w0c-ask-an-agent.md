The desktop-interface contract and the post-launch-paths plan document `askAgentToFix`, which gives every "Ask an agent to fix this" button one task through the new `shell:ask-agent {text, requestId}`, answered with `shell:ask-agent-result`; the `text` member of `app_params`; Chat's `app-ask` launch path; and the `app_ask` intake target, which sends the task to the chat about the app, else to the main chat. `shell:start-with-text` now carries a `requestId` too and is answered with `shell:start-with-text-result`.
