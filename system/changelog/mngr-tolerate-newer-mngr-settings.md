- Every supervised program (the chat app, routines, the agent observer, the system interface) now runs with `MNGR_ALLOW_UNKNOWN_CONFIG=1`, set once in `system/supervisord.conf`. An update makes the new `.mngr/settings.toml` live before it reinstalls mngr, so for that window the old mngr rejected settings only the new one knows, and a chat create, rename or routine could fail; from the next update after this one, those calls go through. Agents' own `mngr` calls stay strict.
