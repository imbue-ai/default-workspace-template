Every page of the workspace gets an element context menu (`docs/system/blueprint/element-reference-menu/`): a right-click opens a menu with the browser's own edit, link, and image rows and then "Copy reference", "Explain...", and "Modify...", which attach a JSON description of the clicked element (its tag, id, classes, attributes, a checked selector, the selection, and the app, window, and page it is on) to a chat message as a `REF-<id>.json` file, with a prompt that names it, so a user can point at anything on screen and an agent knows which element they mean. `.agents/shared/references/element-references.md` tells the agent what the file holds and how to find the element.

The app contract gains `shell:draft-text` (a page asks the shell to draft a text into the chat on screen, as "Design your own..." does) and the handshake carries the window's `app`; every app serves `/_static/context_menu.js` beside `/_static/app_contract.js`. The build-app scaffold's pages connect to the shell and install the menu in place of the old location beacon, and serve the two modules from their own origin.
