A `catalog/` directory at the repo root holds the New Tab page's template catalog: `new-tab-templates.json` (format 1: the published templates and the shelves that group them, "Most popular" first), the templates' drawings under `catalog/thumbnails/`, the `build_catalog_from_export.py` script that produced it from the prototype's export, and a README describing the format and how a workspace fetches it (by default from this file's raw GitHub URL on the `josh/new-tab-base` branch). The New Tab page's design is `docs/system/blueprint/new-tab-page/plan-new-tab-page.md`; the workspace app model's contract (`docs/system/blueprint/workspace-app-model/contracts.md`) gains the manifest's `launcher_rank`, the registry's action `params`, and the chat's `message` param. The terminal, files, and browser manifests declare their launcher ranks. `forward_port.py` copies the new manifest fields onto registry rows.
