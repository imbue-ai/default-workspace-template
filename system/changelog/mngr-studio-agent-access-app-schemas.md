Apps describe themselves: `forward_port.py` copies a manifest's new `description` and `api_schema_path` keys onto the registry row, the workspace app model's and the desktop interface's contracts document both keys (and the former's tool-environments section names `app_schema` among the libraries apps depend on by path), the `system/libs` index lists `app_schema`, the `build-app` skill's scaffolder registers the schema route and writes both keys into every new app, and the datalib and terminal-pty manifests gain descriptions (neither serves an API of its own).
