The workspace image installs `mcpc` (`@apify/mcpc`, pinned as `MCPC_VERSION` in `setup_system.sh`), the MCP client every agent, app, and scheduled job shares. `.mngr/settings.toml` sets `MCPC_HOME_DIR` to `data/.secrets/mcpc`, and `seed_home_skeleton.sh` links `~/.mcpc` there too, so mcpc's sessions, OAuth sign-ins, and stored headers sit under the secrets guard and survive with the rest of `data/`, even for a process started without the variable. The guard (P9) counts `~/.mcpc` and `$MCPC_HOME_DIR` as the secrets directory too, in its checker and in the claude/codex and pi prefilters, so a read of the store by either of those names is refused like one of `data/.secrets`. `.claude/settings.json` drops `enableAllProjectMcpServers`, since no MCP server is wired into a harness's own config any more, and `data/.secrets/README.md` and `with_secrets.py` name `mcp-servers.json` where they named `.mcp.json`.
