Made `system/scripts/setup_system.sh` resilient to transient network failures when fetching the pinned CLIs (restic, ttyd, gh, caddy, frpc, uv, Claude Code). Each `curl` download now retries via a shared `--retry 5 --retry-all-errors --retry-delay 2` flag set, so a transient GitHub-release 503 or a mid-transfer connection drop (curl exit 56) no longer aborts the whole provision under `set -e` -- the same failure mode that was intermittently failing the minds snapshot image build. Every download is still sha256-verified, so a retry cannot admit a corrupt artifact.
