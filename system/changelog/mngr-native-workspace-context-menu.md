In the Imbue Studio desktop app, right-clicking text you are editing, text you have selected, or a plain link inside the workspace now opens the system's native menu (spelling suggestions, Look Up, Cut / Copy / Paste, Copy Link, Share), with none of the workspace's rows in it. Everything else keeps the workspace's own menu, and so does every right-click in a plain browser or an older desktop app. Holding Shift while right-clicking in the desktop app gives the native menu too, except over something with a menu of its own (a taskbar entry, a chat in the list).

Right-clicking an image now offers "Copy image" where the page can read the image.

The element-reference-menu plan (sections 3.3, 4.1, and 11) and contracts.md's `shell:handshake` row describe the new behavior.
