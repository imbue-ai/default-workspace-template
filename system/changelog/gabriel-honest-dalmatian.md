- The agy shim's test suite no longer rewrites the checkout it runs from. `test_the_kill_switch_disables_every_guard` really does execute `git rebase -i HEAD~2` (that is the point of the kill switch), and the helper that ran it inherited pytest's cwd -- so with the workspace's `GIT_EDITOR=true` the rebase ran unattended in the repo root. It passed either way, because it only asserted the exit code was not 2 and both a clean rebase (0) and a conflicted one (1) satisfy that. Observed damage: the tree was left mid-rebase and the following 93 tests failed against a half-rebased checkout. The helper now runs every command in a throwaway directory, and the test additionally asserts the guard's block reason is absent rather than inferring it from the exit code.

- `system/scripts/register_vm_exec.sh` skips cleanly on hosts without iproute2 instead of exiting 127. It resolves the gateway with `ip route`, which under `set -euo pipefail` aborted the script before its own "no default gateway; skipping" branch could run -- so supervisord logged `exited: vm-exec-register (exit status 127; not expected)` on every boot of a workspace the script is documented to no-op on. It now probes for `ip` up front and tolerates a failing `ip route`.
