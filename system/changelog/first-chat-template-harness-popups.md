Added `[create_templates.first]` to `.mngr/settings.toml`: the role template for the workspace's opening chat, stacked as `-t first -t chat` with any `--type`. It carries the `/welcome` message, the `first=true` label, and the fast-mode launch settings for both fast-capable harnesses (claude via `settings_overrides.fastMode`; codex via `config_overrides__extend` -> `service_tier = "fast"` + `features.fast_mode = true` in its per-agent config.toml -- the `__extend` markers at both dict levels are load-bearing, see the template's comment). Settings for whichever harness is not resolved are inert. Every non-first chat now launches at the harness defaults (`fastMode = false` for claude).

`AGENTS.md` now tells harnesses without native slash-command expansion (codex, pi) that a bare `/name` message invokes `.agents/skills/<name>/SKILL.md` silently -- read it and reply with what it says, no narration of the lookup -- so a codex first chat delivers `/welcome` as cleanly as claude does.
