- The desktop-interface plan (sections 3.2 and 3.6), the launcher plan (section 4.2) and the window-bound-resources spec now say that every app a program runs has a default shortcut (its `default_shortcut`, else its first launch path taking no text, in focus mode), never of a launch path that takes typed text, and that a right-click on the launcher row of that shortcut, or on a taskbar entry of the app, adds it to the desktop or removes it, shown at once.
