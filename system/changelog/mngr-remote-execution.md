mngr is pinned to the public export of mngr-internal#2791 (branch `mngr/remote-execution`), the paired mngr change. That change lives in what Imbue Studio's desktop app runs, not in the workspace: the desktop gateway's `permission-requests` extension accepts the `remote-execution` request type the `run-on-users-computer` skill files, and the app gains the "This computer" switch and approval dialog behind it, so a workspace needs an updated Imbue Studio, not this pin, to use the route. Of the packages a workspace installs from the pin only `concurrency-group` changes, with an option nothing here uses. The pin pairs the two branches so the template's CI and the paired-branch harnesses build workspaces against that mngr; once the mngr PR merges, the twice-daily bump moves the pin to the mirror of mngr `main`.
