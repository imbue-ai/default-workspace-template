The desktop interface contracts (`docs/system/blueprint/desktop-interface/contracts.md`, section 1) now say that Imbue Studio owns the shell's client id: it keeps one per shell hostname and writes it under `si-client-id` in the shell frame's local storage before the shell boots, so renaming the key, keeping the id elsewhere, or replacing a stored id would make every Studio window a new client. `ClientIdentity.ts` points at that rule where the key is defined.
