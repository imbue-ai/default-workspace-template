The chat send-failure spec (`docs/specs/chat-send-failure-system.md`) describes how send failures work now. The chat app writes the sentence for each kind of refused send, and the composer shows it as written. A send that got no answer has its own "Your message may not have been sent" notice, which offers only Send again. A message held for a chat deleted before its agent lands comes back to the page that sent it. The workspace app model's contracts (`docs/system/blueprint/workspace-app-model/contracts.md`) say a discard's `provisional_chat_completed` carries the messages dropped with the chat and is replayed to a page that connects later.
