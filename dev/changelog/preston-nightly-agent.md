Adds the recurring-job substrate for scheduled work: `scripts/run_job.sh`, a completion-tracked runner ticked every minute by cron -- any cadence (`--every 15m` to `7d`, `--at <hour>` for daily-or-coarser), catch-up after downtime, and retry of runs that failed or were killed mid-flight (only a completed run covers a window; state under `runtime/jobs/`). Durable schedule entries live in `runtime/cron.d/` and are reinstalled into `/etc/cron.d/` at each boot.

Adds `scripts/caretaker_check.sh` (the Caretaker's deterministic weekly check: crashed services, fresh log errors, disk, OOM shedding -- wakes the agent only on findings), `scripts/run_schedule_agent.sh` (create-or-retrigger for singleton skill agents), and `scripts/with_agent_env.sh` (rebuilds the agent environment for cron jobs from the env files mngr maintains). The cron daemon runs under supervisord as `[program:cron]`; CLAUDE.md gains one pointer sentence.
