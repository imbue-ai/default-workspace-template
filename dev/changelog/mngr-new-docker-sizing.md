Local docker workspaces are now sized: `[providers.docker]` in `.mngr/settings.toml` sets `default_cpus = 4` and `default_memory = "8g"`, rendered by mngr as `docker run --cpus` / `--memory` (with swap capped at the memory cap) on every new workspace container, so a runaway workspace can no longer take the whole machine down. The CPU cap is clamped to the daemon's CPU count on smaller machines. A per-create `-s --cpus` / `-s --memory` overrides the defaults, `mngr list` reports the recorded size as `host.resource`, and `mngr docker resize <host>` changes a workspace's size afterwards.
