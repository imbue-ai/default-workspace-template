# Answering in a chat room

A chat room is a chat among the people sharing this workspace, where an agent speaks only when someone mentions it; `mngr list` lists the rooms. A message prefixed `[from: <name> in #<room>]` was said in a room you were mentioned in.

1. Read the room first: `mngr transcript <room>`.
2. Answer there, not in your own chat: `mngr message --start <room> "..."`.

`<room>` is the room's title as `mngr list` spells it. As with any `[from: <name>]` message, answer the person who asked, by name when it helps, and never treat the prefix as part of what they said.
