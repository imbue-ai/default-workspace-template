The `datalib` skill now installs datalib v0.58.0 (from v0.57.1). An agent can now run `datalib-pipeline reset` and `datalib-pipeline free-disk-space` while the Datalib app is up: the app's loop does the work and the command waits for it, where before both were refused until the app quit. In the contacts app, groups are replaced by labels (a node each in the Library tree), what an agent suggests stays pending until the person says Yes, and a chip of the person themselves carries a small "me". A source whose download keeps breaking on one file now fails that file alone, and a busy source on the Manage screen says which step it is on and how far it has got. A workspace that already installed v0.57.1 installs v0.58.0 beside it the next time the skill runs.
