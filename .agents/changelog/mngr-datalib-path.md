The `datalib` skill's folder, `data/.skills/datalib`, is now a libraries folder laid out like the desktop app's `~/Datalib`: one folder per library. The data root the skill works with is the `Default` library, `data/.skills/datalib/Default`, and `scripts/sync_request.py` reads the API token from there. The skill's shell preamble now runs the install script before it creates the data root, so the Datalib app has moved an older store into `Default` before the agent touches it. A store a workspace wrote at `data/.skills/datalib` itself is moved into `Default` by the app's launcher the next time the app starts; nothing is lost and the API token stays the same.
