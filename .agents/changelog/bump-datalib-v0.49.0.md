The `datalib` skill now installs datalib v0.49.0. An embed uses about 3.6 GB less memory, for about 10% less speed, and the first search by meaning after a start no longer loads every vector while you wait. A source that reads local files scans its folder without reading any file. Slack can mirror only the channels that involve the user, and reading a channel clears its unread markers on the next sync. A download interrupted by a lost network now ends incomplete rather than succeeded, and a file whose parser panics fails that file rather than the whole sync. An agent reading a raw store directly should note that whether an email, Slack conversation, Signal message or SMS was read now lives only in the store's `read_marks` table, and that the `fsindex` source type is now `file_inventory`.
