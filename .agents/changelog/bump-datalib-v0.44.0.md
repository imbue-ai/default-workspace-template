The `datalib` skill now installs datalib v0.44.0. The Datalib app can now be shown inside Studio's windows: this is the datalib that reads the `DATALIB_FRAME_ANCESTORS` the launcher already sets, while every request still needs its API token. It adds Google Drive (Docs, Sheets and Slides with every revision, Docs rendered with their comment threads) and Linear sources; attachments and people's photos are linked from the source's own store instead of copied beside each page; sources appear as chips on the Dashboard with the same Sync, Stop, history and Reset actions as their row; and `datalib-step help` and `datalib-step examples <type>` walk an agent from an empty directory to a first sync. An existing store is upgraded on the app's next start; an older datalib can no longer open it.
