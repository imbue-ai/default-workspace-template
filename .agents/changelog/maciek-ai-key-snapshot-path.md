`use-ai-integration`'s key snapshot always lands at `/home/user/workspace/data/.secrets/anthropic.env`, whatever directory the writer or a reader runs from. Resolved against the caller's working directory, a run from the skill's or an app's directory wrote the key into a file git sees, and Claude Code records a diff of every git-visible file a Bash command changes, the key's full value included, in the agent's session transcript. `read_workspace_ai_credentials` and `write_anthropic_env_snapshot` also take the snapshot path as an argument, which the tests use instead of changing directory.
