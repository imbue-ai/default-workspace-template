`personalized-ideas` searches through Imbue Studio's web lookup (`/api/v1/agents/<id>/web-lookup/search` and `/extract` through `minds-api-proxy`) instead of the agent's own web search: the lookup passes each request to treg under an Imbue-held account, so Imbue pays and no key enters the workspace, and each result saved to `sources.json` records the engine that answered it. When the lookup is unavailable or the account's daily lookups are used up, the agent says so and suggests from what the user tells it, never falling back to another search.
