`personalized-ideas` searches through Imbue Studio's web lookup (`/api/v1/agents/<id>/web-lookup/search` and `/extract` through `minds-api-proxy`) instead of asking the user to connect a treg account: Imbue holds the treg token and pays, and no key enters the workspace. The fixed offer is reworded around getting to know the user so the ideas fit them. Results behind a sign-in, such as LinkedIn profiles, are used only as far as their search result shows; the user can paste their profile or share LinkedIn's PDF export of it instead.
