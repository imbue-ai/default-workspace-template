Update-self's what's new is the target's root changelog section for each release newer than the workspace's: from `CHANGELOG.md`, or from `UNABRIDGED_CHANGELOG.md` for a release the summary does not cover, plus `[Unreleased]` when it holds anything. A workspace whose release cannot be found is shown only the newest release, and a target without `CHANGELOG.md` shows nothing; the results message says when either applied.

The worker's merge triage takes the target's side for the root `CHANGELOG.md` and `UNABRIDGED_CHANGELOG.md` and for an entry file the target deletes, first saving the workspace's version to another path when it holds text the target's lacks. Converting a user package to a standalone project leaves the root changelogs as written.
