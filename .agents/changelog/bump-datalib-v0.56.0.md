The `datalib` skill now installs datalib v0.56.0. The sync runner's binary is renamed `datalib-pipeline`, and every action is a verb: `datalib-pipeline sync <data_root> <step>` replaces `datalib-dag <config> --sync <step>`, and `init`, `check`, `reset`, `free-disk-space`, `status`, `stop`, `turn-off` and `turn-on` are verbs too; each takes the data root or its `config.toml`. There is no `datalib-dag` any more, so a script that still calls it fails. New in this release: Markdown (Local) as a source, a Library card that browses a library as a tree, and Google Drive folders. The Claude Code raw store is re-keyed by transcript on the first start, which takes about a minute on a large store and grows the file; a reader looking records up by `id` keeps working. Links to Lightroom folders and contact categories change once.
