The `datalib` skill's data root moves from `data/.skills/datalib/Default` to `data/.shared-data`. The store is the workspace's shared data, not the skill's own state: `data/.shared-data` is a category of its own under `data/`, beside `.apps/` and `.skills/`, for data shared across the workspace, which datalib manages for the skill and the Datalib app alike; an app's own data stays under `data/.apps/<app>/`. The folder is the data root itself, with no libraries folder or `Default` library around it. The skill's preamble, its `sync_request.py` default and its backup-exclude advice name the new path. No store is moved: datalib is dark-launched, so nothing was written at the old path that a workspace relies on.
