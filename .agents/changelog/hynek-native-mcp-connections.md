The `connect-external-service` skill has a section on the connections a user turns on themselves: the services connected on their own Anthropic or OpenAI account, which a permission card can now offer to enable for one chat. It tells the agent what the message announcing that means, to use the tools it brings (`mcp__claude_ai_...` on Claude, `mcp__codex_apps__...` on Codex) for the services they cover ahead of the routing table, that the table still decides everything else (a service they do not reach, and anything an app, a scheduled job, another chat or a background agent needs), and never to turn the connections on itself or steer the user to the offer. `references/mcp.md` names it as the one harness-held connection an agent may use.
