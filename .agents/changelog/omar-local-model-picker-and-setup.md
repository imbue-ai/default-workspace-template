- An app, a service or a scheduled routine can now run its AI work on the user's local model when they ask for it ("do the refreshes with the local model"). The `use-ai-integration` skill gains that path beside its Claude ones, with a copyable helper (`local_model.py`, standard library only) that reads the workspace's Local model connection and makes one completion with it. The skill says what to build for: the model answers only while the user's computer is awake, so a scheduled run that cannot reach it is skipped and says so rather than falling back to a paid model; calls go one at a time; and only tool-free completions run there.
