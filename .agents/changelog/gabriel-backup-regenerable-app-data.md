The harden pass has a new always-applies rule, "Keep rebuildable data out of the backup". A creation that keeps a store it can rebuild (downloads, extracted archives, clones, caches) gives it its own directory with an empty `.nobackup` file created wherever the code creates the directory, so the hourly backup skips it. The creation must refill the store when it is missing, since a restore deletes what the backup did not hold. build-app's file-path conventions point to it.
