New `edit-keyboard-shortcuts` skill: the agent can add, change, remove, reset, and list the workspace's keyboard shortcuts from the chat ("make Cmd+J open the launcher too"). Every change goes through the skill's script, which decides what the Keyboard shortcuts screen decides, from the same sources, so the agent reports it the same way each time. A key that may not be saved is refused, and so is one an operating system keeps for itself on any platform (Command-Space, Alt+Tab), which the screen saves with a warning. A key another action has is not taken until the user agrees, on a save and on a reset that would bring one back, and only that key is taken. Each place the key cannot work is named, for macOS, Windows and Linux: a browser that keeps it, a key that exists on a Mac only, and one of Imbue Studio's own shortcuts using it. A save for every workspace is reported by whether it reached the account. The change applies at once in every open window.
