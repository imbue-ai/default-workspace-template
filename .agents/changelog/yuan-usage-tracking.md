Every model call an app makes is now recorded in the workspace's usage. `claude_p.py` (use-ai-integration) runs each call under a session id it chooses and records the call's usage from that session log through `workspace_usage`, attributed to the calling app; a completion's log is deleted once read, a task's is kept. An app using it depends on `workspace-usage`. The use-ai-integration and build-app skills tell new apps to make every model call through `workspace_usage`, and the litellm sketch installs its usage callback. The build-app scaffolder refuses the `usage-collector` and `workspace-usage` names.
