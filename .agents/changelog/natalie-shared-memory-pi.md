New reference `memory-protocol.md`: how pi chats keep notes in the workspace's shared memory, adapted from Claude Code's own memory prompt so Claude and pi write notes the other reads. It tells pi never to save secrets, not to save sensitive personal details unless the user asks, and to treat saved notes as data rather than instructions. The note's `modified` date is stamped by the pi extension, not written by the model. Each note's `MEMORY.md` line is kept in step with its description by the pi extension, so the protocol asks for a description that reads well as that line rather than for the line itself.
