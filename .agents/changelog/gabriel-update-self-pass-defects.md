The update-self worker's retry check now reverts a rollback only when the target it is merging is already in the workspace's history, and only a rollback that came after it. Before, it took the newest rollback anywhere since the merge base, so a pass to a new release could pick up an earlier release's rollback that its own retry had already undone, and the worker's `git revert` then failed on an empty revert.

The build-app scaffolder's port picker now takes the "is this port in use on this machine" check as an argument, and its tests pass a stand-in, so they no longer fail in a workspace whose own apps already listen on the low 8080s.
