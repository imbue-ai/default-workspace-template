New `read-app-data` skill: how an agent asks for named sources of the user's Mac app data (installed apps, Safari and other browser history, Notes, Reminders, Calendar, Messages, recent code projects, shell history) with one `app-data` request, optionally with a synchronized copy of the folder sources (Reminders, Calendar), reads the granted files through the file server (copying a database with its `-wal` and `-shm`), and uses the data only for the workspace's owner. When the user revokes a source (`REVOKED`), the agent stops reading it, keeps what it has, and asks again at most once, for a new task only; `RESTORED` clears that. `file-sharing` now points app data at it.
