The `connect-external-service` and `devices` skills say that a permission request is kept for the user whether or not an Imbue Studio app is connected. `connect-external-service` says which failing answers to a filing still mean the request was kept and is not to be filed again: a 503 or a 502 that carries a `request_id`, or a 200 whose `responses` all carry an `error`. `devices` says that the `X-Latchkey-Device` header on a request for a device's own feature says which device it is for, and to send the header on every permission request, since one filed without it may be shown on every device or only on the most recently seen one.
