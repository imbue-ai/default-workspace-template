The file-sharing skill can now ask for a synchronized copy of a folder in the same permission request that asks for access, by adding a `sync` object (with an optional `conflict` rule) to the request payload. The skill explains what the user can do with the ask in the approval dialog, where the copy lands on the machine (`~/synced_folders/<device id>/<path>`), and that the resolution message says whether the copy was enabled. It also calls the app Mind throughout.
