The `datalib` skill now installs datalib v0.43.0. It adds time series: Garmin's daily metrics, weigh-ins and each activity's per-second samples, and YoLink's and AirVisual's sensor readings, are kept as time series, which a new Time series card in the Datalib app charts, and documents draw their charts from them. The unified index is renamed the unified document index; an existing store is moved over on the app's next start.
