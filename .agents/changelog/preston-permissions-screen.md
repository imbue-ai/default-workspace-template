The `latchkey` skill no longer sends users to a "Connectors" settings page to add or reconnect an account. Connections are managed from the Permissions tab of a machine's options (the key icon in the tabs along the top): "Add connection" lists services that already have an account here under "Add another account", and the rest under "Connect a new service". The skill's two references — adding a second account for a service, and reconnecting one whose credentials expired — now name that route, so an agent relaying instructions sends the user somewhere the action actually is.
