Adds the `data-pipeline-builder` skill: a recipe for building a simple, fast ingestion tool that turns batches of raw records (JSON/CSV/Parquet dumps, periodic exports, API pulls) into a processed, queryable store with incremental loading, backfill, and bounded retention. The harden-worker flow now routes to it when a creation ingests recurring overlapping batches, states that the hardening bar wins over the skill's per-step time budgets, and surfaces the identity-key, version-ordering, and storage decisions at the outline-approval gate. The skill spec and validator now say a skill's scripts live in the skill's own `scripts/` directory, and `fetch-process-show`'s description covers user-uploaded data (plus a fix for an unterminated quote that made its frontmatter invalid YAML).
