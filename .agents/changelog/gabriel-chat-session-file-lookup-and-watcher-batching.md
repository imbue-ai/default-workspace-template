The `use-ai-integration` skill's `claude_p_completion` no longer leaves a Claude project directory behind on every call. Each completion runs `claude -p` from a throwaway working directory, and Claude persisted every one of those sessions under the account's `projects/` tree, which is what the chat app watches and scans (839 of 841 project directories on one workspace were completions). Completions now pass `--no-session-persistence`; `claude_p_task` still persists its sessions. Apps that copied `claude_p.py` in earlier keep the old behaviour until they copy it again.
