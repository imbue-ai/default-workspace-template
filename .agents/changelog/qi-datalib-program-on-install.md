`datalib` skill: `scripts/install_datalib.sh` now also adds the Datalib app's program to supervisord, copying `system/apps/datalib/datalib.conf` into `system/supervisord.conf.d/` and loading it with `supervisorctl reread` and `supervisorctl update`, and starts it if it is stopped. The skill no longer runs `supervisorctl start datalib` itself. Tested by `scripts/install_datalib_test.py`.
