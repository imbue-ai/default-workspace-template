Adds the launch-custom-agent skill: a chat agent can now launch a coding agent that works in the user's own repo or directory instead of the workspace checkout, as its own git worktree or in place. The launched agent runs vanilla -- the user's repo conventions govern it, none of the workspace's chat instructions -- but still appears as a chat in the Imbue Studio UI, binds to a signed-in provider account like any chat, and is told where it is running and how to notify the user.
