The `claude_p.py` helper in `use-ai-integration` now works with prompts that start with `-`. It used to pass the prompt as a bare argument, so a prompt starting with `---` (any file with frontmatter, such as a SKILL.md) failed with `unknown option`. The prompt now goes after `--`, and both `claude_p_completion` and `claude_p_task` accept any prompt text. Apps that copied `claude_p.py` in earlier keep the old behaviour until they copy it again.

The `find-transcripts` skill now reads current transcripts. Its jq recipe only knew the old `user_message` / `assistant_message` / `tool_result` records, so it printed nothing useful for agents writing today's `step` / `observation` records. The recipe now handles both formats. The skill points to `mngr transcript --preserved-only` for destroyed agents instead of claiming `mngr transcript` cannot read them, and mentions `--full` for untruncated tool inputs. Its `find` no longer lists the transcript converter's log as a conversation.

Workers exploring the lead's transcript now read with `--role user --role agent`. The guide said `--role assistant`, a role the current transcript format no longer has, so the lead's replies were silently left out. The detailed re-read now adds `--full`, since the default view cuts long tool inputs short.
