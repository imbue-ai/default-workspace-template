The interactive-delivery reference says a prototype that is a page reaches the user as a window on their desktop, never as a link: a localhost link to a page the workspace does not know as an app opens in the workspace's browser. A hand-built page (a detached prototype, such as an HTML mock of a redesign) goes up in the labeled preview frame: `serve_isolated_instance.py up` serves its directory with `python3 -m http.server` and `workspace-layout open` shows it, `workspace-layout refresh` picks up an edit, and `workspace-layout close` plus `serve_isolated_instance.py down` take it down once it is retired.
