- The build-app and update-app skills, `verify.md` and `service-processes.md` verify an app after a code change with one call, `verify_app.py <name> --restart --marker ... --screenshot ... --open` (or `--refresh` without `--screenshot` for an app already on screen), which restarts the program without the 30 s `startsecs` wait, checks the marker, renders the page and surfaces it. `supervisorctl restart` remains the way to bounce a daemon with no port. `check-app-errors` points a restart after a fix at `update-app` step 2 with the same split.
