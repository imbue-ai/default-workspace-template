The `datalib` skill now installs datalib v0.46.0, and tells an agent to start at `datalib-step help`, the one page from which every other datalib doc is reachable: the agent guide, a new guide to reading each source's raw store, and a new guide to building apps on datalib. A data root can now be set up from the shell (`datalib-dag init`, then `datalib-step examples <type> --append` per source), and searched there with no server (`datalib-applet search`). New sources: Todoist, and a calendar source that copies the meetings booked with you on Calendly. A ChatGPT source can be filled from a data export, past the API's rate limit, with the API taking only what changed after it. Gmail label filters keep whole threads, and each email carries Gmail's own ids and labels. In the Datalib app, a clock in the status bar sets the time zone and format of every date. Several sources re-render their documents on the first sync after the upgrade, and an older datalib can no longer open the store.
