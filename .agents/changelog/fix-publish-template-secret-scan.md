`publish-template` no longer fails on every publish with "runs under data/.secrets/restic.env, but no included app.toml [[secrets]] or SKILL.md secrets: entry declares that file" (and the same for `share.env`). The check that every secret file a template runs under is declared now looks only at the supervisord programs and `mcp-servers.json` the template's include paths cover, not the base's own programs, which run under files Imbue Studio provides. It reads program configs the way supervisord does, so a file named only in a comment is not a reference. The manifest writer now uses the validator's copy of this check rather than its own, and runs under `uv run --no-project --with 'pydantic>=2'` to load it.
