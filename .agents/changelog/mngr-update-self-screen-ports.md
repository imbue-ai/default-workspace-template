An update now moves an app of yours that sits on one of the Screen's two ports (8090 or 8091) to another port before it applies, and checks afterwards that the Screen started. Updating a workspace that had an app there used to leave the Screen and the agent browser unable to start while the update reported success. `build-app`'s guidance for wrapping an existing server now lists 8091 among the ports to avoid, and its examples no longer use 8090.
