`update_self.py run-status start` records the lead's chat id (`MINDS_CHAT_ID`, else `MNGR_AGENT_ID`) in the run record as `chat_id`. Renaming a chat renames its agent, so the Imbue Studio app and the workspace's update watchdog, which found the lead only by the recorded chat name, read a renamed chat's update as gone: the app reported it as not finished and the watchdog could record it stuck and stop its worker while it was still working. With the id on the record they find the lead under its new name.
