The app and service worker references (`type-app.md`, `type-service.md`) now run an app's suite by path from the repo root (`uv run pytest system/apps/<package>`), not from inside the app's directory. An app resolves its paths against the repo root, so a run from inside its directory could not find the shell's built modules, and its browser tests failed even in a built checkout. `type-app.md` also says to build the frontends once in a fresh worktree before running an app's browser tests.
