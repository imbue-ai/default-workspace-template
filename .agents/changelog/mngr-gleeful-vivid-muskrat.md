Code can call a model on any AI account signed in to the workspace. The use-ai-integration skill's package gains `use_ai_integration_skill.ai`: `complete()` and `run_task()` run on the workspace's default account (or the one named) through its own CLI -- `claude -p` for Anthropic, `codex exec` for OpenAI, `agy` for Google, `pi` for Opencode Go, OpenRouter and keys added through the API key option -- or litellm on an Anthropic or OpenAI API key. Each call returns the answer, its token usage, its billing and, when billed per token, its dollar cost; uses only the chosen account's credentials; and ends every process it started on a timeout. The skill teaches the library instead of copying `claude_p.py` (existing copies keep working), lists what each account type supports, and says plan sign-ins draw on the plan's usage limits.
