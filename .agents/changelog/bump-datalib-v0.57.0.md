The `datalib` skill now installs datalib v0.57.0. For an agent, the main change is in `datalib-step help <type>`: each source's page now says what that source can never see, how to read its raw store's tables, and how to check whether a copy is complete. `datalib-step help agent` gains the checks to make before answering from a copy. The release also adds a Discord source, a Google method on the `contacts` source, and faster search over a large library.
