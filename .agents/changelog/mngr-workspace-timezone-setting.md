The manage-routines skill no longer has agents switch the workspace's timezone on their own when it differs from the computer's. The zone is the user's setting, changed in Imbue Studio under Workspace settings > Timezone. An agent writes schedules in the workspace's zone, tells the user when the computer's zone differs, and sets the zone only when the user asks. It sets it through Imbue Studio's workspace settings route (with the `minds-workspaces-update` permission), which records the zone as the user's choice; by hand, with `data/.state/user_timezone_source`, only when the app cannot be reached or is too old to set it.
