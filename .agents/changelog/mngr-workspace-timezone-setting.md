The manage-routines skill no longer has agents switch the workspace's timezone on their own when it differs from the computer's. The zone is the user's setting, changed in Imbue Studio under Workspace settings > Timezone. An agent writes schedules in the workspace's zone, tells the user when the computer's zone differs, and sets the zone only when the user asks. When it does, it also writes `data/.state/user_timezone_source` so the app treats the zone as the user's choice.
