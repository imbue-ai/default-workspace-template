The `assist` skill is also run by the workspace's "Ask an agent ..." buttons on a failure, and treats a description that starts "Imbue Studio showed the user this failure" (or says first which app and window it is about) as the failure the user saw, not the user's own words. Where such a description names a task instead of a fault (start an app, free up space), the skill does the task without asking for a go-ahead and diagnoses only if it fails.
