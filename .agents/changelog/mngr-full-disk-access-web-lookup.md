- Online search and Full Disk Access work together. The first chat follows the `personalized-ideas` skill: the welcome's "Do you have any ideas?", then, after a no, one fixed offer of four choices the user answers in their own words: their Mac apps and the web (the app-data request and the name search start in the same turn), only their Mac apps, only the web, or telling the agent themselves. With both, when the search finds several people or none, the agent asks whether to search with at most three details from the app data (an organization, a school, a field); only what the user says yes to is searched with, and raw app data never leaves the workspace. The message showing the people found has no buttons: its questions are numbered and answered in one typed reply, since a button would send at once and leave the other questions unanswered. `suggest-apps` is now the app-data part of `personalized-ideas`, and `read-app-data` no longer makes its first-chat offer on its own. The agent no longer puts reply buttons in its messages anywhere (`AGENTS.md`): every question is asked in plain text and answered in the user's own words.
