Added the `notify-user` skill for chat agents: after a very long-running task in the chat (roughly ten minutes or more -- a multi-step build, a migration, a long test run), at the agent's judgment and never after every turn, it posts a one-sentence summary into the Mind app's notification feed (bell, badge, toast card, and a system banner when the user is looking elsewhere). Clicking the notification lands the user in that chat. The skill is for chats only, not launch-task workers, whose results reach the user through their parent chat. Its script posts to the app's existing per-agent notifications route through the latchkey gateway's minds API proxy and exits non-zero with the reason on stderr when the app cannot be reached, so the agent can say in its reply that the notification did not go out.
