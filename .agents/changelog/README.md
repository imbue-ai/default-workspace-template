# .agents/changelog/

Per-change entries for the `.agents` tree (skills and shared agent config: the
"agents" bucket of the changelog convention -- see
`system/scripts/workspace_scripts/check_changelog_entries.py`), kept as files
until they are consolidated into the root `CHANGELOG.md` and
`UNABRIDGED_CHANGELOG.md`. This file keeps the directory in place when a
consolidation moves every entry out, since skills name it as where an entry
goes.
