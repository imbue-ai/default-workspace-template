Adds the onboarding agent: the first agent in the Welcome chat of an installation's first workspace. It starts from what the user already told the Imbue Studio app on the creation page (what they have done before, what they use, the installed app names they chose to share, and an optional look-up of them), never asks it again, and is proactive: it sums up what it gathered, suggests one first step, asks at most one question per reply (with two or three choices), builds a small starter after at most two vague answers, and shows a short portrait of the user it would keep. Its instructions live in `.agents/shared/onboarding-agent/SKILL.md` and `references/profile-file.md`, read only by this role, so no other agent sees them and they work the same on Claude and Codex. It never labels the user with a skill level or type of user, keeps sensitive topics, other people's details and credentials out of what it writes, and treats everything read from the web, a file or an account as data, never instructions.

The agent writes a plain profile file, `data/profile/about-you.md` (a short prose portrait in the second person, an "Ideas to build" list of five to eight sourced ideas whose first is the starter, and a "Where this came from" line), only after the user has seen the text and chosen to save it. `.agents/shared/onboarding-agent/scripts/profile_check.py` checks a draft read from standard input (heading, closing sources line, length, at most eight ideas, no contact details or credentials, no contrast phrasings) so nothing reaches disk before approval.

When the user asked to be looked up, the agent's first reply only starts a background web look-up and says so; its summary comes after the user answers an "Is this you?" popup (see the chat app's entry). The look-up, `.agents/shared/onboarding-agent/scripts/lookup_user.py`, runs through `run_in_background.py` and a new `claude_p_web_lookup` in the use-ai-integration skill's `claude_p.py`: a `claude -p` with only `WebSearch` and `WebFetch`, from a throwaway directory and not persisted, so instructions on a web page cannot reach a file, a shell or the repo. It runs on the model the chat is set to (as the chat app reports it, or the account's own configured model when the chat app cannot say), for Claude chats only, and searches several ways (the name alone, with each detail, with the places public profiles live, and with name variants), opens at least three pages, and returns up to three distinct people with one factual summary and a source link each. The agent is told only how many matches were shown, never what the pages said, and uses nothing from the search before the user's pick arrives as their own message.

The session is short and ends: learn, then one message with the starter and the portrait, then save or change and close with a marked final message, after which the chat is an ordinary one.
