The `latchkey` skill is replaced by `connect-external-service`, one skill for reaching anything outside the workspace on the user's behalf. Its SKILL.md is a routing table: one row per method (a builtin latchkey service, a custom latchkey service, the service's MCP server, its direct API with a key the user supplies through a secret card, the browser), each with the cheap test that says whether it is workable, the sentence to say, and the reference to read. The agent takes the first workable row and explains rather than asking. The latchkey text lives on as `references/latchkey.md`, with the custom-service `header` option and a pointer to the direct-API row where it used to say to have the user type credentials into a file; `references/mcp.md` and `references/direct-api.md` are new.

The skill ships `scripts/request_secret.py`, which files a secret request with the chat app and prints it; the chat renders a card with one password input per variable, the user submits, and the agent is told the file and the variable names, never the values. A value reaches a program only through `python3 system/scripts/with_secrets.py data/.secrets/<name>.env -- <command>`.

Alongside: the eight skills that named the latchkey skill now point at the new one; `agentic-browser-fleet` no longer says a launch-task worker runs in an isolated container (it runs in a worktree of the same workspace); `use-ai-integration` says to delete and re-snapshot `anthropic.env` rather than edit it; `build-app` takes `--secrets-file` and documents `[[secrets]]` in `app.toml` and the wrapped program command; `manage-scheduled-tasks` and the service-processes reference say how a job or program runs under a secret file; the worker reports a needed secret instead of requesting one.

Templates carry their secrets: `publish-template` aggregates every app's `[[secrets]]` and every skill's `secrets:` front matter (plus the files the snapshot's `.mcp.template.json` and supervisord programs run under) into `[[requirements.secret]]` entries with `file` and `variables`, refuses to assemble when a referenced file is undeclared or a declared variable is missing from the publishing workspace, and ships an included `.mcp.json` renamed to `.mcp.template.json`; `use-template` files one secret card per entry up front and merges each entry's servers into `.mcp.json` once its file is stored.
