The `datalib` skill now installs datalib v0.53.0. Each message of a document renders on its own, so one message's unclosed code block or stray markup no longer spills into the next, and a message's time is shown on its sender's clock. Claude and ChatGPT syncs can keep a conversation deleted upstream, Fastmail fetches mail in larger batches, and search by meaning keeps answering while a sync writes the index. No stored data changes shape.
