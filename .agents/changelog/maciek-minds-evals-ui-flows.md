The `agentic-browser-fleet` skill now documents what the fleet will and will not navigate to, which it never said before: only `http`/`https`, and on loopback only the workspace's own registered app origins (the `url` values in `data/.state/apps.toml`). An app you just built becomes navigable as soon as `forward_port.py` has registered its port; unregistered local ports, `file:` URLs, and the cloud-metadata address stay blocked, and a refused URL exits `1` with a `navigation blocked:` message that retrying will not fix.
