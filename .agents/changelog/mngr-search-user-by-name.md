New `personalized-ideas` skill: when the user does not know what to build, the agent offers to look them up on the public web by name and suggest ideas that fit them, searching through the user's own [treg](https://treg.to/) account (its web search and page-extract tools only, never its person-enrichment providers, which would make the lookup creepy). It searches only after an explicit yes, gets the name from the Imbue account (with the user's approval of the accounts permission) or asks for it, has the user confirm which results are them, and remembers what the user confirms as a sourced `user` memory in `data/memories/` (raw results in `data/.skills/personalized-ideas/`), so later chats know it too; asking it to forget deletes all of it. A "no" is remembered. When Imbue Studio's welcome already made the offer (it does when the account has a name), a yes to it starts the lookup without asking again, and a reply that is not an answer records nothing. It is never offered once the user has described something to build or said they have an idea, and never in a shared workspace or to someone other than the owner. Spec: `docs/system/specs/personalized-ideas/spec.md`.
