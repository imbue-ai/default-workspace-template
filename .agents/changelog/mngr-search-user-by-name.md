New `personalized-ideas` skill: when the user does not know what to build, the agent offers to look them up on the public web by name and suggest ideas that fit them. It searches only after an explicit yes, gets the name from the Imbue account (with the user's approval of the accounts permission) or asks for it, has the user confirm which results are them, and keeps a short sourced note in `data/.skills/personalized-ideas/` that the user can have deleted. A "no" is remembered. It is never offered in a shared workspace or to someone other than the owner. Spec: `docs/system/specs/personalized-ideas/spec.md`.
