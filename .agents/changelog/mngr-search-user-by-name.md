New `personalized-ideas` skill: when the user does not know what to build, the agent offers to look them up on the public web by name and suggest ideas that fit them, searching with the agent's own web search (never people-search or sales-lead databases, which would make the lookup creepy); results behind a sign-in, such as LinkedIn profiles, are used only as far as their search result shows. It searches only after an explicit yes, reads the name on the Imbue account the moment the user says yes (no permission prompt) or asks for it, has the user confirm which results are them, and remembers what the user confirms as a sourced `user` memory in `data/memories/` (raw results in `data/.skills/personalized-ideas/`), so later chats know it too; asking it to forget deletes all of it. A "no" is remembered. When Imbue Studio's welcome already made the offer (it does when the account has a name), a yes to it starts the lookup without asking again, and a reply that is not an answer records nothing. It is never offered once the user has described something to build or said they have an idea, and never in a shared workspace or to someone other than the owner. Spec: `docs/system/specs/personalized-ideas/spec.md`. The lookup is quick: its searches run together, the options come from search results alone, and pages are read only for the person the user confirms.
