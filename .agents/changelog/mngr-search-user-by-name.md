New `personalized-ideas` skill: when the user does not know what to build, the agent offers to look them up on the public web by name and suggest ideas that fit them, searching with the agent's own web search (never people-search or sales-lead databases, which would make the lookup creepy); results behind a sign-in, such as LinkedIn profiles, are used only as far as their search result shows. It searches only after an explicit yes, reads the name on the Imbue account the moment the user says yes (no permission prompt) or asks for it, has the user confirm which results are them, and remembers what the user confirms as a sourced `user` memory in `data/memories/` (raw results in `data/.skills/personalized-ideas/`), so later chats know it too; asking it to forget deletes all of it. A "no" is remembered. When Imbue Studio's welcome already made the offer (it does when the account has a name), a yes to it starts the lookup without asking again, and a reply that is not an answer records nothing. It is never offered once the user has described something to build or said they have an idea, and never to someone other than the owner; when sharing is on, it asks once whether anyone else uses the workspace and searches only after "only me". Spec: `docs/system/specs/personalized-ideas/spec.md`. The lookup is quick: its searches run together, the options come from search results alone, and pages are read only for the person the user confirms.

The lookup tells people with the same name apart using the organization behind the account email (its domain only, never the address, and never a personal provider such as Gmail): results that mention it are listed first, and when none does, the agent asks once before adding it to a search.

The welcome now asks only whether the user has an idea, with Yes and No buttons. After a no, the agent asks what is annoying, overwhelming, or tedious in their digital life and, when the account has a name, offers the lookup in the same fixed message, with Search for me and I’ll tell you myself buttons.

When sharing is on, the question before a lookup has a third button, Others can, but go ahead, for an owner who wants the search even though others can see what is saved. 

What the user tells the agent about themselves is saved as ordinary memories, which the What Studio knows about me page shows and lets them edit, and the agent says so, naming and linking the page, every time it saves one. Forgetting what the lookup found keeps those memories.

The lookup asks about sharing only when the workspace is shared with other people, not when sharing is merely on for the owner's own phone.
