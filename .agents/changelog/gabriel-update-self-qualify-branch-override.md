`update-self` now updates to the template branch you picked. Choosing a branch name (not a release) as the update target used to fail quietly when the workspace only had that branch from the template upstream. The update then ran the workspace's own older update steps instead of the branch's, so fixes that shipped on the branch were skipped. The name now resolves to the upstream branch (`upstream/<branch>`), and that wins over a stale local branch of the same name. A target that names nothing the workspace has fetched now stops the update with a clear error, instead of being staged silently as the workspace's own copy.
