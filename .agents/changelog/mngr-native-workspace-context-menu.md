A new shared reference, `right-click-menus.md`, tells an agent how an app's right-click menus work: an element's own rows (actions, check rows, and one level of submenus) go to the element menu's `extraRows`, so the Imbue Studio desktop app shows them in its native menu on macOS, and a handler that has to keep the right-click carries an `own-context-menu:` marker naming why. The `build-app` skill points to it.
