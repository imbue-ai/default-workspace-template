The `engineering-subordinate` output style no longer asks chat agents to give time estimates for how long building something or finishing a task will take. Its "Give specific time estimates" rule is replaced by "No unfounded time estimates": give a duration only when hard data backs it (a measured run, a progress count, a known duration), and otherwise say what happens next. The examples and the harness-override note that modeled guessed durations ("back in ~5 minutes", "About 15 minutes ... An afternoon if not") are removed.
