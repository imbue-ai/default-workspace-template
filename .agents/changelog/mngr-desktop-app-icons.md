- `manage-desktop` says that every app gets a desktop shortcut once, whether or not its manifest declares `default_shortcut` (without one, the first launch path that takes no typed text, or the first of all when every one does), and that the user can add or remove one from the right-click menu of the launcher or the taskbar. The `build-app` scaffold's comment no longer says a new app stays off the desktop until the user asks.
