`update-self` no longer opens a window for its own chat. Its `surface-chat-tab` step ran `layout.py open chat --path "/?chat=<id>"`, which never matches the pinned chat window, so every update added a second chat window. The chat app's auto-open already shows the update chat that the Imbue Studio app starts, in the pinned chat window, so the step and its `update_self.py` subcommand are removed.
